#96 202012_Zipline (空中鋼索)

PDF: 202012_Zipline.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 小明居住在山區，主要是以空中鋼索為交通工具。所謂的空中鋼索是指在兩個不同的基地之間架設鋼索，使得人可以從較高處的基地藉由鋼索滑向較低處的基地。

山區內共有 N 座基地、M 條鋼索，基地之間只能靠鋼索通行。已知每座基地 i 的海拔高度為 hi，這 M 條鋼索都連接兩個相異的基地 a, b，如果 ha > hb，表示可以從基地 a 到基地 b，反之如果 ha < hb，表示可以從基地 b 到基地 a。而且基地 a 和 b 之間最多只會存在一條鋼索。

小明可以在每條鋼索只能使用一次的前提之下，以任意的方式從基地 1 到基地 N。由於想要體驗空中鋼索的刺激感，所以他希望中間能轉乘越多次越好。小明想要知道存在幾條具有最大轉乘次數的到達方式。

輸入格式： 第一行有兩個正整數 N 和 M (2 ≤ N ≤ 104, 1 ≤ M ≤ min(N × (N-1)/2, 105))，分別表示基地和鋼索的數量。第二行有 N 個非負整數 h1 … hN (0 ≤ h1, …, hN ≤ 109)，依序表示基地 1 到基地 N 的海拔高度。接下來 M 行每一行皆有 2 個正整數 a 和 b (1 ≤ a, b ≤ N, a ≠ b)，表示基地 a 和基地 b 之間存在一條鋼索。

輸出格式： 輸出一個非負整數，表示從基地 1 到基地 N 的有幾種到達方式具有最大轉乘次數。

演算法使用解析：【有向無環圖 (DAG) 的最長路徑與路徑計數 DP / 記憶化 DFS】

本題為圖論中的動態規劃（或記憶化深度優先搜尋）問題：

  • 建圖規則： 比較相連兩基地 a 與 b 的海拔高度 ha 與 hb，若 ha > hb 則建立由 a 指向 b 的有向邊；若 ha < hb 則建立由 b 指向 a 的有向邊。由於水往低處流且高度差有方向性，形成的圖為有向無環圖 (DAG)。
  • 狀態定義： 設 dis[u] 表示從基地 u 到終點 N 的最大轉乘次數（邊數），cnt[u] 表示從基地 u 到終點 N 且達到最大轉乘次數的路徑條數。
  • 狀態轉移： 透過遞迴拜訪所有鄰居 v，更新 dis[u] = max(dis[u], dis[v] + 1)。若有多條鄰居路徑都能達到相同的最大轉乘次數，則將對應的 cnt[v] 累積加總至 cnt[u] 中。

【範例 1 解析】多路徑匯流與最大轉乘次數計算 答案：2
【輸入範例 1】 4 5 10 6 5 2 1 2 1 3 1 4 2 4 3 4

1. 高度與有向邊建構：

鋼索連接 (a, b)高度落差比較有向邊判定說明
(1, 2)h1 = 10 > h2 = 61 → 2基地 1 可滑向基地 2
(1, 3)h1 = 10 > h3 = 51 → 3基地 1 可滑向基地 3
(1, 4)h1 = 10 > h4 = 21 → 4基地 1 可直接滑向基地 4
(2, 4)h2 = 6 > h4 = 22 → 4基地 2 可滑向基地 4
(3, 4)h3 = 5 > h4 = 23 → 4基地 3 可滑向基地 4

2. 到達終點 4 之所有可能路徑：

  • 第一條：1 → 2 → 4（經過 2 條鋼索，於基地 2 轉乘 1 次）
  • 第二條：1 → 3 → 4（經過 2 條鋼索，於基地 3 轉乘 1 次）
  • 第三條：1 → 4（經過 1 條鋼索，轉乘 0 次）

3. DFS 記憶化狀態轉移推導：

  • 基地 4（終點基底）： dis[4] = 0，cnt[4] = 1。
  • 基地 2： 僅有鄰居 4，dis[2] = dis[4] + 1 = 1，cnt[2] = cnt[4] = 1。
  • 基地 3： 僅有鄰居 4，dis[3] = dis[4] + 1 = 1，cnt[3] = cnt[4] = 1。
  • 基地 1： 可抵達鄰居 2, 3, 4：
    • 經 2：長度 = dis[2] + 1 = 2
    • 經 3：長度 = dis[3] + 1 = 2
    • 經 4：長度 = dis[4] + 1 = 1
    • 最大長度 max(2, 2, 1) = 2（代表最多轉乘 1 次）。
    • 符合最大長度的前驅節點為 2 與 3，累加路徑條數：cnt[1] = cnt[2] + cnt[3] = 1 + 1 = 2。

👉 輸出範例 1 結果： 2

【範例 2 解析】等高無法滑行之特例邊 答案：0
【輸入範例 2】 2 1 5 5 1 2

1. 高度與有向邊建構：

  • 基地 1 與基地 2 雖然有鋼索相連，但高度皆為 5（h1 = 5, h2 = 5）。
  • 題意規定「人可以從較高處的基地藉由鋼索滑向較低處的基地」，兩基地高度相同無法產生重力滑行，因此不建立任何有向邊。
  • 圖的鄰接串列 g[1] 為空集合。

2. 狀態推導與運算：

  • 從起點 1 出發無路可走，無法抵達終點 2。
  • 終點不可達，具有最大轉乘次數的到達方式數量為 0。

👉 輸出範例 2 結果： 0

【範例 3 解析】圖不連通（無法抵達終點） 答案：0
【輸入範例 3】 3 1 5 4 3 1 2

1. 高度與有向邊建構：

  • 總基地數 N = 3（目標是抵達基地 3）。
  • 輸入僅有鋼索 (1, 2)，因 h1 = 5 > h2 = 4，建立有向邊 1 → 2。
  • 基地 3 沒有任何鋼索連接，入度與出度均為 0。

2. 狀態推導與運算：

  • 從起點 1 出發只能走到基地 2，基地 2 無法通往任何地方。
  • 終點 3 屬於完全孤立節點，與起點 1 不連通。
  • 不存在任何到達方式，答案為 0。

👉 輸出範例 3 結果： 0

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<cstdio>    // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf
#include<algorithm> // 引入演算法標頭檔，以便使用 max 函數
#include<vector>    // 引入動態陣列標頭檔，以便儲存圖的鄰接串列
const int N = 10000 + 5; // 定義最大基地數量常數
using namespace std;

int n, m, h[N];              // n 為基地數量，m 為鋼索數量，h 陣列儲存各基地的海拔高度
int cnt[N]={0}, dis[N], used[N]={0}; // cnt 記錄最長路徑條數，dis 記錄最大轉乘次數，used 記錄是否已拜訪過
vector<int> g[N];            // 宣告鄰接串列，用來儲存有向邊

// 深度優先搜尋 (DFS) 配合記憶化搜尋，計算從 u 到終點 n 的最長路徑及方案數
void dfs(int u)
{
	if(used[u]) return; // 若該基地已經計算過（記憶化），則直接返回，避免重複計算
	dis[u] = 0;         // 初始化當前基地的最大轉乘次數
	if(u == n)          // 若已到達終點基地 n
	{
		cnt[u] = 1;     // 終點的到達方法數設為 1
		used[u] = 1;    // 標記為已拜訪
		return;
	}
	for(int v : g[u])   // 走訪所有從 u出發的鄰居 v
	{
		dfs(v);         // 遞迴計算鄰居 v
		dis[u] = max(dis[u], dis[v]); // 更新 u 到終點的最大轉乘次數
	}
	
	for(int v : g[u])   // 再次走訪鄰居，計算能達到最大轉乘次數的路徑總數
	{
		if(dis[u] == dis[v]) // 若鄰居 v 的最大轉乘次數等於 u 的最大轉乘次數（代表這條邊在最長路徑上）
		{
			cnt[u] += cnt[v]; // 累加來自 v 的路徑數
		}
	}
	dis[u] += 1;        // 加上當前這一步（跨越一條鋼索）
	used[u] = 1;        // 標記當前基地已計算完成
}

int main()
{
	scanf("%d%d", &n, &m); // 讀入基地數量 n 與鋼索數量 m
	for(int i=1; i<=n; ++i) scanf("%d", &h[i]); // 依序讀入 1 到 n 號基地的海拔高度
	for(int i=0; i<m; ++i)
	{
		int a, b;
		scanf("%d%d", &a, &b); // 讀入一條鋼索連接的兩個基地 a 和 b
		if(h[a] > h[b]) g[a].pushback(b); // 若 a 高度大於 b，建立從 a 到 b 的有向邊
		else if(h[a] < h[b]) g[b].pushback(a); // 若 b 高度大於 a，建立從 b 到 a 的有向邊
	}
	dfs(1);             // 從起點基地 1 開始進行深度優先搜尋
	printf("%d\n", cnt[1]); // 輸出從基地 1 出發到達終點具有最大轉乘次數的路徑總數
	return 0;           // 程式正常結束
}
