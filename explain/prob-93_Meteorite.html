#93 202012_Meteorite (流星雨)

PDF: 202012_Meteorite(Q).pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： OI 國即將有 N 顆重量分別為 W1, W2, …, WN 的隕石要掉落。現有 M 個隕石捕捉器，每一個捕捉器只能使用一次且均可捕捉一個隕石。第 i 個捕捉器可以捕捉一個重量不超過 Ci 單位重的隕石。由於隕石上的稀有物質含量正比於其重量，請計算科學家利用這些捕捉器最多能捕捉到總重量多少的隕石。

輸入格式： 第一行有兩個正整數 N 和 M (1 ≤ N, M ≤ 105)；第二行有 N 個正整數表示隕石重量；第三行有 M 個正整數表示各個捕捉器的最大承載重量限制。

輸出格式： 輸出一行正整數，表示科學家最大能捕捉隕石的重量總和。

演算法使用解析：【貪心法 (Greedy) 與指標遍歷】

本題採用貪心策略（Greedy Strategy）進行最佳匹配：

  • 將隕石重量陣列與捕捉器承載上限陣列分別進行由小到大的排序。
  • 利用雙指針從兩者最大值（由大到小）開始逆向掃描，優先讓最重的隕石去匹配能夠承載它的最大捕捉器。
  • 若當前最大捕捉器無法承載該隕石，則略過該隕石；若可以承載則累加重量，並將捕捉器指針移向次大者。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
4 3
23 45 67 99
46 67 100
  • 隕石重量陣列（排序後）： 23, 45, 67, 99
  • 捕捉器上限陣列（排序後）： 46, 67, 100
  • 逐步配對過程（從大到小 i 指向隕石，j 指向捕捉器）：
    • i 指向 99， j 指向 100：99 ≤ 100 成立 ➔ 成功捕捉！累加 99，兩指針同時往前（i 減 1, j 減 1）。
    • i 指向 67， j 指向 67：67 ≤ 67 成立 ➔ 成功捕捉！累加 67，兩指針往前。
    • i 指向 45， j 指向 46：45 ≤ 46 成立 ➔ 成功捕捉！累加 45，兩指針往前。
    • i 指向 23， j 已經越界 ➔ 迴圈結束。
  • 總重量計算： 99 + 67 + 45 = 211。

👉 輸出範例 1 結果： 211

【輸入範例 2 實際運作推導】

輸入：
4 4
1 8 5 7
1 9 6 6
  • 隕石重量陣列（排序後）： 1, 5, 7, 8
  • 捕捉器上限陣列（排序後）： 1, 6, 6, 9
  • 逐步配對過程：
    • i 指向 8， j 指向 9：8 ≤ 9 成立 ➔ 成功捕捉！累加 8，兩指針往前。
    • i 指向 7， j 指向 6：7 > 6 不成立 ➔ 捕捉器太小，僅將隕石指針 i 往前。
    • i 指向 5， j 指向 6：5 ≤ 6 成立 ➔ 成功捕捉！累加 5，兩指針往前。
    • i 指向 1， j 指向 6：1 ≤ 6 成立 ➔ 成功捕捉！累加 1，兩指針往前。
  • 總重量計算： 8 + 5 + 1 = 14。

👉 輸出範例 2 結果： 14

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

//fast version  
#include<cstdio>  // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf
#include<algorithm>  // 引入演算法標頭檔，以便使用 sort 排序函式
using namespace std;  
const int N = 100000 + 5, M = 100000 + 5;  // 定義陣列的最大容量常數
typedef long long ll;  // 將 long long 簡稱為 ll，避免總重量總和溢位
  
int main()  
{  
    ll ans = 0;  // 初始化 ans 用來累加捕捉到的隕石總重量，型態為 long long
    static int n, m, meteorite[N], machine[N];  // 宣告 n(隕石數)、m(捕捉器數)、meteorite(隕石重量陣列)、machine(捕捉器容量陣列)
    scanf("%d%d", &n, &m);  // 讀入隕石數量 n 與捕捉器數量 m
    for(int i=0; i<n; ++i) scanf("%d", &meteorite[i]);  // 迴圈讀入每顆隕石的重量
    for(int i=0; i<m; ++i) scanf("%d", &machine[i]);  // 迴圈讀入每個捕捉器的最大承載容量
    
    sort(meteorite, meteorite+n);  // 將隕石重量由小到大進行排序
    sort(machine, machine+m);  // 將捕捉器容量由小到大進行排序
    
    // 從最大的隕石 (i = n-1) 與最大的捕捉器 (j = m-1) 開始進行倒序貪心匹配
    for(int i=n-1, j=m-1; i>=0 && j>=0; --i)  
    {  
        if(meteorite[i] > machine[j]) continue;  // 若當前最重的隕石超過目前最大捕捉器的承載極限，則此隕石無法被捕捉，略過
        ans += (ll)meteorite[i];  // 若可以捕捉，將該隕石重量轉型為長整數並累加至 ans 中
        --j;  // 使用掉當前最大捕捉器，將捕捉器指針往前移一位
    }  
    
    printf("%lld\n", ans);  // 輸出最終計算出的最大隕石總重量
}
