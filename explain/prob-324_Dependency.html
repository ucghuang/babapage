#324 202605_Dependency (安裝順序)

題目摘要與限制

問題情境： 老師出了一份學習單，有 N 個待安裝的軟體（編號 1 ~ N）與 M 個相依性限制。若存在相依限制 (ai, bi)，表示安裝軟體 bi 之前，必須先安裝完成軟體 ai。若滿足所有相依條件的安裝順序不唯一，批改會變得極為繁瑣。請判定是否存在多組合法解答。

  • 輸入格式： 第一行包含兩個正整數 N 和 M（2 ≤ N ≤ 2 × 105, M ≤ min(N(N-1)/2, 2 × 105)）。隨後 M 行每行包含兩個正整數 ai, bi。
  • 輸出格式： 若有多組合法解輸出 1；若恰有一組合法解則輸出 0。題目保證必定至少存在一組合法解（無環路矛盾）。
  • 測資規模：
    • 第一組 (40分)：N ≤ 10。
    • 第二組 (60分)：無特別限制（N, M ≤ 2 × 105，需 O(N + M) 演算法）。

演算法核心原理解析：【DAG 拓樸排序唯一性 ⟺ 最長鏈定理】

將軟體視為頂點、相依關係視為有向邊，問題即為**有向無環圖 (DAG) 的拓樸排序 (Topological Sort)**：

  1. 圖論唯一性定理（Hamiltonian Path）：
    一個 DAG 具有唯一拓樸排序的充要條件是：圖中存在一條走遍所有 N 個節點的哈密頓路徑（Hamiltonian Path）。
  2. 最長路徑等價轉換：
    因為圖中無環，若存在貫穿所有頂點的路徑，這條路徑必然是全圖的**最長路徑**，且其邊數恰為 N - 1（深度為 N - 1）。
  3. 演算法檢驗步驟：
    • 步驟 A（入度檢查）： 統計所有點的入度 (inDeg)。唯一的拓樸起始點必須是全圖唯一入度為 0 的頂點。若入度為 0 的點數量不等於 1，代表有多個可以同時作為起點的軟體，直接判定有多組解（回傳 1）。
    • 步驟 B（記憶化 DFS 最長路徑）： 從該起點出發，使用動態規劃 / 記憶化 DFS 計算從起點能抵達的最深長度 dfs(u)： $dis[u] = max(u, v) ∈ E (dis[v] + 1)$ 若 dfs(src) == N - 1，代表全體軟體能串成一條唯一且嚴格的主鏈，輸出 0；否則輸出 1。

課堂黑板推導：三組官方範例圖形與狀態演繹

範例 1：菱形分支結構（N = 4, M = 4） 輸出：1 (多組解)

輸入關係： (1, 2), (1, 3), (2, 4), (3, 4)

推導過程：

節點編號 (1-based / 0-based) 入度 (in-degree) DFS 深度計算 (dis) 拓樸約束分析
1 (索引 0) 0 (唯一的起點 src) max(dis[2]+1, dis[3]+1) = 2 • 最長路徑長度為 2。
• 但全鏈路需滿足 N - 1 = 3。
• 合法安裝序列包含：
  解 A: [1, 2, 3, 4]
  解 B: [1, 3, 2, 4]
👉 存在 2 種排列，判定為多組解。
2 (索引 1) 1 (來自 1) dis[4] + 1 = 1
3 (索引 2) 1 (來自 1) dis[4] + 1 = 1
4 (索引 3) 2 (來自 2, 3) 0 (終點出度為 0)
範例 2：完整主鏈與跨層相依（N = 4, M = 4） 輸出：0 (唯一解)

輸入關係： (1, 2), (1, 3), (2, 3), (3, 4)

推導過程：

節點編號 入度 (inDeg) DFS 深度計算 (dis) 拓樸約束分析
1 (索引 0) 0 (唯一的起點 src) max(dis[2]+1, dis[3]+1) = max(2+1, 1+1) = 3 • 最長路徑深度 dis[0] = 3。
• 剛好等於 N - 1 = 4 - 1 = 3。
• 存在包含所有節點的唯一主鏈：
  1 ➔ 2 ➔ 3 ➔ 4
• 合法安裝順序只有一種：[1, 2, 3, 4]。
👉 解完全唯一。
2 (索引 1) 1 (來自 1) dis[3] + 1 = 1 + 1 = 2
3 (索引 2) 2 (來自 1, 2) dis[4] + 1 = 0 + 1 = 1
4 (索引 3) 1 (來自 3) 0 (終點出度為 0)
範例 3：亂序輸入之完整單向鏈（N = 5, M = 5） 輸出：0 (唯一解)

輸入關係： (5, 1), (3, 4), (5, 4), (2, 5), (1, 3)

推導過程：

節點編號 入度 (inDeg) 深度 (dis) 計算過程 狀態結論
2 (索引 1) 0 (唯一入度為 0，src = 1) dis[5] + 1 = 3 + 1 = 4 • 起點為軟體 2。
• 最長深度為 4，剛好等於 N - 1 = 5 - 1 = 4。
• 形成唯一拓樸順序：
  [2, 5, 1, 3, 4]
• 軟體 5 同時指向 4 是多餘的約束（因為 5 已經透過 1 和 3 間接領先 4），不破壞唯一的線性順序。
👉 因此恰有一組解。
5 (索引 4) 1 (來自 2) max(dis[1]+1, dis[4]+1) = max(3, 1) = 3
1 (索引 0) 1 (來自 5) dis[3] + 1 = 1 + 1 = 2
3 (索引 2) 1 (來自 1) dis[4] + 1 = 0 + 1 = 1
4 (索引 3) 2 (來自 3, 5) 0 (出度為 0)

參考解答 C++ 程式碼（100% 取自官方解答，逐行繁體中文教學註解）

#include<cstdio>      // 引入 C 標準輸入輸出函式庫 (如 scanf, printf)
#include<climits>     // 引入極值常數庫 (如 INTMAX)
#include<vector>      // 引入 C++ 動態陣列容器 (vector) 函式庫
#include<algorithm>   // 引入演算法函式庫 (如 max)
using namespace std;  // 使用標準命名空間 std

// 深度優先搜尋函數：計算從節點 u 出發所能達到的最深路徑（邊的數量）
int dfs(const vector<vector<int>> &g, vector<int> &dis, int u) {
	if (dis[u] != INTMAX) return dis[u];  // 記憶化搜尋：若 dis[u] 已經算過，直接回傳常數時間結果
	dis[u] = 0;                            // 初始化當前節點 u 的基礎深度為 0 (若無後續出邊，深度即為 0)
	for (const int &v : g[u]) {            // 遍歷所有從 u 出發的鄰邊目標節點 v
		dis[u] = max(dis[u], dfs(g, dis, v) + 1);  // 狀態轉移：取所有後繼路徑深度的最大值 + 1
	}
	return dis[u];                         // 回傳計算後的節點 u 最大深度
}

// 核心判定函數：判斷是否有唯一拓樸排序解
int solve(int n, const vector<vector<int>> &edges) {
	int m = (int)edges.size();            // 取得相依關係邊的總數量 m
	vector<vector<int>> g(n);             // 宣告鄰接串列 g，表示有向圖 (0-based)
	vector<int> inDeg(n, 0);              // 宣告入度陣列 inDeg，記錄每個節點被多少個前置節點指向

	vector<int> dis(n, INTMAX);          // 宣告深度記錄陣列 dis，初始化為 INTMAX 代表尚未走訪計算過

	int src = -1;                         // 宣告根起點 src，初始設定為 -1

	for (const vector<int> &edge : edges) {  // 迴圈遍歷輸入的所有相依關係
		g[edge[0]].pushback(edge[1]);    // 建立從 edge[0] 指向 edge[1] 的有向依賴邊
		++inDeg[edge[1]];                 // 目標節點的入度累加 1
	}

	for (int i = 0; i < n; ++i) {         // 尋找全圖中入度為 0 的起始節點
		if (inDeg[i] == 0) {
			src = i;                      // 記錄入度為 0 的節點索引
			break;                        // 找到第一個後跳出（若後面還有其他入度 0 點，後續深度檢驗亦會失敗）
		}
	}
	
	// 唯一性判定條件：
	// 1. src == -1：找不到入度為 0 的起點（雖然題意保證 DAG，此為安全邊界）。
	// 2. dfs(g, dis, src) != n - 1：由起點出發的最長路徑深度未達到 n - 1，
	//    代表節點無法排列成單一的哈密頓鏈（存在分支獨立性），必定存在多組合法順序。
	if (src == -1 || dfs(g, dis, src) != n - 1) return 1; // 存在多組解，輸出 1
	return 0;                                             // 存在唯一解，輸出 0
}

int main()                                // 主程式進入點
{
	int n, m;                             // 宣告軟體數量 n 與相依關係數量 m
	vector<vector<int>> edges;            // 宣告儲存邊資料的二維向量
	scanf("%d%d", &n, &m);                // 快速格式化讀入 n 與 m
	edges.resize(m, vector<int>(2));      // 調整邊向量空間大小為 m x 2
	
	for (vector<int> &edge : edges) {     // 逐筆讀入相依限制邊
		for (int &x : edge) {
			scanf("%d", &x);              // 讀入節點編號
			--x;                          // 將題目 1-based 編號轉換為 C++ 習慣的 0-based 索引
		}
	}
	
	printf("%d\n", solve(n, edges));      // 呼叫核心函數判斷，輸出結果 (1: 多解, 0: 唯一解)
	
	return 0;                             // 程式執行完畢
}
