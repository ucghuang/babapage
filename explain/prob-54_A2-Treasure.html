#54 202004_A2-Treasure (分配寶物)

題目摘要與測資規格

情境敘述： Alice、Bob 和 Cindy 共同發現 N 個不可分割的寶物，第 i 個寶物價值為 Vi 元。所有寶物皆必須分配給三人之一，且每個人獲得的總價值必須完全相同。請判斷是否能達成平分。

輸入格式： 第一行包含一個正整數 N (3 ≤ N ≤ 16)；第二行包含 N 個正整數 V1, V2, …, VN (1 ≤ Vi ≤ 107)。

輸出格式： 若可完全平分輸出 YES，否則輸出 NO。

配分分段： 第一組 (20分)：N = 4；第二組 (80分)：3 ≤ N ≤ 16。

演算法解析：深度優先搜尋 (DFS) 與雙重剪枝策略

本題屬於經典的三等分子集和問題（3-Partition Problem）。由於每個寶物都有分配給 3 個人之一的決策，未剪枝前的狀態空間樹高達 3N（當 N=16 時約 4.3 × 107 種狀態）：

  • 整除前置判定：計算所有寶物總和 Sum。若 Sum ±od 3 ≠ 0，在數學上絕對無法平分，立即輸出 NO。若可整除，平分目標為 Target = Sum / 3。
  • 溢位剪枝（Over-target Pruning）：因為所有寶物價值皆為正整數（Vi ≥ 1），一旦累積總額 p1 > Target 或 p2 > Target 或 p3 > Target，後續分支不可能減少，立刻中斷並回溯。
  • 早停旗標剪枝（Early Stop）：只要任一遞迴分支抵達終點並發現 p1 = p2 = p3 = Target，全域旗標 flag = true，後續所有的 dfs 呼叫藉由 if(!flag) 全數阻斷，大幅省去多餘運算。

【輸入範例 1 運算推導】（無解驗證與單元素超額剪枝）

輸入：N = 3，寶物清單 = { 1, 2, 3 }
  • 第一步：總和與整除檢驗 $Sum = 1 + 2 + 3 = 6 ⟹ 6 ±od 3 = 0 (通過)$ $每人平分目標 Target = 6 / 3 = 2$
  • 第二步：決策推導與溢位矛盾分析

    依題目要求，每個寶物必須全額分給其中一人（不可分割）。檢視陣列中價值為 3 的寶物：

    不論將該寶物分給 Alice、Bob 或 Cindy，該名持有者的累積價值至少為 3。由於 3 > Target (2)，直接違反目標值，在 DFS 進入該狀態時立即觸發 p > pans 剪枝返回。因此狀態空間中不存在任何合法組合。

嘗試路徑步驟 目前累積 (p1, p2, p3) 正在分配寶物 剪枝檢查與狀態
1. dfs(0, 0, 0, 0) (0, 0, 0) a[0] = 1 給 p1 合法，深入至 cur=1
2. dfs(1, 1, 0, 0) (1, 0, 0) a[1] = 2 給 p1 1 + 2 = 3 > 2，觸發剪枝返回
3. dfs(1, 1, 0, 0) (1, 0, 0) a[1] = 2 給 p2 合法，深入至 cur=2
4. dfs(2, 1, 2, 0) (1, 2, 0) a[2] = 3 分給任一人 (4, 2, 0) 或 (1, 5, 0) 或 (1, 2, 3)，全部 > 2，全部剪枝

👉 輸出範例 1 結果： NO

輸入：N = 4，寶物清單 = { 1, 2, 3, 3 }
  • 第一步：總和與整除檢驗 $Sum = 1 + 2 + 3 + 3 = 9 ⟹ 9 ±od 3 = 0 (通過)$ $每人平分目標 Target = 9 / 3 = 3$
  • 第二步：成功指派序列追蹤

    DFS 依序對各個寶物做出以下指派決策：

DFS 遞迴深度 考慮寶物價值 a[cur] 分配決策對象 累積狀態 (p1, p2, p3) 狀態說明
cur = 0 a[0] = 1 分配給 Alice (p1) (1, 0, 0) 1 ≤ 3，繼續搜尋
cur = 1 a[1] = 2 分配給 Alice (p1) (3, 0, 0) p1 = 3，剛好達標

【輸入範例 3 運算推導】（大測資 10 元素集合劃分分析）

輸入：N = 10，寶物清單 = { 12, 53, 34, 23, 29, 26, 19, 10, 1, 6 }
  • 第一步：計算全數值總和 $Sum = 12 + 53 + 34 + 23 + 29 + 26 + 19 + 10 + 1 + 6 = 213$ $整除檢查：213 ±od 3 = 0 ⟹ Target = 213 / 3 = 71$
  • 第二步：三人分配組合拆解矩陣

    DFS 深度探索成功尋獲之劃分組合（三組總和均精確等於 71）：

分配對象 分得之寶物集合 加總推算式 累積總額 驗證狀態
Alice (p1) { 53, 12, 6 } 53 + 12 + 6 71 吻合 Target
Bob (p2) { 34, 26, 10, 1 } 34 + 26 + 10 + 1 71 吻合 Target

官方解答 C++ 原始碼（逐行繁體中文教學註解）

#include <stdio.h>  // 引入標準輸入輸出函式庫 (scanf, puts)

bool flag = false;   // 全域布林旗標：記錄是否成功找到三等分的分配方式，預設為 false
int n;              // 寶物數量 N (3 <= N <= 16)
int a[20];          // 存放各寶物價值的陣列
int pans = 0;       // 累加所有寶物總價值 (後續轉為目標值 pans = pans / 3)

/**
 * 深度優先搜尋 (DFS) 函數
 * @param cur 當前正在考慮分配的寶物索引 (0 到 n-1)
 * @param p1  目前分配給第 1 個人 (Alice) 的累計價值
 * @param p2  目前分配給第 2 個人 (Bob) 的累計價值
 * @param p3  目前分配給第 3 個人 (Cindy) 的累計價值
 */
void dfs(int cur, int p1, int p2, int p3)
{
    // 【剪枝 1】：若任何一人的分配價值已經超過目標平分額 pans，因寶物價值皆為正數，後續無法減小，直接返回
    if (p1 > pans || p2 > pans || p3 > pans) return;
    
    // 【遞迴終止條件】：當所有寶物 (0 到 n-1) 都已經分配給某人
    if (cur == n)
    {
        // 檢查三個人分配到的寶物價值是否完全相等
        if (p1 == p2 && p2 == p3) 
        {
            flag = true;  // 成功尋獲一組合法解
        }
        return;
    }
    
    // 【剪枝 2】：只要找到解 (flag=true)，後續遞迴分支藉由 !flag 直接略過，不再浪費時間搜尋
    if (!flag) dfs(cur + 1, p1 + a[cur], p2, p3);  // 決策 1：將第 cur 個寶物分配給 Alice (p1)
    if (!flag) dfs(cur + 1, p1, p2 + a[cur], p3);  // 決策 2：將第 cur 個寶物分配給 Bob (p2)
    if (!flag) dfs(cur + 1, p1, p2, p3 + a[cur]);  // 決策 3：將第 cur 個寶物分配給 Cindy (p3)
}

int main()
{
    // 讀入寶物數量 n
    scanf("%d", &n);
    
    // 迴圈讀入每個寶物的價值並累計總和
    for (int i = 0; i < n; ++i)
    {
        scanf("%d", &a[i]);
        pans += a[i];      // 累加總金額
    }
    
    // 【前置數學檢查】：若總金額無法被 3 整除，數學上必定無法平分
    if (pans % 3 == 0)
    {
        pans /= 3;         // 計算每個人應得的目標平分價值 (目標值)
        dfs(0, 0, 0, 0);   // 從第 0 個寶物開始搜尋，三人初始金額皆為 0
    }
    
    // 根據旗標輸出最終結果：若為 true 輸出 YES，否則輸出 NO
    puts(flag ? "YES" : "NO");
    
    return 0;  // 程式正常結束
}
