#9 201904_A3-KeyPlanet (關鍵星)

題目規格與摘要

問題情境： 星際航行中僅能依據星圖記載的安全雙向路線移動。如果某一星球消失後，會使得原本能互通的星球群分裂成兩個以上互不連通的區域，該星球即被定義為「關鍵星」[cite: 1]。

輸入格式： 第一列為兩整數 V 與 E（$1 \le V \le 10^4$，$V-1 \le E \le V(V-1)/2$），分別表示星球總數與路線數[cite: 1]。接著 E 列每列為兩整數 u 與 v，表示雙向安全路線[cite: 1]。圖形保證一開始完全連通[cite: 1]。

輸出格式： 將所有關鍵星的編號由大至小依序輸出，中間以空格分隔；若圖中無任何關鍵星，則輸出 FAIL[cite: 1]。

演算法推導：Tarjan 割點演算法 (Articulation Points)

本題為無向圖求解割點的標準經典題，最優複雜度為線性時間 $O(V + E)$[cite: 1, 3]：

核心狀態變數維護：
  • visit[u]：節點 $u$ 在 DFS 搜尋過程中被拜訪的時間戳記（Depth-First Search Discovery Time）[cite: 3]。
  • low[u]：節點 $u$ 或其子樹中的節點，透過「樹邊」以及至多一條「回邊（Back-edge）」所能回溯到的最小 visit 值[cite: 3]。
  • Num_child：節點 $u$ 在 DFS 樹中實際衍生出的子樹分支數量[cite: 3]。
割點判定準則（二分情況判定）：
  • 情況一（DFS 根節點）： 若節點 $u$ 為 DFS 的起始根節點（程式中判定 pre == cur），當且僅當其在 DFS 樹中擁有多於一個子分支（即 Num_child > 1）時，$u$ 為割點[cite: 3]。因為兩棵不同子樹間若有邊相連，則第二棵子樹在遍歷時會直接成為第一棵子樹的後代，不會形成兩個獨立分支。
  • 情況二（非根節點）： 若節點 $u$ 不是根節點，且其存在任一子節點 $v$ 滿足 low[v] >= visit[u]，代表子節點 $v$ 及其後代無法回溯到 $u$ 以前的祖先節點[cite: 3]。一旦移除 $u$，$v$ 所在的分支將徹底與圖的其他部分斷開，因此 $u$ 必為割點[cite: 3]。

節點 ($u$) 拜訪順序 (visit) 回溯值 (low) 子樹分支數 (Num_child) 條件判定 是否為關鍵星
0112 根節點且 Num_child = 2 (> 1) 是 (0)

2310 Back-edge 至 0，low[2]=1 否
3411 Back-edge 至 0，low[3]=1 < visit[0]=1 否

解析：節點 0 作為起點，先後探索了左側三角形 {1, 2} 與右側三角形 {3, 4}，產生兩支獨立的樹分支（Num_child = 2），若拔除 0 兩側互不連通，因此 0 為唯一割點[cite: 2]。

【範例 3】簡單環形圖 (Simple Cycle C4) 輸出：FAIL
輸入 (Input):
4 4
0 1
1 2
2 3
3 0
輸出 (Output):
FAIL
節點 ($u$) 拜訪順序 (visit) 回溯值 (low) 子樹分支數 (Num_child) 條件判定 是否為關鍵星
0111 根節點且 Num_child = 1 (≤ 1) 否
1211 非根，low[2]=1 < visit[1]=2 否
2311 非根，low[3]=1 < visit[2]=3 否
3410 Back-edge 繞回 0 (low[3]=visit[0]=1) 否

解析：環形結構具備雙連通性，節點 3 可直接回溯到起點 0，使得所有節點的 low 值皆被更新為 1，無任何非根節點滿足 low[dest] >= visit[cur]，根節點亦僅有 1 個分支，輸出 FAIL[cite: 2, 3]。

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細教學註解）

#include <bits/stdc++.h>  // 引入常用 C++ 標頭檔

// DFS 函式：利用 Tarjan 演算法核心邏輯尋找圖中的割點 (Articulation Point)
void DFS(int pre, int cur, std::vector<int> adj[], int low[], int visit[], int &t, std::vector<int> &ans)
{
    t += 1;  // 時間戳記遞增
    visit[cur] = low[cur] = t;  // 初始化當前節點的拜訪時間與 low 值
    int Num_child = 0;  // 記錄當前節點在 DFS 樹中的子分支數量
    bool ap = false;    // 記錄當前節點是否符合非根割點條件的旗標
    int Num = adj[cur].size();  // 取得與當前節點相連的鄰居數量
    
    // 走訪所有相鄰的星球
    for (int i = 0; i < Num; i += 1)
    {
        int dest = adj[cur][i];  // 目標鄰居星球編號
        if (dest == pre)
            continue;  // 若目標是 DFS 樹上的父節點則跳過
            
        if (visit[dest] != 0)  // 若目標鄰居已經被拜訪過（代表遇到 Back-edge 返祖邊）
        {
            low[cur] = std::min(low[cur], visit[dest]);  // 更新當前節點能回溯到的最小 visit 值
        }
        else  // 若目標鄰居尚未被拜訪
        {
            Num_child += 1;  // DFS 樹子分支數量 +1
            DFS(cur, dest, adj, low, visit, t, ans);  // 遞迴深入搜尋子樹
            low[cur] = std::min(low[cur], low[dest]);  // 子樹搜尋完畢回溯時，以子節點之 low 值更新自己
            
            // 割點條件：若子節點的 low 值大於或等於當前節點的 visit 值，代表子節點無法繞回當前節點的祖先
            if (low[dest] >= visit[cur]) 
                ap = true;
        }
    }
    
    // 割點判定彙整：
    // 1. 若為根節點 (pre == cur) 且子分支數大於 1 (Num_child > 1)
    // 2. 若不為根節點 (cur != pre) 且符合 ap 條件
    if ((pre == cur && Num_child > 1) || (cur != pre && ap))
        ans.push_back(cur);  // 將該關鍵星加入答案陣列中
}

int main()
{
    // 為符合題目 V <= 10^4，陣列大小設為 20005 確保空間充裕
    std::vector<int> adj[20005];  // 宣告鄰接表儲存圖形結構
    std::vector<int> ans;         // 宣告動態陣列儲存找到的關鍵星
    int visit[20005] = {};        // 記錄每個節點的拜訪時間戳記（0 代表未拜訪）
    int low[20005] = {};          // 記錄每個節點的 low 追溯值
    int t = 0;                    // 拜訪時間計數器

    int V, E;
    if (scanf("%d%d", &V, &E) != 2) return 0;  // 讀入星球數 V 與安全路線數 E
    
    for (int i = 0; i < E; i += 1)
    {
        int v1, v2;
        scanf("%d%d", &v1, &v2);  // 讀入雙向安全路線的兩端星球編號
        adj[v1].push_back(v2);
        adj[v2].push_back(v1);
    }
    
    // 題目保證圖形一開始全連通，故以節點 0 作為起點進行單次 DFS
    DFS(0, 0, adj, low, visit, t, ans);
    
    int n = ans.size();
    std::sort(ans.begin(), ans.end());  // 先將找到的關鍵星由小到大排序
    
    // 題目要求由大到小輸出，故從陣列尾端往前印出
    for (int i = n - 1; i >= 0; i -= 1)
    {
        if (i != n - 1)
            printf(" ");
        printf("%d", ans[i]);
    }
    
    if (n == 0)
        printf("FAIL");  // 若沒有任何關鍵星則輸出 FAIL
    printf("\n");

    return 0;
}
