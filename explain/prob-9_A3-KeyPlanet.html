#9 201904A3-KeyPlanet (關鍵星)

題目摘要

問題敘述： 宇宙中有一群星球與安全路線，若拔除某一顆星球後，會導致剩餘某些星球之間無法互相抵達，該星球就被稱為「關鍵星」（即圖論中的割點 / 關節點 (Articulation Point)）。給定 V 個星球與 E 條安全路線，請找出所有的關鍵星，並將它們依編號由大到小排序輸出；若無關鍵星則輸出 FAIL。

輸入格式： 第一列有兩個整數 V 和 E (1 ≤ V ≤ 104)，代表星球數與路線數；接下來 E 列每列有兩個數字 V1 與 V2，表示兩星球間的安全路線。

輸出格式： 將所有關鍵星依編號由大到小列印出來，以空格間隔；若無關鍵星則輸出 FAIL。

演算法使用解析：【圖論演算法 / Tarjan 演算法求割點】

本題採用圖論中的 Tarjan 演算法尋找割點 (Articulation Point)：

  • 我們利用深度優先搜尋 (DFS) 走訪圖形，並維護兩個核心陣列：`visit[cur]`（記錄節點被拜訪的順序/時間戳記）與 `low[cur]`（記錄透過back-edge能回溯到的最早祖先節點時間）。
  • 割點判定條件：
    • 根節點： 若 DFS 樹的根節點擁有超過一個子樹（Child），則該根節點為割點。
    • 非根節點： 若某個非根節點 cur 存在一個子節點 dest，其 low[dest] >= visit[cur]，代表 dest 及其子孫無法透過其他路徑回到 cur 的祖先，一旦移除 cur 就會導致圖形斷開，因此 cur 是割點。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
6 5
0 1
1 2
2 3
3 4
4 5
  • 圖形結構： 這是一條長條狀的鍊狀圖：0 - 1 - 2 - 3 - 4 - 5。
  • 分析割點：
    • 如果拔除節點 1，節點 0 會與其餘節點斷開。
    • 如果拔除節點 2、3、4，整個圖形會斷開成兩半。
    • 因此關鍵星（割點）包含 1, 2, 3, 4。
  • 輸出排序： 題目要求由大到小排序輸出：4 3 2 1。

👉 輸出範例 1 結果： 4 3 2 1

【輸入範例 3 實際運作推導】

輸入：
4 4
0 1
1 2
2 3
3 0
  • 圖形結構： 這是一個環形圖（0 - 1 - 2 - 3 - 0）。
  • 分析割點： 在環形結構中，任拔除一個星球，其餘星球仍然可以透過環的另一側互相繞道抵達，因此不存在任何關鍵星。

👉 輸出範例 3 結果： FAIL

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<bits/stdc++.h>  // 引入常用 C++ 標頭檔

// DFS 函式：利用 Tarjan 演算法核心邏輯尋找圖中的割點 (Articulation Point)
void DFS(int pre, int cur, std::vector<int> adj[], int low[], int visit[], int &t, std::vector<int> &ans)
{
    t+=1;  // 時間戳記遞增
    visit[cur] = low[cur] = t;  // 初始化當前節點的拜訪時間與 low 值
    int Numchild = 0;  // 記錄當前節點在 DFS 樹中的子節點數量
    bool ap = false;  // 記錄當前節點是否符合割點條件的旗標
    int Num = adj[cur].size();  // 取得與當前節點相連的鄰居數量
    
    // 走訪所有相鄰的星球
    for (int i=0; i<Num; i+=1)
    {
        int dest = adj[cur][i];  // 目標鄰居星球編號
        if (dest==pre)
            continue;  // 若目標是父節點則跳過
            
        if (visit[dest]!=0)  // 若目標鄰居已經被拜訪過（代表遇到 Back-edge）
        {
            low[cur] = std::min(low[cur], visit[dest]);  // 更新當前節點的 low 值
        }
        else  // 若目標鄰居尚未被拜訪
        {
            Numchild+=1;  // 子樹分支數 +1
            DFS(cur, dest, adj, low, visit, t, ans);  // 遞迴深入搜尋子樹
            low[cur] = std::min(low[cur], low[dest]);  // 回溯時更新當前節點的 low 值
            
            // 割點條件：若子節點的 low 值大於或等於當前節點的 visit 值，代表子樹無法繞回祖先
            if(low[dest]>=visit[cur]) ap=true;
        }
    }
    
    // 判斷是否為割點：1. 若為根節點且子樹大於 1； 2. 若不為根節點且符合 ap 條件
    if ((pre==cur&&Numchild>1)||(cur != pre && ap))
        ans.pushback(cur);  // 將該關鍵星加入答案陣列中
}

int main()
{
    std::vector<int> adj[20005];  // 宣告鄰接表儲存圖形結構
    std::vector<int> ans;  // 宣告動態陣列儲存找到的關鍵星
    int visit[20005]= {};  // 記錄每個節點的拜訪時間戳記
    int low[20005]= {};  // 記錄每個節點的 low 追溯值
    int t = 0;  // 拜訪時間計數器

    int V,E;
    scanf("%d%d", &V, &E);  // 讀入星球數 V 與安全路線數 E
    for(int i=0; i<E; i+=1)
    {
        int v1,v2;
        scanf("%d%d",&v1, &v2);  // 讀入雙向安全路線的兩端星球編號
        adj[v1].pushback(v2);
        adj[v2].pushback(v1);
    }
    
    DFS(0,0, adj, low, visit, t, ans);  // 從編號 0 開始進行 DFS 尋找割點
    
    int n=ans.size();
    std::sort(ans.begin(),ans.end());  // 將找到的關鍵星由小到大排序
    
    // 題目要求由大到小輸出，故從尾端往前印出
    for(int i=n-1; i>=0; i-=1)
    {
        if(i!=n-1)
            printf(" ");
        printf("%d", ans[i]);
    }
    
    if (n==0)
        printf("FAIL");  // 若沒有任何關鍵星則輸出 FAIL
    printf("\n");
}
