#26 201908-onsite8-Treasure (幽靈寶藏)

PDF: 201908-onsite8-Treasure.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 幽靈變出了 N 個空的藏寶箱（編號 1 至 N），並進行 M 次操作。操作分為兩種：

  • 類型 1 (R=1)： 在第 P 至 Q 個藏寶箱內放入 S 枚硬幣（加法區間更新）。
  • 類型 2 (R=2)： 使第 P 至 Q 個藏寶箱內的硬幣價值變為 S 倍，包括事後放入的硬幣（乘法區間更新）。

當完成所有操作後，探險隊要挑選一個寶箱帶走。請找出價值最高的寶箱，若有多個價值相等，輸出編號最小者。

  • 輸入格式： 第一列有兩個正整數 N, M（1 ≤ N, M ≤ 106）。接著 M 列，每列四個正整數 P, Q, R, S（1 ≤ P, Q ≤ N，R ∈ \{1, 2\}）。
  • 輸出格式： 輸出一列共兩個數字：最高價值寶箱的編號及其價值。

演算法使用解析：【差分陣列與區間倍率維護 (Difference Array & Range Multiplier Maintenance)】

本題涉及區間加法與區間乘法（包含對未來放入硬幣的影響），若直接對每個寶箱進行暴力修改，時間複雜度為 O(N × M)，在 N, M ≤ 106 時會超時。

  • 加法差分 (R=1)： 利用差分陣列技巧，在起點 P 加上 S（add[p] += s），並在終點後一個位置 Q+1 減去 S（add[q+1] -= s）。最後透過前綴和即可還原每個寶箱獲得的總硬幣數 x。
  • 乘法區間 (R=2)： 為了讓區間 [P, Q] 內的硬幣價值乘以 S，且不影響區間外、同時能正確套用到後來才加進去的硬幣，我們可以使用類似差分的技巧維護乘數與除數：在起點 P 乘上 S（multi[p] *= s），並在終點後一個位置 Q+1 除以 S（divi[q+1] *= s，程式中以維護 divi 陣列來抵銷超出範圍的倍率）。
  • 透過依序掃描，利用 base 維護當前位置的累积倍率（base *= multi[i]; base /= divi[i];），結合硬幣數 x，就能在 O(N + M) 時間內高效求出每個寶箱的最終價值。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
5 4
3 5 2 2
1 4 1 2
5 5 2 2
2 5 1 3
  • 步驟 1：依序處理 4 個操作
    • 操作 1 (3 5 2 2)：R=2（乘法），第 3 到 5 個寶箱乘 2。multi[3] *= 2, divi[6] *= 2。
    • 操作 2 (1 4 1 2)：R=1（加法），第 1 到 4 個寶箱加 2 枚硬幣。add[1] += 2, add[5] -= 2。
    • 操作 3 (5 5 2 2)：R=2（乘法），第 5 到 5 個寶箱乘 2。multi[5] *= 2, divi[6] *= 2。
    • 操作 4 (2 5 1 3)：R=1（加法），第 2 到 5 個寶箱加 3 枚硬幣。add[2] += 3, add[6] -= 3。
  • 步驟 2：從 1 到 N 掃描計算每個寶箱的最終價值
    • 寶箱 1：base = 1, x = 2 ⇒ 價值 = 2
    • 寶箱 2：base = 1, x = 5 ⇒ 價值 = 5
    • 寶箱 3：base = 2, x = 5 ⇒ 價值 = 10
    • 寶箱 4：base = 2, x = 5 ⇒ 價值 = 10
    • 寶箱 5：base = 4, x = 3 ⇒ 價值 = 12

👉 輸出範例 1 結果： 5 12（最高價值為 12，位於編號 5 的寶箱）

【輸入範例 2 實際運作推導】

輸入：
6 5
1 6 1 1
2 3 1 2
3 5 2 2
2 2 1 3
4 5 1 2
  • 經過 5 次操作後，各寶箱價值分別計算為：1, 6, 6, 6, 6, 1。
  • 其中最高價值為 6，有多個寶箱符合（編號 2, 3, 4, 5）。依照題目要求「若有數個寶箱價值相等，請輸出編號最小者」，故選擇編號 2。

👉 輸出範例 2 結果： 2 6

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<bits/stdc++.h> // 引入 C++ 標準函式庫

int multi[10000005]={}; // 宣告全域乘法倍率陣列，記錄每個區間起點的乘數
int add[10000005]={};   // 宣告全域加法差分陣列，記錄硬幣數量的差分變化
int divi[10000005]={};  // 宣告全域除法陣列，用來在區間終點後抵銷乘法倍率

int main()
{
    // 初始化 multi 與 divi 陣列的所有元素為 1（因為乘除法預設倍率為 1）
    for(int i=0;i<10000005;i+=1)
    {
        multi[i]=1;
        divi[i]=1;
    }
    
    int N,M; // 宣告寶箱總數 N 與操作次數 M
    scanf("%d%d",&N,&M); // 讀入 N 與 M
    
    for(int i=0;i<M;i+=1) // 迴圈讀入 M 個操作指令
    {
        int p,q,r,s; // p: 起始寶箱編號, q: 結束寶箱編號, r: 操作類型(1或2), s: 數值(硬幣數或倍率)
        scanf("%d%d%d%d",&p,&q,&r,&s); // 讀入四個參數
        
        if(r==1) // 若 r == 1 代表區間加法操作（放入 s 枚硬幣）
        {
            add[p]+=s; // 在起始位置 p 加上 s
            add[q+1]-=s; // 在結束位置的下一個位置 q+1 減去 s（差分陣列維護）
        }
        else if(r==2) // 若 r == 2 代表區間乘法操作（價值變為 s 倍）
        {
            multi[p]*=s; // 在起始位置 p 乘上倍率 s
            divi[q+1]*=s; // 在結束位置的下一個位置 q+1 記錄除數 s，以在區間外恢復原倍率
        }
    }
    
    int big=0,bigind=1; // big 記錄最高價值（初始化為 0），bigind 記錄對應的寶箱編號（預設為 1）
    int base=1,x=0;     // base 記錄當前寶箱的累計倍率，x 記錄當前寶箱的硬幣總數
    
    for(int i=1;i<=N;i+=1) // 從編號 1 到 N 依序走訪每個寶箱
    {
        base*=multi[i]; // 累乘當前位置的倍率
        base/=divi[i];  // 除以超出區間範圍的倍率，精準維護區間乘法
        x+=add[i];      // 透過前綴和累加差分陣列，計算當前寶箱的硬幣總數 x
        
        // 若當前寶箱的總價值 (x * base) 大於目前記錄的最高價值 big
        if(big<x*base)
        {
            big=x*base;   // 更新最高價值
            bigind=i;     // 更新對應的寶箱編號
        }
    }
    
    printf("%d %d\n",bigind,big); // 輸出最高價值的寶箱編號與其對應價值
}
