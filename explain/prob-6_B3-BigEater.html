#6 201903_B3-BigEater (大吃大喝)

PDF: 201903_B3-BigEater(Q).pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： Wayne 想要將身上所有的錢拿來買 32 元的蘋果派和 55 元的大杯玉米濃湯。他的堅持是必須「蘋果派與玉米濃湯交替著吃」，若無法形成交替則停止進食。請寫一個程式列印出他大吃大喝的過程。

  • 輸入格式： 三個整數 N、M、K，以空白隔開。
    • N：總共帶了多少錢（0 ≤ N ≤ 500）
    • M：每隔幾分鐘進食一次（0 < M ≤ 60）
    • K：起始食物種類（K=0 代表從蘋果派開始吃，K=1 代表從玉米濃湯開始）
  • 輸出格式： 依序輸出經過的時間、吃的食物與剩餘金額，或是在一開始無法進食時輸出特定訊息。

演算法使用解析：【迴圈模擬與條件分支邏輯】

本題屬於經典的模擬題（Simulation）。程式核心邏輯包含：

  • 初始條件檢查： 若初始金額小於 32 元，或選擇從玉米濃湯開始 (K=1) 但金額小於 55 元，則無法進行任何消費，直接輸出 Wayne can't eat and drink.。
  • 交替進食迴圈： 利用 while 迴圈模擬時間推進與金錢扣除。透過變數 K 的值（0 或 1）來決定當前該買蘋果派還是玉米濃湯。
  • 狀態切換： 每次成功購買後，金額扣除對應品項價格（32 或 55），印出對應的時間點、食物名稱與剩餘金額文字（注意零錢單複數的英文文法細節：dollar vs dollars vs doesn't have money），並將 K 的值在 0 與 1 之間切換以達到交替效果，同時將時間累加 M 分鐘。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
65 5 0
  • 初始狀態： N = 65（元）, M = 5（分鐘）, K = 0（從蘋果派開始）, time = 0。
  • 迴圈第 1 次：
    • K = 0，檢查 N ≥ 32（65 ≥ 32 成立）。
    • N 扣除 32：65 - 32 = 33。
    • 輸出時間 0：0: Wayne eats an Apple pie,
    • 切換 K = 1。
    • 檢查剩餘金額 N = 33，印出：and now he has 33 dollars.
    • 時間推進：time = 0 + 5 = 5。
  • 迴圈第 2 次：
    • K = 1，檢查 N ≥ 55（33 ≥ 55 不成立！無法買玉米濃湯）。
    • 觸發 break 跳出迴圈。

👉 輸出範例 1 結果：
0: Wayne eats an Apple pie, and now he has 33 dollars.

【輸入範例 2 實際運作推導】

輸入：
143 18 1
  • 初始狀態： N = 143, M = 18, K = 1, time = 0。
  • 迴圈第 1 次 (K = 1)： 143 ≥ 55 成立 → 買玉米濃湯，花費 55 → 剩餘 143 - 55 = 88 → 切換 K = 0。
    輸出：0: Wayne drinks a Corn soup, and now he has 88 dollars.
    time = 0 + 18 = 18。
  • 迴圈第 2 次 (K = 0)： 88 ≥ 32 成立 → 買蘋果派，花費 32 → 剩餘 88 - 32 = 56 → 切換 K = 1。
    輸出：18: Wayne eats an Apple pie, and now he has 56 dollars.
    time = 18 + 18 = 36。
  • 迴圈第 3 次 (K = 1)： 56 ≥ 55 成立 → 買玉米濃湯，花費 55 → 剩餘 56 - 55 = 1 → 切換 K = 0。
    輸出：36: Wayne drinks a Corn soup, and now he has 1 dollar.
    time = 36 + 18 = 54。
  • 迴圈第 4 次 (K = 0)： 1 ≥ 32 不成立 → break 結束。

👉 輸出範例 2 結果：
0: Wayne drinks a Corn soup, and now he has 88 dollars.
18: Wayne eats an Apple pie, and now he has 56 dollars.
36: Wayne drinks a Corn soup, and now he has 1 dollar.

【輸入範例 3 實際運作推導】

輸入：
55 1 1
  • 初始金額 N = 55, K = 1。購買玉米濃湯剛好花完 55 元，剩餘金額為 0。
  • 輸出金額時特別處理 and now he doesn’t have money.。

👉 輸出範例 3 結果：
0: Wayne drinks a Corn soup, and now he doesn’t have money.

【輸入範例 4 實際運作推導】

輸入：
31 10 0
  • 初始金額 N = 31 小於蘋果派價格 32，直接進入初始條件檢查，判定無法進食。

👉 輸出範例 4 結果：
Wayne can’t eat and drink.

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <iostream> // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout

using namespace std;

int main()
{
    int n, m, k; // 宣告三個整數變數：n 代表總金額，m 代表間隔分鐘數，k 代表起始食物種類
    cin >> n >> m >> k; // 依序讀入總金額、間隔時間與起始狀態

    int time = 0, check = 0; // 宣告時間變數 time 初始化為 0，以及檢查旗標 check 初始化為 0
    
    // 檢查初始條件：若總金額小於 32（買不起蘋果派），或者選擇從玉米濃湯開始 (k==1) 但金額小於 55（買不起玉米濃湯）
    if((n < 32) || (k == 1 && n < 55))
    {
        cout << "Wayne can't eat and drink." << endl; // 輸出無法進食的提示訊息
        check = 1; // 將檢查旗標設為 1，代表不需要進入後續的購買迴圈
    }
    
    // 當金額大於等於 0 且 check 等於 0（代表符合進食條件）時，持續進行迴圈模擬
    while(n >= 0 && check == 0)
    {
        if(k == 0) // 若當前輪到吃蘋果派 (k == 0)
        {
            if(n >= 32) // 檢查剩餘金額是否足以支付蘋果派的 32 元
            {
                n -= 32; // 總金額扣除蘋果派價格 32 元
                cout << time << ": Wayne eats an Apple pie, "; // 輸出當前時間與吃了蘋果派的前半句訊息
                k = 1; // 將下一次的食物種類切換為玉米濃湯 (k = 1)
            }
            else break; // 若錢不夠買蘋果派，則跳出迴圈
        }
        else if(k == 1) // 若當前輪到喝玉米濃湯 (k == 1)
        {
            if(n >= 55) // 檢查剩餘金額是否足以支付玉米濃湯的 55 元
            {
                n -= 55; // 總金額扣除玉米濃湯價格 55 元
                cout << time << ": Wayne drinks a Corn soup, "; // 輸出當前時間與喝了玉米濃湯的前半句訊息
                k = 0; // 將下一次的食物種類切換為蘋果派 (k = 0)
            }
            else break; // 若錢不夠買玉米濃湯，則跳出迴圈
        }
        
        // 根據剩餘金額 n 的不同數值，輸出對應的英文單複數剩餘金額描述
        if(n > 1) cout << "and now he has " << n << " dollars." << endl; // 若剩餘金額大於 1 元，使用複數 dollars
        else if(n == 1) cout << "and now he has 1 dollar." << endl; // 若剩餘金額剛好為 1 元，使用單數 dollar
        else if(n == 0) cout << "and now he doesn't have money." << endl; // 若剛好花完沒有錢，輸出特定無錢訊息
        
        time += m; // 每次進食完成後，時間推進 m 分鐘
    }
    return 0; // 程式正常結束
}
