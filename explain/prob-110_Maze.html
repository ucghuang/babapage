一、 題目模型與規則解析

1. 問題定義： 給定一個 N × N 的二維網格空間，最左上角座標 (0, 0) 為起點 S，最右下角座標 (N-1, N-1) 為終點 E。空格以 0 表示，障礙物以 # 表示。

2. 移動限制： 只能朝「東（右）、西（左）、南（下）、北（上）」四個相鄰方向移動，不能走出邊界且不可經過障礙物。

3. 最優化目標： 每移動 1 格耗費 1 單位時間。求從起點至終點的最少單位時間（最短路徑長度）；若被障礙物隔絕無法抵達，則輸出 -1。

4. 圖論抽象化： 本題等價於「無權重無向網格圖（Unweighted Grid Graph）的最短路徑問題」。

二、 演算法理論推導：廣度優先搜尋 (BFS)

在所有相鄰邊權重均為常數 1 的圖形中，廣度優先搜尋 (Breadth-First Search, BFS) 具備以下嚴謹的數學特性：

  • 波前擴散性（Wavefront Expansion）： BFS 按照距離起點的步數（d = 0, 1, 2, …）層層向外搜尋。同一層的所有節點必定比下一層的節點先被走訪。
  • 最短步數保證： 透過先進先出（FIFO）的 std::queue 控制，當終點座標 (N-1, N-1) 第一次出現在隊列前端時，所記錄的步數必定是全域最小值。
  • 造訪標記與無窮迴圈防範： 建立二維距離陣列 dis[N][N]，全部初始化為 -1。
    • dis[r][c] == -1：表示尚未拜訪。
    • dis[r][c] >= 0：表示已拜訪過，且數值即為從起點出發的最短步數，後續到達的分支將被剪枝（Pruning），避免重複走訪。

走訪歷程與距離推導：

  1. 第 1 列障礙物 ####0 封鎖了除了最右側以外的所有下行通道，強迫路徑向東移動到 (0, 4)（耗時 4），再向南到達 (1, 4)（耗時 5）與 (2, 4)（耗時 6）。
  2. 第 3 列障礙物 0#### 封鎖了除了最左側以外的所有下行通道，強迫路徑從 (2, 4) 向西折返直到 (2, 0)（耗時 10）。
  3. 向下走到 (3, 0)（耗時 11）與 (4, 0)（耗時 12）。
  4. 在第 4 列一路向東直達 (4, 4) 終點，總耗時為 16 單位時間。

演算法狀態：第 1 列整列為 ###。佇列在走訪完 (0,0), (0,1), (0,2) 後無任何合法的相鄰格子可推入，queue.empty() == true，觸發 flag == false，輸出 -1。

情況 B：中心單點障礙（輸出 4）

r\c012
0S0→1↓2
10#↓3
200E4

演算法狀態：曼哈頓距離最短走法為 4 步。路徑對稱存在兩條：S → 右 → 右 → 下 → 下 或 S → 下 → 下 → 右 → 右，均能在第 4 層步數抵達終點，輸出 4。

六、 完整 C++ 官方解答原始碼（逐行繁體中文註解）

以下程式碼完整保留官方原始演算法邏輯，針對國中生與演算法初學者加入完整的變數說明與邊界判斷註釋：

#include <cstdio>      // 引入標準 I/O 函式庫 (scanf, printf)
#include <cstring>     // 引入記憶體配置函式庫 (memset)
#include <queue>       // 引入佇列容器 (std::queue) 用於 BFS
#include <utility>     // 引入 pair 結構體 (std::pair)

#define pii pair<int, int>       // 將 pair<int, int> 簡寫為 pii，表示座標 (row, col)
#define mp(a, b) makepair(a, b)  // 快速建立坐標 pair

using namespace std;

const int N = 500 + 5;           // 支援最大地圖維度 (500) 加上安全緩衝區

int dis[N][N];        // 距離陣列：記錄起點到該座標的最少步數，-1 代表尚未走過
char maze[N][N];      // 地圖矩陣：儲存迷宮字元 ('0', '#', 'S', 'E')

int main()
{
    // dh 與 dw 分別代表垂直方向與水平方向的位移向量：{-1:上, 1:下, 0:左, 0:右}
    int n, dh[4] = {-1, 1, 0, 0}, dw[4] = {0, 0, -1, 1};
    bool flag = false;   // 標記是否成功抵達終點
    queue<pii> q;        // 宣告 BFS 擴散隊列

    // 初始化距離陣列全部為 -1
    memset(dis, -1, sizeof(dis));

    // 讀取迷宮維度 n
    if (scanf("%d", &n) != 1) return 0;

    // 逐列讀入地圖字串
    for (int i = 0; i < n; ++i)
    {
        scanf("%s", maze[i]);
    }

    // 設定起點 (0, 0) 距離為 0，並推入搜尋隊列
    dis[0][0] = 0;
    q.push(mp(0, 0));

    // 開始進行廣度優先搜尋 (BFS)
    while (!q.empty())
    {
        pii u = q.front(); q.pop();   // 取出隊列中最前端的節點

        // 檢查當前節點是否已經抵達右下角終點 (n-1, n-1)
        if (u.first == n - 1 && u.second == n - 1)
        {
            printf("%d\n", dis[u.first][u.second]); // 輸出最短步數
            flag = true;
            break;                                  // 最短路徑已確定，結束搜尋
        }

        // 展開相鄰的 4 個方向 (上、下、左、右)
        for (int i = 0; i < 4; ++i)
        {
            int nh = u.first + dh[i];   // 下一個座標的 row
            int nw = u.second + dw[i];  // 下一個座標的 col

            // 邊界條件檢查：
            // 1. 0 <= nh < n 且 0 <= nw < n (不得越出迷宮範圍)
            // 2. maze[nh][nw] != '#' (不得撞入障礙物)
            // 3. dis[nh][nw] == -1 (必須是尚未被造訪過的節點)
            if (0 <= nh && nh < n && 0 <= nw && nw < n && maze[nh][nw] != '#' && dis[nh][nw] == -1)
            {
                dis[nh][nw] = dis[u.first][u.second] + 1; // 記錄距離 = 前一步 + 1
                q.push(mp(nh, nw));                       // 將新座標推入隊列尾端
            }
        }
    }

    // 若搜尋完整個連通分量皆無法抵達終點，則輸出 -1
    if (!flag)
    {
        printf("-1\n");
    }

    return 0;
}

七、 模組化結構與複雜度分析

  • 時間複雜度：O(N2)。迷宮共有 N × N 個格子，每個格子最多只會進出隊列一次，每個狀態常數展開 4 個方向，在 N ≤ 500 時運算次數約 2.5 × 105 次，執行時間遠小於 0.05 秒。
  • 空間複雜度：O(N2)。maze 與 dis 陣列大小為 505 × 505 × 4 Bytes ≈ 1 MB，隊列最多容納約 4N 個節點，符合記憶體嚴格限制。
  • 教學延展思考：
    • 若題目要求印出完整走法座標：可建立 pii parent[N][N] 記錄每格是從哪個座標轉移而來，抵達終點時透過回溯法（Backtracking）印出路徑。
    • 若經過不同格子需要不同體力消耗（帶權重迷宮）：則須由 BFS 升級為戴克斯特拉演算法 (Dijkstra's Algorithm) 或 A* 啟發式搜尋演算法。
