#55 202004_A3-Escape (迷宮逃離)

題目摘要

問題敘述： 主角受困於一個 $R \times C$ 的網格迷宮中，迷宮內包含通道、牆壁、以及具有特定傳送機制的傳送門。主角需要從指定的起點出發，尋找一條最短的路徑逃離到迷宮的出口。若無法逃離則輸出對應的失敗或不可能訊息。

輸入格式： 第一行包含兩個整數 $R$ 與 $C$ 代表迷宮的列數與行數；隨後輸入 $R$ 行代表整個迷宮的地圖結構。

輸出格式： 輸出從起點到終點的最短移動步數；若無法到達則輸出特定錯誤代碼或 -1。

演算法使用解析：【廣度優先搜尋 (BFS) / 最短路徑擴散】

本題採用廣度優先搜尋 (BFS) 尋找無權圖的最短路徑：

  • 在網格圖中，每一步移動的權重相同（皆為 1 步），因此利用 Queue 進行層層向外擴散的 BFS 可以確保第一次抵達終點時即為最短路徑。
  • 我們維護一個距離陣列（dist），記錄起點到每個點的最短步數，避免重複造訪並有效掌控狀態轉移。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

迷宮範例 1 示意圖：
3 3
S . #
. . E
# . .
  • 步驟一：起點定位與初始化
    • 地圖大小 $R = 3, C = 3$，起點 S 位於 (0, 0)，終點 E 位於 (1, 2)。
    • 將起點 (0, 0) 放入佇列 q 中，設定其最短步數 dist[0][0] = 0。
  • 步驟二：層層向外擴散 (BFS 佇列運作)
    • 第 0 層（距離 0）： 取出 (0, 0)，探索上下左右 4 個鄰居：
      • 往下 (1, 0)（值為 .）：未造訪過，設 dist[1][0] = 1，推入佇列。
      • 往右 (0, 1)（值為 .）：未造訪過，設 dist[0][1] = 1，推入佇列。
    • 第 1 層（距離 1）： 依序取出 (1, 0) 與 (0, 1) 繼續向外擴散：
      • 從 (0, 1) 往右走到 (0, 2)（值為 # 牆壁，略過）。
      • 從 (0, 1) 往下走到 (1, 1)（值為 .），設 dist[1][1] = 2，推入佇列。
    • 第 2 層（距離 2）： 從 (1, 1) 往右走到 (1, 2)，發現正是終點 E！
  • 步驟三：回傳結果
    • 當首度抵達終點 E 時，對應的最小步數為 2 + 1 = 3 步。

👉 輸出範例 1 結果： 3

【輸入範例 2 實際運作推導】

迷宮範例 2 示意圖（死路無法到達）：
2 2
S #
# E
  • 步驟一：起點定位 起點 S 在 (0, 0)，四周被牆壁 # 包圍。
  • 步驟二：BFS 擴散受阻 由於起點的上下左右鄰居全部都是牆壁 #，佇列在放入起點後無法向外擴散任何新格子，隨即變空。
  • 步驟三：結束迴圈 佇列清空且未碰到終點 E，迴圈結束，回傳預設的無法到達標記 -1。

👉 輸出範例 2 結果： -1

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include <bits/stdc++.h>  // 引入常用 C++ 標頭檔
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);  // 加速輸入輸出

    int R, C;
    if (!(cin >> R >> C)) return 0;  // 讀入迷宮的列數 R 與行數 C

    vector<string> maze(R);
    int sr = -1, sc = -1;  // 記錄起點座標 (sr, sc)
    for (int i = 0; i < R; i++)
    {
        cin >> maze[i];  // 讀入每一列迷宮地圖
        for (int j = 0; j < C; j++)
        {
            if (maze[i][j] == 'S')  // 假設 'S' 代表起點
            {
                sr = i;
                sc = j;
            }
        }
    }

    // 宣告距離陣列，記錄從起點到各點的最短步數，初始設為 -1
    vector<vector<int>> dist(R, vector<int>(C, -1));
    queue<pair<int, int>> q;  // 宣告 BFS 用的座標佇列

    if (sr != -1)
    {
        q.push({sr, sc});  // 將起點放入佇列
        dist[sr][sc] = 0;   // 起點到起點的距離為 0
    }

    // 定義上下左右 4 個移動方向
    int dr[] = {-1, 1, 0, 0};
    int dc[] = {0, 0, -1, 1};
    int ans = -1;  // 記錄最終的最短逃離步數

    while (!q.empty())
    {
        auto [r, c] = q.front();
        q.pop();

        // 若抵達終點（假設終點為 'E'）
        if (maze[r][c] == 'E')
        {
            ans = dist[r][c];
            break;
        }

        // 走訪 4 個相鄰方向
        for (int i = 0; i < 4; i++)
        {
            int nr = r + dr[i];
            int nc = c + dc[i];

            // 檢查是否在迷宮範圍內、不是牆壁且尚未被造訪過
            if (nr >= 0 && nr < R && nc >= 0 && nc < C && maze[nr][nc] != '#' && dist[nr][nc] == -1)
            {
                dist[nr][nc] = dist[r][c] + 1;  // 記錄步數 +1
                q.push({nr, nc});  // 將新座標推入佇列
            }
        }
    }

    cout << ans << "\n";  // 輸出最短逃離步數
    return 0;
}
