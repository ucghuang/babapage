#84 202010_Knight (騎士走棋)

PDF: 202010_Knight.pdf 開啟題目與原始解法 ↗

題目摘要與圖解

問題敘述： 騎士（Knight）是西洋棋中的棋子，走法為「日」字形。下圖中騎士位於 (4, 3)，打叉記號（✕）代表騎士在一步之內可以跳躍抵達的 8 個合法位置。請寫出程式計算起點到終點的最短步數。

輸入格式： 第一行包含兩個整數 x, y (1 < x, y < 1000)，表示棋盤寬與高。第二、三行分別為起點 (Sx, Sy) 與終點 (Ex, Ey)。原點 (0, 0) 為棋盤左下角。

輸出格式： 輸出從起點到終點的最短步數；若無法抵達則輸出 -1。

8 方向相對位移拆解表：

騎士從中心 (x, y) 移動時，每次必須沿一個軸走 2 格、另一個軸走 1 格：

方向編號 位移 (Δ x, Δ y) 到達坐標（以 (4,3) 為例）
0, 1(+2, +1), (+1, +2)(6, 4), (5, 5)
2, 3(-2, +1), (-1, +2)(2, 4), (3, 5)
4, 5(-2, -1), (-1, -2)(2, 2), (3, 1) (範例終點)
6, 7(+2, -1), (+1, -2)(6, 2), (5, 1)

演算法使用解析：【廣度優先搜尋 (BFS) / 8 方向最短路徑】

本題採用廣度優先搜尋 (BFS) 尋找棋盤中騎士的最短移動步數：

  • 日字跳躍向量化：將 8 種跳躍方向預先定義在常數陣列 delta[8][2]，避免多重巢狀 if-else 判斷。
  • 層級擴散性 (Level-order Traversal)：因為每次走棋邊權重皆為 1，BFS 第一次造訪到終點節點時，當下的步數必定是全域最短步數。
  • 空間防重造訪機制：利用 walked[1000][1000] 布林陣列進行剪枝，凡已入隊的節點即時標記，避免座標被重複搜尋導致超時或無窮迴圈。

課堂黑板板書推導

【輸入範例 1 詳細拆解與 8 方向擴散推導】

輸入：
8 8
4 3
3 1
  • 步驟一：初始化與起點入隊
    • 棋盤大小 8 × 8，起點 (Sx, Sy) = (4, 3)，終點 (Ex, Ey) = (3, 1)。
    • 將起點 (4, 3) 放入佇列 step 中，並標記 walked[4][3] = true。
  • 步驟二：第一層 BFS 擴散
    • 從 (4, 3) 出發，透過 8 種位移量展開： (6, 4), (5, 5), (2, 4), (3, 5), (2, 2), (3, 1), (6, 2), (5, 1)。
    • 其中新座標 (3, 1) 正好與終點 (Ex, Ey) = (3, 1) 吻合！
  • 步驟三：回傳結果
    • 在當前層級 sc = 0 擴散時即發現終點，回傳累計步數 0 + 1 = 1。

👉 輸出範例 1 結果： 1

【輸入範例 2 詳細拆解與 8 方向擴散推導】

輸入：
2 2
0 0
1 1
  • 步驟一：初始化與起點入隊
    • 棋盤大小 2 × 2，起點 (0, 0)，終點 (1, 1)。
    • 將 (0, 0) 放入佇列，標記 walked[0][0] = true。
  • 步驟二：擴散受阻（邊界檢查失敗）
    • 從 (0, 0) 嘗試 8 種日字型移動（最小位移量均至少為 1 與 2 格），所有跳躍後的新座標均超出 2 × 2 棋盤合法範圍（均由 inbound 攔截過濾）。
  • 步驟三：結束並回傳
    • 佇列耗盡，無法推進，最終回傳 -1。

👉 輸出範例 2 結果： -1

參考解答 C++ 程式碼（100% 取自官方解答，逐行繁體中文教學註解）

#include <bits/stdc++.h>  // 引入標準函式庫 (包含 I/O、queue 等)
#define inbound(sx,sy,x,y) ((sx >=0 && sx < x) && (sy >=0 && sy < y))  // 定義巨集：檢查座標 (sx, sy) 是否在 x * y 棋盤範圍內
using namespace std;  // 使用標準命名空間 std

bool walked[1000][1000] = {0};  // 全域二維布林陣列，記錄棋盤上各位置是否已經被造訪過，預設為 false (0)

int delta[8][2]=  // 定義西洋棋馬（Knight）在 8 個方向上的「日」字型位移量
{
    { 2, 1},{ 1, 2},{-2, 1},{-1, 2},  // 4 種方向位移組合
    {-2,-1},{-1,-2},{ 2,-1},{ 1,-2}   // 另外 4 種方向位移組合
};

int bfs(int x,int y,int sx,int sy,int ex,int ey)  // 廣度優先搜尋函數：計算從 (sx, sy) 到 (ex, ey) 的最短步數
{
    int sc = 0;  // 初始化步數計數器 sc 為 0
    queue<pair<int,int> > step;  // 宣告儲存座標 (x, y) 的 queue 佇列
    step.push(makepair(sx,sy));  // 將起點座標放入佇列中
    while(!step.empty())  // 當佇列不為空時，持續進行層級擴散搜尋
    {
        int bc = step.size();  // 記錄當前層級（相同步數）的節點數量
        for(int i=0;i!=bc;++i)  // 走訪當前層級的所有節點
        {
            pair<int,int> cloc = step.front();  // 取得佇列前端的當前位置座標

            walked[cloc.first][cloc.second] = true;  // 標記當前位置為已造訪

            if(cloc.first == ex && cloc.second == ey)  // 檢查當前位置是否已經到達終點 (ex, ey)
                return sc;  // 若到達終點，立即回傳當前累計的最短步數 sc

            for(int d=0;d!=8;++d)  // 展開 8 個「日」字型移動方向
            {
                int nx,ny;  // 宣告下一步的目標座標變數
                nx = cloc.first+delta[d][0];  // 計算下一步的橫向座標
                ny = cloc.second+delta[d][1];  // 計算下一步的縱向座標

                if(inbound(nx,ny,x,y) && !walked[nx][ny])  // 若新座標在棋盤內且尚未被造訪過
                {
                    step.push(makepair(nx,ny));  // 將新座標推入佇列
                    walked[nx][ny] = true;  // 立即標記該新座標為已造訪，避免重複入隊
                }
            }

            step.pop();  // 將已處理完畢的當前節點從佇列前端移除
        }
        sc++;  // 當前層級走訪完畢，步數 +1
    }
    return -1;  // 若佇列耗盡仍未到達終點，表示無法到達，回傳 -1
}

int main()  // 主程式起點
{
    int x,y;  // 宣告棋盤的直行數 x 與橫列數 y
    cin >> x >> y;  // 輸入棋盤大小
    int sx,sy,ex,ey;  // 宣告起點 (sx, sy) 與終點 (ex, ey) 座標
    cin >> sx >> sy;  // 輸入起點座標
    cin >> ex >> ey;  // 輸入終點座標
    try  // 使用 try-catch 區塊捕捉可能的記憶體配置異常
    {
        cout << bfs(x,y,sx,sy,ex,ey) << '\n';  // 呼叫 bfs 計算並輸出最短步數
    }
    catch(badalloc &e)  // 若發生記憶體不足異常
    {
        cout << "allocate failed:" <<e.what() <<'\n';  // 輸出錯誤訊息
        return -1;  // 回傳錯誤碼 -1
    }
    return 0;  // 程式正常結束
}
