#84 202010_Knight (騎士走棋)

PDF: 202010_Knight.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 在西洋棋盤中，馬（Knight）的移動方式是走「日」字型（即橫走兩格再直走一格，或橫走一格再直走兩格，總共 8 種可能的跳躍方向）。給定棋盤大小以及騎士的起始位置與目標位置，請計算騎士要到達目標位置所需的最少移動步數。

輸入格式： 第一行由兩個整數 $x, y$ 構成，表示棋盤的直行數和橫列數；第二行由兩個數字 $S_x$ 與 $S_y$ 構成，表示起點；第三行由兩個數字 $E_x$ 與 $E_y$ 構成，表示終點。(0, 0) 為地圖左下角。

輸出格式： 輸出騎士從起點到終點的最少移動步數，若是不存在路徑，則輸出 -1。

演算法使用解析：【廣度優先搜尋 (BFS) / 8 方向最短路徑】

本題採用廣度優先搜尋 (BFS) 尋找騎士的最短跳躍路徑：

  • 西洋棋盤中的騎士移動擁有 8 個固定的「日」字型方向。由於每次移動的邊權重皆為 1，因此使用 BFS 可以確保第一次碰到目標座標時即為最短步數。
  • 我們維護一個距離陣列（dist）或拜訪狀態紀錄，並利用 8 個方向的偏移量陣列在每次迴圈中計算下一個合法的落點座標。

課堂黑板板書推導

【輸入範例 1 詳細拆解與 8 方向擴散推導】

輸入：
8 8
4 3
3 1
  • 步驟一：起點與終點設定
    • 棋盤大小 $8 \times 8$，起點座標 $(S_x, S_y) = (4, 3)$，終點座標 $(E_x, E_y) = (3, 1)$。
    • 將起點 (4, 3) 放入佇列中，設定其起始距離 dist[4][3] = 0。
  • 步驟二：8 個「日」字型方向擴散 (BFS 佇列運作)
    • 騎士每次跳躍的 8 種偏移量組合為：`(-2, -1), (-2, 1), (-1, -2), (-1, 2), (1, -2), (1, 2), (2, -1), (2, 1)`。
    • 從 (4, 3) 出發，第一步跳躍可以到達 8 個不同的周邊落點。經計算，其中某一方向跳躍一次即可直接抵達終點 (3, 1)。
  • 步驟三：抵達終點回傳結果
    • 首度觸碰到目標終點 (3, 1)，對應的最少移動步數為 1 步。

👉 輸出範例 1 結果： 1

【輸入範例 2 詳細拆解與 8 方向擴散推導】

輸入：
2 2
0 0
1 1
  • 步驟一：起點與終點設定
    • 棋盤大小僅 $2 \times 2$，起點 $(0, 0)$，終點 $(1, 1)$。
    • 將 (0, 0) 放入佇列中，距離設為 0。
  • 步驟二：BFS 擴散受阻
    • 在 $2 \times 2$ 的極小棋盤中，騎士從 (0, 0) 按照「日」字型跳躍的任何落點都會超出邊界範圍，導致佇列無法擴散出任何新格子。
  • 步驟三：結束迴圈
    • 佇列清空且無法抵達終點，回傳題目規定的無路徑標記 -1。

👉 輸出範例 2 結果： -1

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include <bits/stdc++.h>  // 引入常用 C++ 標頭檔
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);  // 加速輸入輸出

    int N, M;
    if (!(cin >> N >> M)) return 0;  // 讀入棋盤的直行數 N 與橫列數 M

    int sr, sc, tr, tc;
    cin >> sr >> sc;  // 讀入騎士起點座標 (sr, sc)
    cin >> tr >> tc;  // 讀入目標終點座標 (tr, tc)

    // 宣告距離陣列，記錄從起點到各點的最短步數，初始設為 -1
    vector<vector<int>> dist(N, vector<int>(M, -1));
    queue<pair<int, int>> q;  // 宣告 BFS 用的座標佇列

    q.push({sr, sc});  // 將起點放入佇列
    dist[sr][sc] = 0;   // 起點到起點的距離設為 0

    // 定義西洋棋馬（Knight）移動的 8 個「日」字型方向偏移量
    int dr[] = {-2, -2, -1, -1, 1, 1, 2, 2};
    int dc[] = {-1, 1, -2, 2, -2, 2, -1, 1};

    int ans = -1;  // 記錄最終的最少步數，若無法到達則維持 -1

    while (!q.empty())
    {
        auto [r, c] = q.front();
        q.pop();

        // 若抵達目標終點
        if (r == tr && c == tc)
        {
            ans = dist[r][sc == sc ? r : r][c];  // 記錄當前最短步數
            ans = dist[r][c];
            break;
        }

        // 走訪 8 個可能的跳躍方向
        for (int i = 0; i < 8; i++)
        {
            int nr = r + dr[i];
            int nc = c + dc[i];

            // 檢查新座標是否在棋盤範圍內且尚未被造訪過
            if (nr >= 0 && nr < N && nc >= 0 && nc < M && dist[nr][nc] == -1)
            {
                dist[nr][nc] = dist[r][c] + 1;  // 記錄步數 +1
                q.push({nr, nc});  // 將新座標推入佇列
            }
        }
    }

    cout << ans << "\n";  // 輸出最少移動步數或 -1
    return 0;
}
