題目摘要

問題敘述： 捷運實施常客優惠多年，三月調整了優惠方案：

  • 每月搭乘捷運 11 至 20 次，現金回饋 5%（即總票價乘以 0.95）。
  • 每月搭乘捷運 21 至 40 次，現金回饋 10%（即總票價乘以 0.90）。
  • 每月搭乘捷運 41 次以上，現金回饋 15%（即總票價乘以 0.85）。
  • 若每月搭乘次數未達 11 次，則無現金回饋。

此外，還有 TPASS 1200 方案，每月搭乘金額 1200 元以上的乘客可以購買 TPASS 更划算。露璐想知道她每個月的交通費，如果常客優惠計算後的交通費超過 1200 元的話她打算購買 TPASS（即交通費上限為 1200 元）。請寫一個程式計算露璐的交通費。

輸入格式： 第一列輸入一個正整數 N (1 ≤ N ≤ 100)，表示露璐一個月的搭車次數。第二列包含 N 個正整數 Xi (20 ≤ Xi ≤ 65)，每個數代表每次搭乘的票價。

輸出格式： 輸出露璐該月的交通費。如果交通費比 1200 便宜，輸出該費用（原始票價扣除現金回饋金額，四捨五入至整數）；否則輸出 1200（即使用 TPASS）。

演算法使用解析：【條件判斷與模擬計算】

本題為基礎的迴圈累加與條件分支應用題：

  • 累加總票價： 使用迴圈讀入搭乘次數 N 以及每次的票價 Xi，將其累加至 amount 變數中。
  • 套用常客優惠： 根據搭乘次數 N 的區間（11~20次、21~40次、41次以上），對 amount 乘以對應的折扣係數（0.95、0.90、0.85）。
  • 比較 TPASS 方案： 判斷計算後的優惠金額是否大於或等於 1200 元。若大於或等於 1200 元則輸出 1200；否則使用 round() 函數將金額四捨五入至整數後輸出。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
12
20 20 25 30 20 15 25 20 35 30 20 20
  • 搭乘次數 N = 12。落在 11 至 20 次區間，享有 5% 現金回饋（乘以 0.95）。
  • 票價加總：20+20+25+30+20+15+25+20+35+30+20+20 = 280元。
  • 折扣後金額：280 × 0.95 = 266元。
  • 金額 266 小於 1200，故無需使用 TPASS。

👉 輸出範例 1 結果： 266

【輸入範例 2 實際運作推導】

輸入：
50
65 65 ... (共50個65)
  • 搭乘次數 N = 50。落在 41 次以上區間，享有 15% 現金回饋（乘以 0.85）。
  • 票價加總：50 × 65 = 3250元。
  • 折扣後金額：3250 × 0.85 = 2762.5元。
  • 金額 2762.5 超過 1200 元，改用 TPASS 方案較划算。

👉 輸出範例 2 結果： 1200

【輸入範例 3 實際運作推導】

10

  • 搭乘次數 N = 10。小於 11 次，無常客優惠（折扣 1.0）。
  • 票價加總：10 × 65 = 650元。
  • 金額 650 小於 1200，故輸出原價。

👉 輸出範例 3 結果： 650

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <iostream> // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout
#include <math.h>   // 引入數學函式庫，以便使用 round 進行四捨五入
using namespace std;

int main()
{
    int n;          // 宣告變數 n 用來儲存每個月搭乘捷運的總次數
    cin >> n;       // 讀入搭乘次數 n
    double amount = 0; // 宣告雙精度浮點數變數 amount 用來累加總票價，初始化為 0
    for (int i = 0; i < n; i++) // 使用迴圈讀入每次搭乘的票價共 n 次
    {   
        int x;      // 宣告變數 x 用來儲存單次搭乘票價
        cin >> x;   // 讀入單次票價
        amount += x; // 將單次票價累加到總金額 amount 中
    }
    
    // 根據搭乘次數套用不同的常客優惠現金回饋方案
    if (n >= 41)    // 若搭乘次數 41 次以上
    {
        amount = amount * 0.85; // 享 15% 現金回饋（乘以 0.85）
    }
    else if (n >= 21) // 若搭乘次數介於 21 至 40 次之間
    {
        amount = amount * 0.9;  // 享 10% 現金回饋（乘以 0.90）
    }
    else if (n >= 11) // 若搭乘次數介於 11 至 20 次之間
    {
        amount = amount * 0.95; // 享 5% 現金回饋（乘以 0.95）
    }
    
    // 判斷是否購買 TPASS 1200 方案
    if (amount >= 1200) // 若優惠後的交通費大於或等於 1200 元
    {
        cout << 1200 << endl; // 購買 TPASS 方案更划算，固定輸出 1200
    }
    else // 若交通費小於 1200 元
    {
        // 將金額四捨五入到整數後輸出
        cout << round(amount) << endl;
    }
    return 0; // 程式正常結束
}
