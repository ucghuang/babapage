#2 201903A2-QueenBee (尋找蜂后)

題目摘要與生活化理解

問題敘述： 科學家發現一種新型蜜蜂，其蜂巢結構為立方體，長、寬、高分別為 L、W、H[cite: 1]。蜂巢被蜂巢壁分割為好幾個小空間（0 代表空間，1 代表蜂巢壁），蜂后住在蜂巢內體積最大（空格數最多）的連通空間中[cite: 1]。請寫一個程式計算蜂巢中的最大空間包含多少格[cite: 1]。

輸入格式： 第一列有三個正整數 L, W, H (1 ≤ L, W, H ≤ 135)；第二列共有 L × W × H 個字元，字元為 '0' 或 '1'，依序代表各層的蜂巢結構[cite: 1]。

輸出格式： 輸出一列整數，代表蜂巢中的最大空間大小[cite: 1]。

🧱 課堂生活比喻（Minecraft 蓋大樓）：
  • '1'（蜂巢壁）： 堅固的黑曜石牆壁，蜜蜂穿不過去，水也流不過去[cite: 1]。
  • '0'（蜜蜂空間）： 空氣方塊，蜜蜂能自由穿梭、築巢的房間[cite: 1]。
  • 蜂后的目標： 找出哪一組「互相打通的空氣方塊」數量最多（最大套房），回傳其總格子數[cite: 1]。

演算法解析：【立體 6 方向擴散與 BFS 連通塊】

本題採用廣度優先搜尋 (BFS) 與三維網格走訪策略[cite: 1]：

  • 二維平面到三維立體的擴展： 平面地圖只有「前後左右」4 個方向；但在立體蜂巢中，蜜蜂還可以向上飛到上一層、向下鑽到下一層，因此每個格子 (H, L, W) 共有 6 個相鄰方向[cite: 1]。
移動方向 高度變化 (movex) 長度變化 (movey) 寬度變化 (movez) 程式陣列對應
向上樓層 / 向下樓層 +1 / -1 0 0 movex[6] = {1, -1, 0, 0, 0, 0}[cite: 1]
向前往後 (深度) 0 +1 / -1 0 movey[6] = {0, 0, 1, -1, 0, 0}[cite: 1]
向左向右 (橫向) 0 0 +1 / -1 movez[6] = {0, 0, 0, 0, 1, -1}[cite: 1]
  • 倒水擴散法（BFS 佇列）：
    1. 從大樓巡邏，遇到第一個沒被走過的 '0' 就倒一桶水，將座標加入佇列（Queue）[cite: 1]。
    2. 水朝 6 個方向擴散[cite: 1]。撞到邊界或 '1' 停住；若是未造訪的 '0' 則繼續漫延，連通大小 now++[cite: 1]。
    3. 水全部流完即量出此連通房間大小，並透過 big = max(big, now) 更新最大空間[cite: 1]。
    4. 標記已造訪（visit=1），避免重複計算[cite: 1]。

參考解答 C++ 程式碼（百分之百保留原始邏輯與變數，每行逐行詳解）

#include<bits/stdc++.h>  // 引入 C++ 標準函式庫所有常用標頭檔 (包含 iostream, vector, queue, algorithm 等)[cite: 1]
using namespace std;    // 使用標準命名空間 std，省去每次呼叫函式都需加上 std:: 的麻煩[cite: 1]

char arr[305][305][305]= {};  // 宣告三維字元陣列 arr[樓層H][長度L][寬度W]，用來儲存整座蜂巢各點的字元 ('0' 為空間，'1' 為蜂巢壁)[cite: 1]
int visit[305][305][305]= {};  // 記錄該座標是否已經被 BFS 正式處理並結算過 (0 代表尚未造訪，1 代表已造訪)[cite: 1]
int enqueue[305][305][305]= {};  // 記錄座標是否已經被加入到隊列 (Queue) 中，防止同一個格子被重複排入佇列造成無窮擴散[cite: 1]
int now=0;  // 累加器變數，用來統計當前發動的這一場 BFS 共擴散了多少格空白空間[cite: 1]
int big=0;  // 全域最大值變數，用來紀錄歷史探索中出現過的「最大連通空間大小」 (即蜂后要住的空間)[cite: 1]

// 定義名為 st 的結構體，用來打包儲存三維空間中的單一座標點 (包含長度 L, 寬度 W, 高度 H)[cite: 1]
struct st
{
    int L,W,H;  // 結構體內部儲存 L(縱向長度), W(橫向寬度), H(垂直高度/樓層) 三個整數值[cite: 1]
};

// 定義 BFS (廣度優先搜尋) 函式，傳入起始座標點 temp 以及地圖的三維上限大小 L, W, H[cite: 1]
void BFS(st temp,int L,int W,int H)
{
    queue<st> next;  // 建立一個存遞 st 座標結構的 FIFO (先進先出) 佇列，命名為 next[cite: 1]
    next.push(temp);  // 將起始擴散點 temp 放進佇列中，作為 BFS 探索的第一步[cite: 1]
    
    while(!next.empty())  // 進入迴圈：只要佇列裡面還有尚未處理擴散的座標，就持續進行走訪[cite: 1]
    {
        st pos=next.front();  // 取出佇列最前端 (最先排隊) 的座標點存入 pos[cite: 1]
        now++;  // 成功取出一個未造訪的空白格，當前連通區塊的大小加 1[cite: 1]
        big=max(big,now);  // 將當前的大小 now 與歷史最大紀錄 big 比較，隨時將較大值更新給 big[cite: 1]
        next.pop();  // 將該座標從佇列最前端彈出移除，避免重複處理[cite: 1]
        
        int x=pos.H, y=pos.L, z=pos.W;  // 解析座標：x 代表高度樓層(H)，y 代表長度直向(L)，z 代表寬度橫向(W)[cite: 1]
        enqueue[x][y][z]=0;  // 該點已正式從隊列取出並處理，將排隊標記歸零[cite: 1]
        visit[x][y][z]=1;  // 將該座標在造訪矩陣 visit 中標記為 1，代表已經完成造訪[cite: 1]
        
        // 定義三維空間 6 個移動方向的高度位移：前兩個代表向上(+1)與向下(-1)樓層，其餘 4 向樓層不變(0)[cite: 1]
        int movex[6]={1,-1,0,0,0,0};
        // 定義 6 個方向的長度(縱向)位移：第三、四個代表向前(+1)與向後(-1)，其餘方向縱向不變(0)[cite: 1]
        int movey[6]={0,0,1,-1,0,0};
        // 定義 6 個方向的寬度(橫向)位移：第五、六個代表向右(+1)與向左(-1)，其餘方向橫向不變(0)[cite: 1]
        int movez[6]={0,0,0,0,1,-1};
        
        // 使用 for 迴圈走訪 0 到 5，依序檢驗這 6 個相鄰相通的方向[cite: 1]
        for(int i=0;i<6;i+=1)
        {
            int nx=x+movex[i];  // 計算新相鄰點的高度座標 (新樓層)[cite: 1]
            int ny=y+movey[i];  // 計算新相鄰點的長度座標 (新縱向位置)[cite: 1]
            int nz=z+movez[i];  // 計算新相鄰點的寬度座標 (新橫向位置)[cite: 1]
            
            // 邊界防護檢查：新座標必須在大樓合法範圍內 (0 <= nx < H, 0 <= ny < L, 0 <= nz < W) 防止陣列越界當機[cite: 1]
            if(nx>=0 && ny>=0 && nz>=0 && nx<H && ny<L && nz<W)
            {
                // 連通與狀態檢查：該相鄰格「沒被造訪過」且「不是蜂巢壁('1')」且「尚未在排隊隊列中」[cite: 1]
                if(!visit[nx][ny][nz] && arr[nx][ny][nz]!='1' && !enqueue[nx][ny][nz])
                {
                    next.push({ny,nz,nx});  // 將合法的相鄰空間座標打包成結構體推入佇列 (對應 L=ny, W=nz, H=nx)[cite: 1]
                    enqueue[nx][ny][nz]=1;  // 立即將該相鄰點標記為已加入排隊隊列，防止其他相鄰格子重複加入[cite: 1]
                }
            }
        }
    }
}

int main()
{
    int L,W,H;  // 宣告三個整數變數，代表蜂巢的長(L)、寬(W)、高(H)[cite: 1]
    scanf("%d%d%d",&L,&W,&H);  // 使用 scanf 快速讀入輸入的第一列三個數值 L, W, H[cite: 1]
    
    // 三層巢狀迴圈：由最底層到最高層 (i 代表高 H)，逐層逐格讀取地圖資訊[cite: 1]
    for(int i=0; i<H; i+=1)
    {
        // 第二層迴圈：遍歷每一層裡由前到後的長度直行 (j 代表長 L)[cite: 1]
        for(int j=0; j<L; j+=1)
        {
            // 第三層迴圈：遍歷每一橫排由左到右的寬度位置 (k 代表寬 W)[cite: 1]
            for(int k=0; k<W; k+=1)
            {
                scanf(" %c",&arr[i][j][k]);  // 讀入每個格子的字元狀態 ('0' 或 '1')，%c 前空一格可自動過濾換行與空格[cite: 1]
            }
        }
    }
    
    // 遍歷整座三維蜂巢的每一格，尋找每一個可能的連通空間出發點[cite: 1]
    for(int i=0; i<H; i+=1)
    {
        // 走訪每一個長度維度[cite: 1]
        for(int j=0; j<L; j+=1)
        {
            // 走訪每一個寬度維度[cite: 1]
            for(int k=0; k<W; k+=1)
            {
                // 判斷條件：如果該格是可通行的空間 ('0')，而且以前從未被水流淹過造訪過 (!visit)[cite: 1]
                if(arr[i][j][k]=='0' && !visit[i][j][k])
                {
                    now=0;  // 找到全新一間未探索的套房，將本次連通格數計數器 now 重設為 0[cite: 1]
                    BFS({j,k,i},L,W,H);  // 以該點座標 {L=j, W=k, H=i} 為起點發動 BFS 倒水擴散並計算套房面積[cite: 1]
                }
            }
        }
    }
    
    printf("%d\n",big);  // 走訪完整棟大樓後，輸出記錄到的最大套房格數 (即蜂后的棲息空間) 並換行[cite: 1]
}
