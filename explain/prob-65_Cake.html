#65 202006Cake (切蛋糕)

PDF: 202006Cake.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 小明擁有一個分成 N 小塊的長方形水果蛋糕，每塊蛋糕有一個喜好度評分 Si（可正、可負、或為零）。小明至多只能挑選連續一段長度不超過 K 小塊的蛋糕來吃（可以完全不拿，總分為 0）。請寫一個程式計算出小明能吃到的蛋糕最高總分為多少分。

輸入格式： 第一行有兩個正整數 N (1 ≤ N ≤ 105) 和 K (1 ≤ K ≤ N)。接下來一行有 N 個整數，依序代表由左至右每一小塊蛋糕的評分 Si（|Si| ≤ 100）。

輸出格式： 請輸出一行整數，表示小明能吃到的蛋糕的最高分，如果完全不拿，輸出 0。

評分說明：

  • 第一組 (20 分)： 1 ≤ N ≤ 102、K=1
  • 第二組 (20 分)： 1 ≤ N ≤ 102
  • 第三組 (10 分)： 1 ≤ N ≤ 3 × 103
  • 第四組 (50 分)： 無特別限制 (N ≤ 105)

演算法使用解析：【前綴和 (Prefix Sum) 與雙向佇列單調佇列 (Monotonic Deque)】

本題要求在長度為 N 的陣列中，尋找長度不超過 K 的連續區段，使其區段總和最大。透過數學轉化與資料結構優化：

  • 前綴和轉換： 令前綴和陣列為 prefix[i] = ∑j=1i S[j]（且 prefix[0] = 0）。則任意區段 [L, R] 的總和可表示為 prefix[R] - prefix[L-1]。
  • 長度限制： 區段長度 R - (L-1) ≤ K ⟹ L-1 ≥ R - K。因此對於右端點 R，左端點前綴和的索引範圍為 [R-K, R-1]。
  • 單調佇列優化： 為了使 prefix[R] - prefix[L-1] 最大化，我們需要在區間 [R-K, R-1] 內找到最小的前綴和。使用雙向佇列（deque）維護一個遞增的單調佇列，時間複雜度可降至 O(N)，完美應對 N = 105 的大規模測資。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
7 3
3 7 -1 9 2 2 1
  • 前綴和計算： prefix = [0, 3, 10, 9, 18, 20, 22, 23]
  • 當視窗大小 K = 3 時，透過單調佇列尋找區段長度 ≤ 3 的最大差值：
    • 選取子區段 [7, -1, 9]，其和為 7 + (-1) + 9 = 15，為所有可能區段中的最大值。

👉 輸出範例 1 結果： 15

【輸入範例 2 實際運作推導】

輸入：
5 4
-3 -4 -5 -6 -7

推導： 所有蛋糕的評分皆為負數，無論拿取哪一段都會使總分減少。根據題目規定「如果完全不拿，輸出 0」。

👉 輸出範例 2 結果： 0

參考解答 C++ 程式碼（含每行詳細中文教學註解）

//cake.cpp
#include<cstdio> // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf
#include<algorithm> // 引入演算法標頭檔，以便使用 max 函式
#include<deque> // 引入雙向佇列 (deque) 標頭檔，用來維護滑動視窗內的最小前綴和
#include<utility> // 引入 pair 工具標頭檔
#define val first // 將 pair 的 first 定義為 val（儲存前綴和數值）
#define pos second // 將 pair 的 second 定義為 pos（儲存前綴和對應的陣列索引位置）
using namespace std; // 使用標準命名空間 std

int main()
{
    int n, k, ans=0, pre=0, v; // 宣告 n（蛋糕塊數）、k（最大拿取塊數）、ans（最高總分，初始化為 0）、pre（前綴和）、v（當前蛋糕評分）
    deque<pair<int, int>> dq; // 宣告雙向佇列 dq，內含 pair<int, int> 分別記錄 (前綴和, 索引位置)
    scanf("%d%d", &n, &k); // 讀入蛋糕總塊數 n 與最大拿取塊數 k
    dq.pushback(makepair(0, 0)); // 初始化佇列，放入前綴和為 0、位置為 0 的基準點
    
    for(int i=1; i<=n; ++i) // 從第 1 塊到第 n 塊蛋糕進行迴圈迭代
    {
        scanf("%d", &v); // 讀入當前第 i 塊蛋糕的評分 v
        pre+=v; // 將當前評分累加到前綴和 pre 中
        
        while(dq.size() && dq.front().pos < i-k) dq.popfront(); // 當佇列不為空且隊首記錄的位置小於當前視窗左界 (i-k) 時，將其彈出（維持視窗長度不大於 k）
        
        ans=max(ans, pre-dq.front().val); // 用「當前前綴和 pre」減去視窗內的最小前綴和（隊首的 val），嘗試更新最高總分 ans
        
        while(dq.size() && dq.back().val > pre) dq.popback(); // 單調性維持：若佇列尾端的前綴和大於當前前綴和 pre，則將其彈出（確保佇列保持遞增順序）
        
        dq.pushback(makepair(pre, i)); // 將當前的前綴和 pre 與其對應位置 i 壓入佇列尾端
    }
    
    printf("%d\n", ans); // 輸出計算得到的最高蛋糕總分
    return 0; // 程式正常結束
}
