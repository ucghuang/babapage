#7 201904_A1-FarmlandIrrigating (農田灌溉)

PDF: 201904_A1-FarmlandIrrigating(Q).pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 農夫引進新型灌溉裝置，電力分為五個等級 (N = 1 ∼ 5)。若電力強度為 N，則可灌溉以自身為中心向左右延伸 (N - 1) 單位的範圍。灌溉裝置可放在道路上任何地方，且所有裝置電力強度必須統一。給定道路長度 L 以及種植作物與否的狀態（0 代表種植作物，1 代表無種植作物），每台灌溉裝置電費公式為：1.32 × N + 1.07，請幫農夫計算灌溉所有農田的最低成本電費以及對應的電力強度（若成本相同，輸出電力強度較大者）。

輸入格式： 第一列有一個正整數 L (1 ≤ L ≤ 5,000,000) 代表道路總長度；第二列共有 L 個字元（0 代表種植作物，1 代表無種植作物）。

輸出格式： 輸出一列共兩個數字，分別為最低電費（至小數點後兩位）與對應的電力強度 N，中間以空白隔開。

演算法使用解析：【貪心法 (Greedy) 與窮舉搜尋】

本題採用貪心策略與迴圈窮舉：

  • 由於電力強度 N 的範圍非常固定且很小（僅有 1 到 5 種等級），我們可以將每一種電力強度分別進行模擬計算。
  • 對每一個固定的電力強度 N，其有效覆蓋範圍（range）固定為 2N - 1。我們從左到右掃描道路，遇到需要灌溉的作物（字元 '0'）時，就放置一台灌溉裝置，並直接將指針向右跳過該裝置的最大灌溉距離，藉此計算出最少需要幾台裝置。
  • 最後計算出總電費，並在所有電力等級中挑選出花費最低的方案（若金額相同則選電力強度較大者）。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
8
00011110
  • 道路總長度： L = 8，農田狀態為 00011110（索引 0~2 及 7 需要灌溉，3~6 無需灌溉）。
  • 分別測試 5 種電力強度 N：
    • N = 1 (範圍 = 1)： 需要 5 台裝置，總成本高。
    • N = 2 (範圍 = 2 × 2 - 1 = 3)：
      • 從左掃描，在索引 0 放置第一台（涵蓋 0~2），接著跳到索引 3，遇到 '1' 略過，直到索引 7 放置第二台。總共需要 2 台裝置。
      • 單台成本：1.32 × 2 + 1.07 = 3.71。總成本：3.71 × 2 = 7.42。
    • N = 3, 4, 5： 分別計算出對應的裝置數量與總電費。
  • 經比較後，最小電費為 7.42，對應的電力強度為 2。

👉 輸出範例 1 結果： 7.42 2

【輸入範例 2 實際運作推導】

輸入：
9
001011100
  • 道路總長度： L = 9，農田狀態為 001011100。
  • 依序測試 N = 1 ∼ 5，計算各電力強度下的最少裝置數與總電費。
  • 當 N = 5 時，計算出的總電費最低為 7.67。

👉 輸出範例 2 結果： 7.67 5

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<bits/stdc++.h>  // 引入常用 C++ 標頭檔
const int sizes=10000005;  // 定義陣列最大容量常數
char farm[sizes]={};  // 宣告全域字元陣列 farm，用來儲存農田道路的作物狀態 ('0' 或 '1')
int main()
{
    int L;  // 宣告變數 L 代表道路總長度
    scanf("%d",&L);  // 讀入道路長度 L
    for(int i=0;i<L;i+=1)
    {
        scanf(" %c",&farm[i]);  // 迴圈依序讀入每個位置的農田狀態（前面加空格以略過換行字元）
    }
    double large=99999999;  // 初始化最低總電費為一個極大值，以便後續尋找最小值
    int ind=-1;  // 初始化記錄最佳電力強度的變數
    
    // 題目規定電力分五個等級，從 1 到 5 逐一窮舉測試
    for(int i=1;i<=5;i+=1)
    {
        int range=i*2-1;  // 當電力強度為 i 時，可灌溉的總範圍大小為 (2 * i - 1)
        int num=0;  // 記錄在當前電力強度下，總共需要幾台灌溉裝置
        
        // 從頭到尾掃描整條道路
        for(int j=0;j<L;j+=range)
        {
            // 當遇到不需要灌溉的土地 ('1') 且尚未超出道路範圍時，指針往右移動跳過
            while(farm[j]=='1' && j<L)
            {
                j++;
            }
            num+=(j<L);  // 若尚未超過邊界且遇到需要灌溉的農田 ('0')，則代表需要放置一台裝置，裝置數 +1
        }
        
        double money=(1.32*i+1.07)*num;  // 根據題目公式計算當前電力強度的總電費 = 單台電費 * 裝置總數
        
        // 若當前計算出的電費小於或等於目前記錄的最低電費（題目要求金額相同時輸出電力強度較大者，故使用 >=）
        if(large>=money)
        {
            large=money;  // 更新最低電費
            ind=i;  // 更新最佳電力強度
        }
    }
    
    printf("%.2f %d\n",large,ind);  // 輸出最低電費（四捨五入至小數點後兩位）與對應的電力強度
}
