#216 202308-OFFLINETreasure (搜集寶藏)

題目摘要

問題敘述： 遊戲中控制角色通過一個 N × M 的網格區域，從左上角進入，從右下角離開。只能向下或向右移動，總步數固定為 (N + M - 2) 步。每個格子內有不定數量的寶藏，請計算通過並獲取最大量寶藏的最佳路徑。

輸入格式： 第一列輸入兩個正整數 N 和 M (1 ≤ N, M ≤ 2000)。接下來有 N 列，每列有 M 個非負整數 X (0 ≤ X ≤ 1000) 表示該格的寶藏數量。

輸出格式： 輸出一個數字，表示成功離開時能獲取的最大寶藏總量。

演算法使用解析：【動態規劃 (DP) / 網格路徑最大權重和】

本題採用經典的二維動態規劃 (2D DP) 解決網格最大路徑和問題：

  • 狀態定義：令 v[i][j] 表示從起點 (0, 0) 移動到格子 (i, j) 所能收集到的最大寶藏總量。
  • 狀態轉移方程：因為只能從上方 (i-1, j) 或左方 (i, j-1) 移動到當前格子 (i, j)，所以轉移方程為： $v[i][j] = v[i][j] + max(v[i-1][j], v[i][j-1])$
  • 邊界條件：
    • 第一欄（j = 0）只能由上方累積下來：v[i][0] += v[i-1][0]。
    • 第一列（i = 0）只能由左方累積下來：v[0][j] += v[0][j-1]。

課堂黑板板書推導

【輸入範例 2 詳細拆解 (2 × 2 網格)】

輸入：
2 2
1 2
8 9
  • 步驟一：初始化第一列與第一欄
    • v[0][0] = 1
    • v[0][1] = v[0][0] + 2 = 1 + 2 = 3（第一列只能從左到右）
    • v[1][0] = v[0][0] + 8 = 1 + 8 = 9（第一欄只能從上到下）
  • 步驟二：計算右下角終點 v[1][1]
    • v[1][1] = v[1][1] + max(v[1][0], v[0][1]) = 9 + max(9, 3) = 9 + 9 = 18。

👉 輸出範例 2 結果： 18

參考解答 C++ 程式碼（100% 取自官方解答，逐行繁體中文教學註解）

#include <iostream>   // 引入 C++ 標準輸入輸出串流函式庫 (如 cin, cout, endl)
#include <vector>     // 引入 C++ 動態陣列容器 (vector) 函式庫
using namespace std;  // 使用標準命名空間 std

int main()            // 主程式起點
{
	cin.syncwithstdio(0);  // 解除 C 與 C++ 的 I/O 同步，加速輸入輸出
	cin.tie(0);              // 解除 cin 與 cout 的繫結，進一步提升執行效能
	
	int n, m;                // 宣告整數 n 與 m，分別代表網格的列數與行數
	cin >> n >> m;           // 輸入 n 與 m
	
	vector<vector<int>> v(n, vector<int>(m));  // 宣告大小為 n x m 的二維向量 v，用來儲存每個格子的寶藏數量
	for(int i = 0; i < n; ++i)                // 迴圈讀入每一列
	{
		for(int j= 0; j < m; ++j)             // 迴圈讀入每一行
		{
			cin >> v[i][j];                   // 輸入格子 (i, j) 的寶藏數量
		}
	}
	
	for(int i = 1; i < n; ++i)                // 初始化第一欄 (j = 0)：只能從上方走下來
	{
		v[i][0] += v[i-1][0];                 // 當前格子的最大寶藏量 = 上方格子的累積寶藏量 + 當前格子寶藏量
	}

	for(int j = 1; j < m; ++j)                // 初始化第一列 (i = 0)：只能從左方走過來
	{
		v[0][j] += v[0][j-1];                 // 當前格子的最大寶藏量 = 左方格子的累積寶藏量 + 當前格子寶藏量
	}

	for(int i = 1; i < n; ++i)                // 巢狀迴圈遍歷其餘內部格子 (從第二列、第二行開始)
	{
		for(int j= 1; j < m; ++j)
		{
			// 狀態轉移方程：到達當前格子 (i, j) 的最大寶藏量 = 從左方過來 v[i][j-1] 或從上方過來 v[i-1][j] 的最大值 + 當前格子寶藏量
			v[i][j] += max(v[i][j-1], v[i-1][j]); 
		}
	}

	cout << v[n-1][m-1] << endl;              // 輸出到達右下角終點 (n-1, m-1) 時所能獲取的最大寶藏量
	return 0;                                 // 程式正常結束
}
