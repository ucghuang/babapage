題目摘要

問題敘述： 給定一條長度為 L 的道路和長度為 1, 2, 3, …, L 的磁磚各無限個，請問將道路用磁磚鋪滿共有幾種不同的鋪法？答案需對 109 + 7 取餘數。

  • 輸入格式： 第一列有一個正整數 T（1 ≤ T ≤ 104），代表有 T 條路要鋪。接著 T 列每列有一個正整數 L（1 ≤ L ≤ 109），為道路的長度。
  • 輸出格式： 對每筆資料輸出一個正整數，為鋪法總數除以 109 + 7 後的餘數。

演算法使用解析：【遞迴規律推導、前綴和優化與快速冪模運算】

本題在教學分類上歸納為「前綴和」與「教學範例」（難度評級：2 星 ★★☆☆☆）。我們可以透過以下五個步驟的嚴謹推導來掌握其核心思路：

  • 步驟一：定義狀態與基本情形
    設 f(L) 代表長度為 L 的道路鋪滿各種長度磁磚的總方法數[cite: 1]。當道路長度 L = 0 時，代表不需要鋪設，唯一的方法就是「什麼都不放」，因此規定基準值 f(0) = 1。當 L = 1 時，只能放一張長度為 1 的磁磚，故 f(1) = 1。
  • 步驟二：建立動態規劃狀態轉移方程式
    當我們要鋪設長度為 L 的道路時，可以從「最後一塊放的磁磚長度 k」切入思考（1 ≤ k ≤ L）[cite: 1]。當決定最後一塊磁磚長度為 k 後，前面剩下的道路長度就會是 L - k。透過將所有可能的 k 累加起來，得到遞迴關係式[cite: 1]：
    f(L) = f(L-1) + f(L-2) + f(L-3) + ... + f(1) + f(0)
  • 步驟三：實際代入小數值觀察規律
    • L = 1 ⟹ f(1) = f(0) = 1
    • L = 2 ⟹ f(2) = f(1) + f(0) = 1 + 1 = 2
    • L = 3 ⟹ f(3) = f(2) + f(1) + f(0) = 2 + 1 + 1 = 4
    • L = 4 ⟹ f(4) = f(3) + f(2) + f(1) + f(0) = 4 + 2 + 1 + 1 = 8
    觀察結果 1, 2, 4, 8 … 可以發現這是一個以 2 為底數的等比成長規律。
  • 步驟四：利用前綴和觀念進行代數化簡
    為了避免 O(L2) 的重複累加，我們觀察 f(L) 與 f(L-1) 的展開式：
    f(L) = f(L-1) + f(L-2) + f(L-3) + … + f(0) (f(L-1))
    由於後面那一整串相加剛好就是 f(L-1) 本身[cite: 1]，因此可以將式子化簡為：
    f(L) = f(L-1) + f(L-1) = 2 * f(L-1)
  • 步驟五：推導一般項公式與快速冪應用
    透過遞迴展開 f(L) = 2f(L-1)，最終可推導出封閉形式的數學解：f(L) = 2^(L-1)[cite: 1]。
    因為題目給定的道路長度 L 高達 109[cite: 1]，若直接用迴圈乘會超時，因此必須結合快速冪（Binary Exponentiation）演算法，在 O(log N) 時間內完成 2L-1 bmod (109+7) 的計算[cite: 1]。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<bits/stdc++.h> // 引入常用標準函式庫

const long long MOD = 1e9 + 7; // 定義題目要求的模數 109 + 7，避免整數溢位

// 定義遞迴加快速冪函式 mod(a)，用來計算 2a 對 MOD 取餘數的結果 (對應前綴和化簡後的公式 2^(L-1))
long long mod(long long a)
{
    if(a == 0) return 1; // 遞迴終止條件：任何數的 0 次方為 1 (即 20 = 1)
    else if(a == 1) return 2; // 基本條件：2 的 1 次方為 2
    else if(a % 2 == 0) // 若指數 a 為偶數，利用分治法：2a = (2^(a/2)) * (2^(a/2))
    {
        long long x = mod(a / 2); // 遞迴計算一半指數的結果
        return (x * x) % MOD; // 將兩半相乘並直接取模，防範數值過大
    }
    else return (mod(a - 1) * mod(1)) % MOD; // 若指數 a 為奇數，拆成 2^(a-1) * 21 再進行運算
}

int main()
{
    int a; // 宣告變數 a 用來儲存測資的總筆數 T
    scanf("%d", &a); // 讀入測資筆數
    
    while(a--) // 當還有測資時持續迴圈
    {
        long long x; // 宣告長整數 x 用來儲存道路長度 L（數值可達 109）
        scanf("%lld", &x); // 讀入道路長度 L
        
        // 根據前綴和遞迴化簡公式 f(L) = 2^(L-1)，呼叫 mod 函式計算 2^(x-1) % (109 + 7)
        printf("%lld\n", mod(x - 1)); // 輸出最終答案並換行
    }
}
