題目摘要

問題敘述： 給定一條長度為 $L$ 的道路和長度為 $1, 2, 3, \dots, L$ 的磁磚各無限個，請問將道路用磁磚鋪滿共有幾種不同的鋪法？答案需對 $10^9 + 7$ 取餘數。

  • 輸入格式： 第一列有一個正整數 $T$（$1 \le T \le 10^4$），代表有 $T$ 條路要鋪。接著 $T$ 列每列有一個正整數 $L$（$1 \le L \le 10^9$），為道路的長度。
  • 輸出格式： 對每筆資料輸出一個正整數，為鋪法總數除以 $10^9 + 7$ 後的餘數。

演算法使用解析：【遞迴規律推導、前綴和優化與快速冪模運算】

本題在教學分類上歸納為「前綴和」與「教學範例」（難度評級：2 星 ★★☆☆☆）。我們可以透過嚴謹的前綴和狀態轉移與遞迴化簡來掌握其核心思路：

  • 從動態規劃與前綴和出發的思路：
    • 若設 $f(L)$ 為長度為 $L$ 的道路鋪法總數。當我們考慮最後一塊放的磁磚長度為 $k$（$1 \le k \le L$），則前面的長度為 $L-k$，因此可以得到遞迴式：$f(L) = \sum_{k=1}^{L} f(L-k) = f(L-1) + f(L-2) + \dots + f(0)$。
    • 如果利用「前綴和」的概念來優化觀看這個累加過程：不難發現 $f(L-1) = \sum_{k=1}^{L-1} f(L-1-k)$。將兩式相減或遞推展開會發現 $f(L) = 2f(L-1)$。
    • 透過這樣的遞迴關係，我們能迅速推導出封閉形式的數學解：$f(L) = 2^{L-1}$。
  • 超大範圍處理與快速冪： 題目給定的道路長度 $L$ 高達 $10^9$，若直接用迴圈乘 $L-1$ 次會超時。因此必須結合快速冪（Binary Exponentiation）演算法，在 $O(\log N)$ 時間內完成 $2^{L-1} \bmod (10^9+7)$ 的計算，完美兼顧時間效能與取模正確性。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<bits/stdc++.h> // 引入常用標準函式庫

const long long MOD = 1e9 + 7; // 定義題目要求的模數 10^9 + 7，避免整數溢位

// 定義遞迴加快速冪函式 mod(a)，用來計算 2^a 對 MOD 取餘數的結果 (對應前綴和化簡後的公式 2^(L-1))
long long mod(long long a)
{
    if(a == 0) return 1; // 遞迴終止條件：任何數的 0 次方為 1 (即 2^0 = 1)
    else if(a == 1) return 2; // 基本條件：2 的 1 次方為 2
    else if(a % 2 == 0) // 若指數 a 為偶數，利用分治法：2^a = (2^(a/2)) * (2^(a/2))
    {
        long long x = mod(a / 2); // 遞迴計算一半指數的結果
        return (x * x) % MOD; // 將兩半相乘並直接取模，防範數值過大
    }
    else return (mod(a - 1) * mod(1)) % MOD; // 若指數 a 為奇數，拆成 2^(a-1) * 2^1 再進行運算
}

int main()
{
    int a; // 宣告變數 a 用來儲存測資的總筆數 T
    scanf("%d", &a); // 讀入測資筆數
    
    while(a--) // 當還有測資時持續迴圈
    {
        long long x; // 宣告長整數 x 用來儲存道路長度 L（數值可達 10^9）
        scanf("%lld", &x); // 讀入道路長度 L
        
        // 根據前綴和遞迴化簡公式 f(L) = 2^(L-1)，呼叫 mod 函式計算 2^(x-1) % (10^9 + 7)
        printf("%lld\n", mod(x - 1)); // 輸出最終答案並換行
    }
}
