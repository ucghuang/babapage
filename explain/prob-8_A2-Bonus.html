#8 201904_A2-Bonus (獎金關卡)

題目摘要

問題敘述： 遊戲桌上有排成一列的 $N$ 個按鈕，每個按鈕上有對應的積分。當按下其中一個按鈕時，可獲得等同該按鈕數字的積分，但會使其左右兩邊的相鄰按鈕失效。遊戲結束後獲得總獎金為所按按鈕的積分總和。請計算參賽者最多可以得到多少獎金（此題即為著名的「不相鄰子序列最大和 / House Robber」變形）。

輸入格式： 第一列有一個正整數 $N$ ($3 \le N \le 10^6$)，代表按鈕總數；第二列共有 $N$ 個正整數，代表每個按鈕上的積分（不超過 99），以空白隔開。

輸出格式： 輸出一列共一個數字，代表參賽者可以取得的最高獎金。

演算法使用解析：【動態規劃 (DP)】

本題採用動態規劃 (Dynamic Programming)：

  • 由於按下某個按鈕會使左右兩側失效，因此我們不能選擇相鄰的按鈕。這與「不能搶劫相鄰房屋」的經典 DP 問題完全相同。
  • 狀態轉移方程式： 設 $DP[i]$ 代表考慮前 $i$ 個按鈕且必選第 $i$ 個按鈕時能獲得的最大累計積分。則到達第 $i$ 個按鈕時，我們只能從 $i-2$ 或 $i-3$ 的狀態轉移過來（因為選了 $i$ 會使 $i-1$ 失效）： $$DP[i] = \max(DP[i-2], DP[i-3]) + arr[i]$$
  • 最後的答案為 $\max(DP[N-1], DP[N-2])$，代表最佳選擇可能落在倒數第一個或倒數第二個按鈕。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
6
1 2 3 4 5 6
  • 按鈕陣列： $arr = [1, 2, 3, 4, 5, 6]$，$N = 6$。
  • 逐步計算 DP 狀態：
    • $DP[0] = arr[0] = 1$
    • $DP[1] = arr[1] = 2$
    • $DP[2] = arr[0] + arr[2] = 1 + 3 = 4$
    • $DP[3] = \max(DP[1], DP[0]) + arr[3] = \max(2, 1) + 4 = 6$
    • $DP[4] = \max(DP[2], DP[1]) + arr[4] = \max(4, 2) + 5 = 9$
    • $DP[5] = \max(DP[3], DP[2]) + arr[5] = \max(6, 4) + 6 = \mathbf{12}$
  • 取最大值： $\max(DP[5], DP[4]) = \max(12, 9) = 12$。

👉 輸出範例 1 結果： 12

【輸入範例 2 實際運作推導】

輸入：
5
2 1 2 5 2
  • 按鈕陣列： $arr = [2, 1, 2, 5, 2]$，$N = 5$。
  • 逐步計算 DP 狀態：
    • $DP[0] = 2$
    • $DP[1] = 1$
    • $DP[2] = arr[0] + arr[2] = 2 + 2 = 4$
    • $DP[3] = \max(DP[1], DP[0]) + arr[3] = \max(1, 2) + 5 = 7$
    • $DP[4] = \max(DP[2], DP[1]) + arr[4] = \max(4, 1) + 2 = 6$
  • 取最大值： $\max(DP[4], DP[3]) = \max(6, 7) = 7$。

👉 輸出範例 2 結果： 7

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<bits/stdc++.h>  // 引入常用 C++ 標頭檔
int arr[1000005]={};  // 宣告全域陣列 arr，用來儲存每個按鈕上的積分
int DP[1000005]={};  // 宣告 DP 陣列，DP[i] 代表在第 i 個按鈕為結尾時能取得的最高累積積分
using namespace std;
int main()
{
    int N;  // 宣告變數 N 代表按鈕總數
    scanf("%d",&N);  // 讀入按鈕總數 N
    for(int i=0;i<N;i+=1)
    {
        scanf("%d",&arr[i]);  // 迴圈讀入每個按鈕的積分值
        
        // 動態規劃基礎狀態與轉移方程式初始化
        if(i<2) DP[i]=arr[i];  // 前兩個按鈕無法被隔開，直接對應其本身積分
        else if(i==2) DP[i]=arr[0]+arr[2];  // 第三個按鈕可以與第一個按鈕相加（中間的第二個按鈕會失效）
        else DP[i]=max(DP[i-2]+arr[i],DP[i-3]+arr[i]);  // 超過三個按鈕時，狀態轉移自前兩格或前三格的最佳解加上當前按鈕積分
    }
    printf("%d\n",max(DP[N-1],DP[N-2]));  // 輸出最後一格或倒數第二格的最大累積積分作為最高獎金
}
