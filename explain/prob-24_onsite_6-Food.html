題目摘要

問題敘述： 為了幫助挑食的小胖建立均衡飲食觀念，需要製作一個過濾器來分類現有的食物。給定 $N$ 個食物名稱與對應的種類，以及最後要搜尋的目標種類 $C$，請找出所有屬於該種類的食物名稱，並依照字典順序（由小到大）輸出。

輸入格式： 第一行有一個正整數 $N$ ($1 \le N \le 50$) 代表食物個數；接下來 $N$ 行，每行各有兩個字串 $F$ 與 $S$，分別代表食物名稱與種類；最後一行有一字串 $C$ 代表要搜尋的食物種類（字串長度均不超過 15 個字元且不含空格）。

輸出格式： 按照字典順序（由小到大）輸出屬於搜尋種類的食物名稱。若無該搜尋種類的食物則輸出 No。

演算法使用解析：【字串處理與氣泡排序法】

本題採用字串比對與基本排序策略：

  • 透過迴圈讀入所有食物的名稱與種類，並將最後查詢的種類存入變數中。
  • 走訪所有記錄，利用 strcmp 比對食物種類是否與目標種類 $C$ 相同；若相符，則將該食物名稱複製到答案陣列中。
  • 若沒有找到任何符合的食物，直接輸出 No；若有找到，則使用雙層迴圈配合 strcmp 進行字串的氣泡排序（Dictionary Order），確保輸出時由小到大排列。

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<stdio.h>  // 引入標準輸入輸出標頭檔
#include<string.h>  // 引入字串處理標頭檔，以便使用 strcmp 與 strcpy

int main()
{
    int N=0;  // 宣告變數 N 代表現有的食物個數
    scanf("%d",&N);  // 讀入食物總數 N
    char food[51][16]= {};  // 宣告二維字元陣列儲存食物名稱
    char sort[51][16]= {};  // 宣告二維字元陣列儲存食物種類
    for(int i=0; i<N; i++)
    {
        scanf("%s %s",food[i],sort[i]);  // 迴圈依序讀入每個食物的名稱與對應種類
    }

    char chose[16]= {};  // 宣告字元陣列儲存欲搜尋的目標種類
    scanf("%s",chose);  // 讀入要搜尋的種類 C

    char ans[51][16]= {};  // 宣告儲存符合條件的食物名稱陣列
    int count = 0;  // 記錄符合條件的食物數量
    bool search = false;  // 旗標變數，記錄是否有找到符合的食物
    for(int i=0; i<N; i++)
    {
        // 檢查當前食物的種類是否與目標種類相同
        if(strcmp(chose,sort[i])==0)
        {
            strcpy(ans[count],food[i]);  // 若相符，將食物名稱複製到答案陣列中
            count += 1;  // 符合數量加 1
            search = true;  // 標記已找到符合項目
        }
    }

    if(search == false)
        printf("No\n");  // 若完全沒找到符合的食物，輸出 No
    else
    {
        // 若有找到，使用氣泡排序法將符合的食物名稱依照字典順序（由小到大）排序
        for(int i=0; i<count; i++)
        {
            for(int j=i+1; j<count; j++)
            {
                // 若前面的字串大於後面的字串（字典序大於0），則進行交換
                if(strcmp(ans[i],ans[j])>0)
                {
                    char tmp[16]= {};  // 宣告暫存字串
                    strcpy(tmp,ans[i]);  // 將 ans[i] 暫存

                    for(int k=0; k<strlen(ans[i]); k++)
                    {
                        ans[i][k]='\0';  // 清空 ans[i]
                    }
                    strcpy(ans[i],ans[j]);  // 將 ans[j] 複製到 ans[i]

                    for(int k=0; k<strlen(ans[j]); k++)
                    {
                        ans[j][k]='\0';  // 清空 ans[j]
                    }
                    strcpy(ans[j],tmp);  // 將暫存的 tmp 複製到 ans[j]
                }
            }
        }
        // 依序輸出排序好的食物名稱
        for(int i=0; i<count; i++)
        {
            printf("%s\n",ans[i]);
        }
    }
}
