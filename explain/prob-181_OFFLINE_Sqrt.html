題目摘要與幾何規則

問題敘述：小光在玩數學遊戲，當中有一個「平方根魔法」，畫面會呈現由 * 字元構成的根號特效。圖形依序由四個幾何線段構成：「短邊 → 左斜邊 → 右斜邊 → 長邊」：

  • (1) 長邊：頂部水平線，星號數量是短邊的兩倍（長度 2K）。
  • (2) 右斜邊：往右上揚升至頂端，星號數量與短邊相同（長度 K）。
  • (3) 短邊高度與奇偶數對齊規則：
    • 短邊固定為水平線，長度為 K。
    • 當 K 為奇數時：短邊水平高度剛好切齊「右斜邊線段之中點」。短邊起始列為 \lfloor K / 2 \rfloor。
    • 當 K 為偶數時：因幾何中心無法整除對齊，短邊高度稍微下降（列座標增加 1，即起始列為 K / 2），以維持視覺協調美觀。

輸入格式：整數 K (3 ≤ K ≤ 500)，代表根號的短邊長。

輸出格式：依據規則使用 * 與空格輸出繪圖後的字元矩陣。

演算法解析：【二維畫布模擬與向量步進】

本題屬於經典的二維字元畫布 (2D Canvas) 狀態機軌跡模擬題：

  • 畫布邊界計算：圖形垂直高度固定為 K 列（列索引為 0 ∼ K-1），最頂部的長邊固定落在第 0 列。矩陣總寬度經推導為 W = 4K + \lfloor \frac{K+1}{2} \rfloor - 3。
  • 向量方向控制：定義方向偏移向量 dir[4][2] = {{0,1}, {1,1}, {-1,1}}：
    • 0 (水平向右)：Δ x = 0, Δ y = +1
    • 1 (右下斜行)：Δ x = +1, Δ y = +1
    • 2 (右上斜行)：Δ x = -1, Δ y = +1
  • 模組化繪圖流程：
    1. 起點定位：初始座標設為 (x, y) = (\lfloor K/2 \rfloor, 0)，方向為向右。
    2. 繪製短邊：呼叫 drawhorizon 走 K-1 步填入 *，接著切換方向至右下。
    3. 繪製 V 型底與右斜邊：呼叫 drawv。左斜邊走偶數步 (K/2 - 1) 或奇數步 (\lfloor K/2 \rfloor) 觸底，切換方向為右上，再走 K-1 步抵達頂端第 0 列。
    4. 繪製頂部長邊：向右走 2K 步完成長邊，隨後依高度 K 與寬度 W 依序印出。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <stdio.h> // 引入標準輸入輸出標頭檔

char area[501][2501] = {}; // 宣告 2D 畫布，支援題目測資上限 K <= 500
// 定義方向向量：0 代表水平向右 (0, 1)，1 代表右下 (1, 1)，2 代表右上 (-1, 1)
int dir[4][2] = {{0, 1}, {1, 1}, {-1, 1}};

// 繪製水平線段的模組函式
void drawhorizon(int *x, int *y, int *way, int len)
{
    // 移動 len - 1 步，沿途留存 '*' 字元
    for(int i = 0; i < len - 1; ++i)
    {
        area[*x][*y] = '*';
        *x += dir[*way][0];
        *y += dir[*way][1];
    }
    *way = 1; // 短邊畫完後，轉向右下 (方向 1) 繪製左斜邊
}

// 繪製 V 型底端與揚升右斜邊的模組函式
void drawv(int *x, int *y, int *way, int len)
{
    // 依據短邊長度的奇偶性，調整向下深入的步數以符合幾何對齊需求
    if(len % 2 == 0) // 偶數情況：下探步數稍微減少 1 步
    {
        for(int i = 0; i < len / 2 - 1; ++i)
        {
            area[*x][*y] = '*';
            *x += dir[*way][0];
            *y += dir[*way][1];
        }
        *way = 2; // 抵達谷底，轉向右上 (方向 2)
    }
    else // 奇數情況：下探 len / 2 步恰好可切齊右斜邊中心
    {
        for(int i = 0; i < len / 2; ++i)
        {
            area[*x][*y] = '*';
            *x += dir[*way][0];
            *y += dir[*way][1];
        }
        *way = 2; // 抵達谷底，轉向右上 (方向 2)
    }

    // 右斜邊往右上揚升 len - 1 步直達頂端第 0 列
    for(int i = 0; i < len - 1; ++i)
    {
        area[*x][*y] = '*';
        *x += dir[*way][0];
        *y += dir[*way][1];
    }
    *way = 0; // 抵達頂部後轉回水平向右 (方向 0)，準備繪製頂部長邊
}

int main()
{
    int len;
    if(scanf("%d", &len) != 1) return 0;

    // 起始位置設為列 x = len / 2，行 y = 0，初始方向為向右
    int x = len / 2, y = 0, way = 0;

    // 初始化畫布全填為空白字元
    for(int i = 0; i < 501; ++i)
    {
        for(int j = 0; j < 2501; ++j)
        {
            area[i][j] = ' ';
        }
    }

    // 依序執行畫筆軌跡
    drawhorizon(&x, &y, &way, len);          // 1. 繪製長度為 len 的短邊
    drawv(&x, &y, &way, len);                // 2. 繪製 V 型凹陷及右斜邊
    drawhorizon(&x, &y, &way, len * 2 + 1);  // 3. 繪製頂部長邊 (長度為 2 * len)

    // 計算畫布實際需輸出的總寬度
    int horizon = 4 * len + (len + 1) / 2 - 3;

    // 依列輸出 0 到 len - 1 行
    for(int i = 0; i < len; ++i)
    {
        for(int j = 0; j < horizon; ++j)
        {
            printf("%c", area[i][j]);
        }
        printf("\n");
    }

    return 0;
}
