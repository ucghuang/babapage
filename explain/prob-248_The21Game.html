題目摘要

問題敘述： 「搶數字」是一種雙人博弈遊戲。從 0 開始，兩人輪流加 1 ∼ R 之間的數字，誰先加到目標數字 T 就獲勝。給定目標數字 T 與報數範圍 R，請判斷是先手必勝（輸出 1）還是後手必勝（輸出 0）。

輸入格式： 輸入只有一列，包含兩個正整數 T (1 ≤ T ≤ 104) 和 R (1 ≤ R ≤ 9)，以一個空白隔開。

輸出格式： 若先手必勝輸出 1，否則輸出 0。

演算法使用解析：【賽局理論 (Game Theory) / 巴什博弈 (Bash Game)】

本題採用賽局理論中的巴什博弈數學公式分析：

  • 核心原理：每次可加 1 ∼ R 的數字，目標是搶到 T。若總數是 (1 + R) 的倍數，則先手每次報數後，後手都可以搭配湊成 (1 + R) 的總和，因此後手必勝；否則先手必勝。
  • 判定公式：計算餘數 `target = T % (1 + R)`。
    • 若 0 < target <= R，代表先手在第一步可以直接報數加 `target`，將局面留給對手一個 (1 + R) 倍數的必敗態，因此先手必勝（輸出 1）。
    • 否則（即 target == 0），先手面對的是一個必敗態，後手必勝（輸出 0）。

課堂黑板板書推導

【輸入範例 1 詳細拆解】

輸入：
21 3
  • 步驟一：計算關鍵餘數
    • 目標 T = 21，報數範圍 R = 3。
    • 1 + R = 1 + 3 = 4。
    • target = 21 - 4 * (21 / 4) = 21 - 4 * 5 = 21 - 20 = 1。
  • 步驟二：判定勝負
    • 因為 1 ≤ 1 ≤ 3 且 1 ≠ 0，符合先手必勝條件。

👉 輸出範例 1 結果： 1

【輸入範例 2 詳細拆解】

輸入：
30 1
  • 步驟一：計算關鍵餘數
    • 目標 T = 30，報數範圍 R = 1。
    • 1 + R = 2。
    • target = 30 - 2 * (30 / 2) = 30 - 30 = 0。
  • 步驟二：判定勝負
    • 因為 target == 0，先手必敗，後手必勝。

👉 輸出範例 2 結果： 0

參考解答 C++ 程式碼（100% 取自官方解答，逐行繁體中文教學註解）

#include <iostream>   // 引入 C++ 標準輸入輸出串流函式庫 (如 cin, cout, endl)
using namespace std;  // 使用標準命名空間 std

int main()            // 主程式起點
{
    int64t t, r;     // 宣告 64 位元整數 t（目標數字 T）與 r（報數範圍上限 R）
    cin >> t >> r;    // 輸入目標數字 t 與報數範圍 r

    // 根據巴什博弈 (Bash Game) 原理，計算目標值 t 對 (1 + r) 取餘數的剩餘量
    int64t target = t - (1+r) * (t/(1+r));
    
    // 判定先手是否必勝：若剩餘量 target 介於 1 到 r 之間（即 0 < target <= r），代表先手可以透過第一步直接搶到關鍵數字，達到必勝態
    if (target <= r && target != 0)
        cout << 1 << endl;  // 先手必勝，輸出 1
    else
        cout << 0 << endl;  // 後手必勝（或先手必敗），輸出 0
}
