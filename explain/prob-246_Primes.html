題目摘要

問題敘述：給定一個正整數 \(N\)，請判斷 \(N\) 是否為兩個質數的乘積。如果是，請輸出這兩個質數 \(A\) 與 \(B\) (\(A ≤ B\))，以空白分隔；若不是，則輸出 0 0。

輸入格式：輸入僅有一列，包含一個整數 \(N\) (\(2 ≤ N ≤ 2 × 109\))。

輸出格式：若 \(N\) 是兩個質數 \(A\) 與 \(B\) 的乘積，輸出 A B；若不是，輸出 0 0。

演算法使用解析：【質數判定與因數分解】

本題需要對給定的數字進行因數尋找與質數檢驗：

  • 因數尋找：透過迴圈從 2 檢查到 \(\sqrt{N}\)。若 \(N \% i == 0\)，則 \(a = i\)、\(b = N / i\) 為一組因數對。
  • 質數判定 (isPrime)：針對分解出的因數進行嚴格的質數檢驗。先排除偶數（除了 2 以外），再透過從 3 測試到 \(\sqrt{n}\)（每次遞增 2）來確認其是否為質數。
  • 結果輸出：若因數 \(a\) 與 \(b\) 皆通過質數檢驗，則依序輸出；否則輸出 0 0。

課堂黑板板書推導

【輸入範例 1】 \(N = 14\)

  • 尋找因數：從 2 到 \(\sqrt{14} ≈ 3.74\)。當 \(i = 2\) 時，\(14 \% 2 == 0\)，故 \(a = 2\)、\(b = 14 / 2 = 7\)。
  • 質數判定：檢驗 \(a = 2\) 為質數，\(b = 7\) 為質數。

👉 輸出範例 1 結果：2 7

【輸入範例 2】 \(N = 63\)

  • 尋找因數：從 2 到 \(\sqrt{63} ≈ 7.93\)。當 \(i = 3\) 時，\(63 \% 3 == 0\)，\(a = 3, b = 21\)；當 \(i = 7\) 時，\(63 \% 7 == 0\)，更新 \(a = 7, b = 9\)。
  • 質數判定：檢驗 \(a = 7\) 為質數，但 \(b = 9\) 不是質數（\(9 \% 3 == 0\)）。

👉 輸出範例 2 結果：0 0

【輸入範例 3】 \(N = 917747\)

  • 尋找因數：可找到因數對 \(257\) 與 \(3571\)。
  • 質數判定：\(257\) 與 \(3571\) 皆為質數。

👉 輸出範例 3 結果：257 3571

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <iostream> // 引入標準輸入輸出串流標頭檔
#include <cmath>    // 引入數學函式庫，以便使用 sqrt 函數

using namespace std;

bool isPrime(int n) // 定義判斷質數的函式 isPrime
{
    if (n % 2 == 0 && n != 2) // 若數字為偶數且不等於 2，則不是質數
    {
        return false;
    }

    if (n > 3) // 若數字大於 3，透過迴圈檢查是否有奇數因數
    {
        for (int i = 3; i <= sqrt(n); i += 2) // 從 3 開始測試到 sqrt(n)，每次遞增 2
        {
            if (n % i == 0) // 若能被 i 整除，代表不是質數
            {
                return false;
            }
        }
    }
    return true; // 通過檢查則為質數，回傳 true
}

int main()
{
    int N, a = 0, b = 0; // 宣告整數 N 代表輸入數字，a 與 b 用來記錄分解出的兩個因數
    cin >> N; // 讀入整數 N
    for (int i = 2; i <= sqrt(N); ++i) // 從 2 開始尋找 N 的因數到 sqrt(N)
    {
        if (N % i == 0) // 若 i 是 N 的因數
        {
            a = i; // 將因數指定給 a
            b = N / i; // 另一因數為 N / i，指定給 b
        }
    }

    if (isPrime(a) && isPrime(b)) // 檢查 a 與 b 是否同時為質數
    {
        cout << a << " " << b << endl; // 若皆為質數，依序輸出 a 與 b
    }
    else
    {
        cout << "0 0" << endl; // 若不是兩個質數的乘積，輸出 0 0
    }
}
