#16 201905_B1-Currency (貨幣轉換)

題目摘要

問題敘述： 協助學生小品進行出國旅遊的貨幣換算。給定初始台幣預算 n，以及一筆花費金額 m 與目的地幣制代號（T: 台幣、U: 美元、J: 日元、E: 歐元）。已知匯率如下：

  • 台幣 (T)：1.0
  • 美元 (U)：30.9（30.9 元台幣 = 1 美元）
  • 日元 (J)：0.28（0.28 元台幣 = 1 日元）
  • 歐元 (E)：34.5（34.5 元台幣 = 1 歐元）

請計算預算扣除花費後的該幣制剩餘金額。若餘額不足則輸出 No Money，否則輸出幣制代號與四捨五入至小數點後兩位的餘額。

輸入格式： 第一行輸入一個正整數 n（台幣預算）。第二行輸入一個正整數 m 與一個英文字母（T, U, J 或 E），代表花費金額與幣制。

輸出格式： 輸出幣制代號與剩餘金額（小數點後兩位），或當資金不足時輸出 No Money。

演算法使用解析：【基礎條件判斷與浮點數算術】

本題為基礎的算術模擬題，核心步驟：

  • 讀入資料： 分別讀入初始預算 n、花費金額 m 以及幣制字元 `cur`。
  • 匯率換算： 根據 `cur` 的種類（T、U、J、E），將台幣預算 n 除以對應匯率換算成目標幣制的總資產 HaveMoney。
  • 餘額檢查： 比較 HaveMoney 與花費 m。若 HaveMoney < m，表示金額不足，輸出 No Money；否則計算 remain = HaveMoney - m，並以 printf("%.2f") 格式化輸出小數點後兩位。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
50000
200 U
  • 初始預算 n = 50000 台幣，花費 m = 200 美元（`U`）。
  • 轉換為美元：HaveMoney = 50000 / 30.9 ≈ 1618.122977 美元。
  • 扣除花費：remain = 1618.122977 - 200 = 1418.122977 美元。
  • 格式化輸出（小數點後兩位）：U 1418.12

👉 輸出範例 1 結果： U 1418.12

【輸入範例 2 實際運作推導】

輸入：
15000
800 E
  • 初始預算 n = 15000 台幣，花費 m = 800 歐元（`E`）。
  • 轉換為歐元：HaveMoney = 15000 / 34.5 ≈ 434.78 歐元。
  • 因為 434.78 < 800，資金不足。

👉 輸出範例 2 結果： No Money

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<stdio.h> // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf
#include<string.h> // 引入字串處理標頭檔

int main()
{
	int n = 0, m = 0; // 宣告整數 n（初始預算，台幣）與 m（花費金額），初始化為 0
	char cur = '\0'; // 宣告字元 cur，用來儲存目的地幣制代號（T, U, J, E）
	scanf("%d",&n); // 讀入初始預算 n
	scanf("%d %c", &m, &cur); // 讀入花費金額 m 與幣制代號 cur

	double HaveMoney = 0; // 宣告倍精確浮點數 HaveMoney，用來儲存換算後的目標幣制總金額
	if( cur == 'T'){ // 若幣制為台幣 T
		HaveMoney = n * 1.0; // 匯率為 1.0，直接乘以 1.0
	}
	else if( cur == 'U' ){ // 若幣制為美元 U
		HaveMoney = n / 30.9; // 以 30.9 進行匯率換算
	}
	else if( cur == 'J' ){ // 若幣制為日元 J
		HaveMoney = n / 0.28; // 以 0.28 進行匯率換算
	}
	else if( cur == 'E' ){ // 若幣制為歐元 E
		HaveMoney = n / 34.5; // 以 34.5 進行匯率換算
	}

	if(HaveMoney < m) // 若換算後的總金額小於花費金額 m
		printf("No Money\n"); // 資金不足，輸出 No Money 並換行
	else // 否則（資金足夠）
	{
		double remain = HaveMoney - m; // 計算扣除花費後的剩餘金額 remain
		printf("%c %.2f\n", cur, remain); // 格式化輸出幣制代號與四捨五入至小數點後兩位的剩餘金額
	}
} // 主程式結束
