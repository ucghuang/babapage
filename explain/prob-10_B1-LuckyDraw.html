題目摘要

問題敘述： 模擬粉絲專頁的隨機抽獎演算法。給定 N 則留言的隨機數字，以最後一個數字作為基數 B，找出所有索引值除以 B 餘數為 1 的留言隨機數並加總。最後將總和除以 N 取餘數得到中獎索引 M（若餘數為 0 則以最後一則留言中獎）。請輸出中獎留言之索引值與對應的隨機數。

輸入格式： 總共輸入兩行，第一行輸入一個正整數 N (3 ≤ N ≤ 10,000)，表示留言總數；第二行輸入 N 個整數 ri (2 ≤ ri ≤ 1,000)，代表隨機值。

輸出格式： 共輸出兩個正整數，以空白區隔，第一個為中獎留言索引 M (1 ≤ M ≤ N)，第二個為該索引對應之隨機數。

演算法使用解析：【基礎模擬與陣列運算】

本題為經典的邏輯模擬題，核心步驟如下：

  • 資料儲存： 使用陣列 num 依序讀取並儲存 N 個隨機數字。
  • 基數設定： 根據題目規則，以陣列最後一個元素 num[n-1] 作為基數 B。
  • 條件篩選與加總： 走訪所有索引 i（從 0 到 N-1），若 1-based 索引 (i+1) 除以 B 的餘數為 1（即 (i+1) % B == 1），則將對應的 num[i] 累加至 total。
  • 中獎索引計算： 計算 m = total % n。若 m == 0，代表餘數為 0，此時中獎者為最後一則留言，故將 m 設為 n。
  • 輸出結果： 輸出中獎索引 m 與對應的隨機數 num[m-1]。

課堂黑板板書推導

【輸入範例 2 實際運作推導】

輸入：
5
20 50 7 100 2
  • 留言總數 N = 5，陣列內容 num = [20, 50, 7, 100, 2]。
  • 基數 B = num[4] = 2。
  • 檢查每個位置 (i+1) ±od 2 == 1 的項目：
    • i = 0 (位置 1)：1 ±od 2 = 1（符合），累加 num[0] = 20
    • i = 1 (位置 2)：2 ±od 2 = 0（不符合）
    • i = 2 (位置 3)：3 ±od 2 = 1（符合），累加 num[2] = 7
    • i = 3 (位置 4)：4 ±od 2 = 0（不符合）
    • i = 4 (位置 5)：5 ±od 2 = 1（符合），累加 num[4] = 2
  • 總和 total = 20 + 7 + 2 = 29。
  • 計算中獎索引 m = 29 % 5 = 4。
  • 對應隨機數為 num[3] = 100。

👉 輸出範例 2 結果： 4 100

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <iostream> // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout
using namespace std; // 使用標準命名空間 std

int main()
{
    int n=0; // 宣告整數 n，用來儲存留言總數，初始化為 0
    cin>>n; // 從標準輸入讀取留言數 n
    int num[10005]={}; // 宣告大小為 10005 的整數陣列 num，用來儲存每則留言的隨機值，並初始化為 0
    for(int i=0;i<n;i+=1){ // 從 0 到 n-1 進行迴圈迭代
        cin>>num[i]; // 依序讀取每一則留言的隨機值並存入 num[i]
    }
    int B=num[n-1]; // 以陣列最後一個元素（即第 n 個隨機數）作為基數 B
    int total=0; // 宣告整數 total，用來累加符合條件的隨機值，初始化為 0
    for(int i=0;i<n;i+=1){ // 再次從 0 到 n-1 走訪所有留言
        if((i+1)% B==1){ // 若當前 1-based 索引 (i+1) 除以基數 B 的餘數等於 1
            total += num[i]; // 將該隨機值累加到總和 total 中
        }
    }
    int m=total%n; // 計算加總值 total 對留言數 n 取餘數，得到中獎索引餘數 m
    if(m==0) m=n; // 若餘數 m 為 0，則表示最後一則留言中獎，將 m 設為 n
    cout<<m<<' '<<num[m-1]; // 輸出中獎留言的索引 m 與對應的隨機數 num[m-1]，以空白隔開
} // 主程式結束
