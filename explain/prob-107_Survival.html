#107 202104_Survival (物競天擇)

題目摘要

問題敘述：「物競天擇、適者生存」是大自然的殘酷競爭法則。母獅在小獅子出生後，會優先照顧強壯的個體，而天生弱小的獅子則可能遭到忽視或遺棄。為了保護弱小的小獅子，保育人員計畫在小獅子出生後，將最弱小的那隻帶回城市進行保育。比較方式是以每隻小獅子的體重（公斤）乘以身高（公分），將該數值最小的小獅子帶回保護。

輸入格式：

  • 第一行為一個整數 N (2 ≤ N ≤ 2000)，代表小獅子的總數。
  • 第二行有 N 個整數，代表每隻獅子的身高 Hi (1 ≤ Hi ≤ 1000, 1 ≤ i ≤ N)。
  • 第三行有 N 個整數，代表每隻獅子的體重 Wi (1 ≤ Wi ≤ 1000, 1 ≤ i ≤ N)。

輸出格式：輸出一行包含要帶走的小獅子的身高與體重，兩數中間以一個空格隔開。題目保證只會恰好有一隻小獅子擁有最小的乘積數值。

演算法使用解析：【一維陣列線性掃描與最小值維護】

本題為經典的線性掃描搜尋極值（Linear Search for Minimum）問題：

  • 資料儲存：使用兩個長度至少為 2001 的一維整數陣列 lionH[] 與 lionW[]，分別依序存放每隻小獅子的身高與體重。
  • 極值維護：先設定變數 min 為一個足夠大的初始值（例如 99999999），變數 idx 用於記錄目前最小乘積出現的陣列索引（編號）。
  • 邊讀邊比對：在第二個迴圈讀取體重 lionW[i] 的同時，直接計算 lionH[i] * lionW[i]。只要當前小獅子的乘積小於記錄中的 min，就立即更新 min 為該數值，並將 idx 更新為目前的索引 i。
  • 結果輸出：迴圈結束後，idx 所指向的就是全體乘積最小的小獅子，直接輸出 lionH[idx] 與 lionW[idx] 即可。整體時間複雜度為 O(N)，空間複雜度為 O(N)。

課堂黑板板書推導（全部範例詳細推導）

【輸入範例 1 實際運作推導】

輸入：
2
145 34
21 55
  • 讀入小獅子總數：N = 2
  • 讀入身高陣列：lionH[0] = 145, lionH[1] = 34
  • 讀入體重並即時比對（初始 min = 99999999, idx = 0）：
    • i = 0：讀入 lionW[0] = 21。
      計算乘積 = 145 × 21 = 3045。
      因為 3045 < 99999999，更新 min = 3045, idx = 0。
    • i = 1：讀入 lionW[1] = 55。
      計算乘積 = 34 × 55 = 1870。
      因為 1870 < 3045，更新 min = 1870, idx = 1。
  • 最終最小值索引：idx = 1，對應身高 lionH[1] = 34、體重 lionW[1] = 55。

參考解答 C++ 程式碼（百分之百保留原檔邏輯與變數名稱，逐行中文教學註解）

#include <iostream> // 引入標準輸入輸出串流函式庫，以便使用 cin 與 cout
using namespace std; // 使用標準命名空間 std，省去每次呼叫時的前綴

int main() // 主程式進入點
{ // 主程式區塊開始
	int N; // 宣告整數變數 N，用來代表小獅子的總數量
	cin>>N; // 從標準輸入讀入小獅子總數 N
	int lionH[2001]={}; // 宣告大小為 2001 的整數陣列 lionH，並全部初始化為 0，用來儲存各獅子的身高
	int lionW[2001]={}; // 宣告大小為 2001 的整數陣列 lionW，並全部初始化為 0，用來儲存各獅子的體重
	int min=99999999; // 宣告整數變數 min 並初始化為極大值 99999999，用來維護最小的「身高×體重」乘積
	int idx=0; // 宣告整數變數 idx 並初始化為 0，用來記錄擁有最小乘積之小獅子的陣列索引
	for(int i=0; i<N; ++i) // 使用迴圈依序讀入 N 隻小獅子的身高資料
	{ // 讀入身高迴圈開始
		cin>>lionH[i]; // 讀入第 i 隻小獅子的身高並存入 lionH[i]
	} // 讀入身高迴圈結束
	for(int i=0; i<N; ++i) // 使用迴圈依序讀入 N 隻小獅子的體重資料，並同步進行最小值比對
	{ // 讀入體重與比較迴圈開始
		cin>>lionW[i]; // 讀入第 i 隻小獅子的體重並存入 lionW[i]
		if(lionH[i]*lionW[i]<min) // 判斷第 i 隻獅子的「身高×體重」乘積是否小於當前記錄的最小值 min
		{ // 若小於當前最小值則執行更新
			min = lionH[i]*lionW[i]; // 將最小值 min 更新為當前小獅子的乘積
			idx=i; // 將最小值的索引 idx 更新為當前小獅子的編號 i
		} // 條件更新結束
	} // 讀入體重與比較迴圈結束
	cout<<lionH[idx]<<" "<<lionW[idx]<<endl; // 輸出擁有最小乘積小獅子的身高與體重，兩數以空格隔開並換行
} // 主程式區塊結束
