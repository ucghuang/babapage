題目摘要與規則設定

情境描述： Alice 和 Bob 到沙灘旅遊，在岸邊撿了很多石頭進行策略博弈。

  • 規則 1（先手與結束條件）： Alice 必為先手。雙方輪流從地面上拿走石頭，輪到自己時地面無石頭可拿者判敗（Normal Play Convention）。
  • 規則 2（指定步數集合）： 指定 N 個正整數組成集合 P = \{P1, P2, …, PN\}（1 ≤ P ≤ 2 × 106），每次只能從地面拿走屬於集合 P 內指定數量的石頭。題目保證集合中必定包含 1（即最少可拿 1 顆）。
  • 輸入格式： 第一列為 N (1 ≤ N ≤ 50)；第二列為 N 個整數 P；第三列為局數 M (1 ≤ M ≤ 105)；接續 M 列各為該局初始石頭數 Q (1 ≤ Q ≤ 2 × 106)。
  • 輸出格式： 對每局輸出 Alice 的勝負結果：勝輸出 Win!，敗輸出 Lose。
  • 評分級距：
    • 第 1 組 (10分) 1 ≤ P, Q ≤ 4, M = 1
    • 第 2 組 (30分) 1 ≤ P, Q ≤ 100,000
    • 第 3 組 (60分) 1 ≤ P, Q ≤ 2,000,000

演算法數學原理：賽局理論與狀態轉移

本題屬於標準的公平組合遊戲（Impartial Game）。由於遊戲只在單一石堆上進行，我們可以直接採用「必勝態（P-position）與必敗態（N-position）」的二元性質簡化 SG 函數計算：

  • 終止態（Base Case）： SG[0] = 0。輪到該局的人已無石頭可拿，直接判輸，屬於必敗態（Lose）。
  • 必勝態（Winning State, SG[Q] = 1）： 從狀態 Q 出發，只要存在至少一個合法的取石數 Pj ∈ P (Pj ≤ Q)，使得轉移後的狀態為必敗態（即 SG[Q - Pj] == 0），則先手玩家只要選擇拿走 Pj 顆，就能將必敗態強加給對手，確保自身獲勝。
  • 必敗態（Losing State, SG[Q] = 0）： 從狀態 Q 出發，若針對「所有」合法的取石數 Pj ∈ P，轉移後的狀態全都是必勝態（即 ∀ Pj ≤ Q,\ SG[Q - Pj] == 1），則先手玩家無論怎麼拿，對手接手後都處於必勝局面，因此當前狀態為必敗態。
  • 線性動態規劃預處理： 狀態最大值達 2 × 106。透過外層走訪 i = 1 … 2 × 106、內層遍歷集合 P 的常數次操作，能在 O(N \cdot max(Q)) 時間內預處理完畢，並以 O(1) 快速回答每筆查詢。

範例 1 詳細狀態轉移與黑板推導

輸入參數： N = 5，P = \{1, 2, 3, 4, 5\}，查詢 Q ∈ \{6, 7\}。

石頭數 Q 可轉移之後續狀態 (Q - Pj) 後續狀態之 SG 值 當前 SG[Q] 勝負結論
0 無（已無法取石） - 0 必敗態 (Lose)
1 取 1 顆 → 剩 0 SG[0] = 0 最佳步 1 必勝態 (Win!)
2 取 1 → 1; 取 2 → 0 SG[0] = 0 最佳步, SG[1] = 1 1 必勝態 (Win!)
3 取 1 → 2; 取 2 → 1; 取 3 → 0 SG[0] = 0 最佳步 1 必勝態 (Win!)
4 取 1~4 顆 → 可轉移至 3, 2, 1, 0 包含 SG[0] = 0 最佳步 1 必勝態 (Win!)
5 取 1~5 顆 → 可轉移至 4, 3, 2, 1, 0 包含 SG[0] = 0 最佳步 1 必勝態 (Win!)
6 (查詢) 取 1~5 顆 → 分別剩 5, 4, 3, 2, 1 全部狀態之 SG 均為 1（無任何轉移能到達 0） 0 Lose
7 (查詢) 取 1 顆 → 剩 6; 取其他 → 剩 5, 4, 3, 2 SG[6] = 0 最佳步：取 1 顆 1 Win!

週期性規律推導： 當可取集合為連續的 1 ∼ K 時（此處 K=5），整個遊戲等價於巴什博弈（Bash Game）。狀態呈現以 K+1 = 6 為週期的規律：只要 Q ±od 6 == 0 則先手必敗（Lose），否則先手必勝（Win!）。

範例 2 詳細狀態轉移與黑板推導

輸入參數： 第二列輸入 1 2 2 5（去重並排序後有效集合 P = \{1, 2, 5\}），查詢 Q ∈ \{5, 6, 8\}。

石頭數 Q 合法取法與轉移狀態 (Q - Pj) 後續狀態 SG 值判定 當前 SG[Q] 勝負結論
0 無合法操作 邊界條件 0 必敗態 (Lose)
1 可拿 1 → 剩 0 SG[0] = 0 最佳步 1 必勝態 (Win!)
2 可拿 1 → 1; 拿 2 → 0 SG[0] = 0 最佳步：拿 2 顆 1 必勝態 (Win!)
3 可拿 1 → 2; 拿 2 → 1 SG[2]=1,\ SG[1]=1（全為勝態，無 0 可選） 0 必敗態 (Lose)
4 可拿 1 → 3; 拿 2 → 2 SG[3] = 0 最佳步：拿 1 顆 1 必勝態 (Win!)
5 (查詢) 可拿 1 → 4; 拿 2 → 3; 拿 5 → 0 SG[0] = 0 最佳步：拿 5 顆一次拿完 1 Win!
6 (查詢) 可拿 1 → 5; 拿 2 → 4; 拿 5 → 1 SG[5]=1,\ SG[4]=1,\ SG[1]=1（全為勝態） 0 Lose
7 可拿 1 → 6; 拿 2 → 5; 拿 5 → 2 SG[6] = 0 最佳步：拿 1 顆 1 必勝態 (Win!)
8 (查詢) 可拿 1 → 7; 拿 2 → 6; 拿 5 → 3 SG[3] = 0 最佳步：拿 5 顆留 3 顆 1 Win!

參考解答 C++ 程式碼（逐行繁體中文教學註解）

#include<bits/stdc++.h>  // 引入標準擴充標頭檔 (包含 vector、演算法 sort 與標準 I/O)
std::vector<int> v;       // 宣告全域動態陣列 v，用來儲存每次可拿走的石頭數量集合 P
int SG[2000005]={};       // 宣告全域陣列 SG，大小為 2,000,005
                          // SG[i] = 0 代表當石頭剩餘 i 顆時為「先手必敗態」(Lose)
                          // SG[i] = 1 代表當石頭剩餘 i 顆時為「先手必勝態」(Win!)

void getsg()             // 核心動態規劃函數：由小到大計算所有狀態的 SG 值
{
    int visit=1;          // 預設擴充變數
    for(int i=0;i<2000005;i+=1)  // 從 0 顆一路遞推推導至 2,000,000 顆
    {
        for(int j=0;j<(int)v.size();j+=1)  // 遍歷所有合法的取石步數
        {
            if(v[j]>i) break;              // 若目前可取數量已超過剩餘石頭數 i，後續更大者皆無法取，提前結束
            else if(SG[i-v[j]]==0)         // 關鍵轉移：若拿走 v[j] 顆後留給對手的是「必敗態 (0)」
            {
                SG[i]=1;                   // 則目前狀態 i 為「必勝態 (1)」
                break;                     // 已找到致勝路徑，無需再檢查其餘取法
            }
        }
        if(!visit)          // 保留擴充機制
        {
            SG[i]=1;
        }
    }
}

int main()                  // 程式執行進入點
{
    int a;                  // 宣告整數 a，代表指定可拿石頭數量的個數 N
    if(scanf("%d",&a) != 1) return 0; // 讀入 N
    
    while(a--)              // 依序讀入 N 個指定的石頭數量
    {
        int x;
        scanf("%d",&x);
        v.pushback(x);     // 加入至可取集合陣列中
    }
    std::sort(v.begin(),v.end());  // 升冪排序，以利 DP 內部 break 剪枝提早結束迴圈
    
    getsg();               // 預先計算 0 ~ 2,000,000 每一種石頭數量之勝負結果
    
    int T;                  // 宣告整數 T，代表遊戲局數 M
    if(scanf("%d",&T) != 1) return 0; // 讀入 M
    
    int x;                  // 宣告整數 x，代表當前局地面上的初始石頭數量 Q
    while(T--)              // 逐局處理查詢
    {
        scanf("%d",&x);     // 讀入該局的初始石頭數 Q
        if(SG[x]==0) printf("Lose\n");  // 若為 0 代表先手必敗，輸出 Lose
        else printf("Win!\n");          // 若為 1 代表先手必勝，輸出 Win!
    }
    return 0;
}
