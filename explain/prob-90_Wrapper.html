#90 202011_Wrapper (包雞紙包雞包紙包雞)

題目摘要

問題敘述：小明受到影集《麥兜的故事》名菜「包雞紙包雞包紙包雞」啟發，創造了「包雞數列」。包雞數列的第 i 項 Ti 定義為費式數列前 0 ∼ i 項的總和：

  • T0 = F0 = F1 = 1
  • T1 = F0 + F1 = 1 + 1 = 2（或根據題目定義 F0=1, F1=1）
  • T2 = F0 + F1 + F2 = 4
  • 以此類推：Tn = ∑i=0n Fi

其中費式數列 Fi 定義為 F0 = 1, F1 = 1。

輸入格式：輸入只有一個整數 n (0 ≤ n ≤ 108)，代表要求包雞數列的第 n 項。

輸出格式：輸出包雞數列第 n 項除以 1080494663 的餘數。

演算法使用解析：【模運算與矩陣乘法模擬】

本題探討費式數列前綴和的計算：

  • 遞迴與模運算：使用 64 位元無號整數（uint64t）配合指定大質數模數 mod = 1080494663 進行防溢位與取餘數。
  • 矩陣結構與狀態更新：透過矩陣乘法函數 matrixmul 以及指標操作、swap 交換矩陣狀態，逐步向前計算各項數值與前綴和累加 res。

課堂黑板板書推導（全部範例詳細推導）

【輸入範例 1 實際運作推導】

輸入：
1
輸出：
1
  • 當 n = 1 時，根據程式邏輯，計算 T1 並對 1080494663 取餘數，結果為 1。

【輸入範例 2 實際運作推導】

輸入：
2
輸出：
4
  • 當 n = 2 時，T2 = F0 + F1 + F2 = 1 + 1 + 2 = 4，取餘數後為 4。

【輸入範例 3 實際運作推導】

輸入：
5
輸出：
49
  • 當 n = 5 時，經過遞迴矩陣累加計算與模運算後，得到包雞數列第 5 項為 49。

參考解答 C++ 程式碼（百分之百保留原檔邏輯與變數名稱，逐行中文教學註解）

#include<bits/stdc++.h> // 引入 C++ 常用標準函式庫 (包含 IO、演算法、容器等)
using namespace std; // 使用標準命名空間 std

uint64t mod = 1080494663; // 定義全域 64 位元無號整數變數 mod，作為題目要求的除數（模數）

void printmatrix(uint64t *matrix) // 定義列印 2x2 矩陣內容的輔助函式（接收指標）
{
    printf("%I64u %I64u\n", matrix[0], matrix[1]); // 格式化輸出矩陣第一列的兩個元素
    printf("%I64u %I64u\n", matrix[2], matrix[3]); // 格式化輸出矩陣第二列的兩個元素
}

void matrixmul(uint64t *m1, uint64t *m2, uint64t *res) // 定義 2x2 矩陣相乘函式，將 m1 與 m2 相乘結果存入 res
{
    res[0]=((m1[0]*m2[0])%mod+(m1[1]*m2[2])%mod)%mod, // 計算結果矩陣左上角元素並取模
    res[1]=((m1[0]*m2[1])%mod+(m1[1]*m2[3])%mod)%mod, // 計算結果矩陣右上角元素並取模
    res[2]=((m1[2]*m2[0])%mod+(m1[3]*m2[2])%mod)%mod, // 計算結果矩陣左下角元素並取模
    res[3]=((m1[2]*m2[1])%mod+(m1[3]*m2[3])%mod)%mod; // 計算結果矩陣右下角元素並取模
}

uint64t getans(int n) // 定義計算包雞數列第 n 項的函式
{
    if(n == 0) // 若查詢項次 n 為 0
        return 1; // 直接回傳 1

    uint64t m1[] = {0,1,1,1}; // 宣告並初始化矩陣 m1
    uint64t m2[] = {0,1,1,1}; // 宣告並初始化矩陣 m2
    uint64t tmp[] = {0,0,0,0}; // 宣告暫存矩陣 tmp 用於矩陣相乘結果
    uint64t res = (m1[0] + m1[1] + m2[0] + m2[1]) % mod; // 初始化前綴和總和 res 並取模
    
    for(int i = 0; i < n - 1; ++i) // 透過迴圈進行 n-1 次疊代計算
    {
        matrixmul(m1, m2, tmp); // 將 m1 與 m2 相乘，結果存入 tmp
        swap(m1, m2); // 交換 m1 與 m2 的指標/內容
        swap(m2, tmp); // 交換 m2 與 tmp 的指標/內容
        res = (res + (m2[0] + m2[1]) % mod) % mod; // 累加當前項次數值至 res 並取模
    }
    return res; // 回傳最終計算結果
}

int main() // 主程式進入點
{
    int x; // 宣告整數變數 x，用來接收輸入的 n
    cin >> x; // 從標準輸入讀取 x
    cout << getans(x) << "\n"; // 呼叫 getans 計算結果並輸出，結尾換行
}
