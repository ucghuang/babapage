題目摘要

問題敘述： 著名的歷史典故「韓信點兵」：三三數之剩二，五五數之剩三，七七數之剩二。給定三行輸入，每行包含兩個整數 ai 與 bi（1 < ai, bi < 300，且保證任兩個 ai 互質），代表軍隊人數 m 每 ai 個一數會剩下 bi 個人。請寫一個程式找出符合所有條件的最小軍隊人數 m (1 ≤ m < 2 \cdot 106)。

輸入格式： 輸入有三行，每行含兩個整數 ai 與 bi，以空白隔開。

輸出格式： 請輸出一個最小的正整數 m，代表軍隊人數。

演算法使用解析：【數論與數學 / 同餘方程式與窮舉搜尋】

本題採用同餘性質與迴圈窮舉策略：

  • 此題為中國剩餘定理（Chinese Remainder Theorem）的基礎應用。
  • 由於題目給定的 m 上限範圍不大（m < 2 \cdot 106），我們可以直接利用 while(true) 從 m = 1 開始由小到大進行迴圈檢查。
  • 當某個數字 m 同時滿足 m ±od{a1} == b1、m ±od{a2} == b2 且 m ±od{a3} == b3 時，該數字即為所求的最小軍隊人數，直接輸出並結束程式。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
3 2
5 3
7 2
  • 條件方程式：
    • m ±od 3 = 2
    • m ±od 5 = 3
    • m ±od 7 = 2
  • 逐一測試 m 從 1 開始：
    • m = 1 ⟹ 1\%3=1 ≠ 2（不符）
    • …
    • m = 23 ⟹ 23\%3=2（符合）、23\%5=3（符合）、23\%7=2（符合）！
  • 找到符合的第一個最小數字為 23。

👉 輸出範例 1 結果： 23

【輸入範例 2 實際運作推導】

輸入：
7 2
9 5
13 7
  • 條件方程式： m ±od 7 = 2, m ±od 9 = 5, m ±od{13} = 7。
  • 由小到大進行迴圈搜尋，第一個同時滿足三個同餘條件的最小正整數為 527。

👉 輸出範例 2 結果： 527

【輸入範例 3 實際運作推導】

輸入：
251 69
191 58
241 81
  • 條件方程式： m ±od{251} = 69, m ±od{191} = 58, m ±od{241} = 81。
  • 透過程式迴圈檢查，找到符合條件的最小人數為 48763。

👉 輸出範例 3 結果： 48763

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<iostream>  // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout
using namespace std;

int main()  
{  
    int a1, a2, a3;  // 宣告三個除數變數 a1, a2, a3
    int b1, b2, b3;  // 宣告三個對應的餘數變數 b1, b2, b3
    
    cin >> a1 >> b1;  // 讀入第一組除數與餘數
    cin >> a2 >> b2;  // 讀入第二組除數與餘數
    cin >> a3 >> b3;  // 讀入第三組除數與餘數
  
    int ans = 1;  // 初始化士兵人數猜測值 ans 從 1 開始
    while(true)  // 使用無限迴圈由小到大尋找符合條件的數字
    {  
        // 檢查當前 ans 是否同時滿足除以 a1 餘 b1、除以 a2 餘 b2、除以 a3 餘 b3
        if(ans % a1 == b1 && ans % a2 == b2 && ans % a3 == b3)
        {  
            cout << ans;  // 若完全符合，輸出這個最小的軍隊人數
            break;  // 找到答案後跳出迴圈
        }  
        ans += 1;  // 若尚未符合，將人數猜測值加 1 繼續測試
    }  
}
