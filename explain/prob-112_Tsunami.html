#112 202105_Tsunami (海嘯)

題目摘要

問題敘述： 某國的沿海地區是一個長條狀區域，包含 N 個一整列的建物。海嘯侵襲沿海地區是連續的（即某個連續區間 [i, j] 的建物遭受破壞），海嘯侵襲的嚴重程度為該區間內所有建物損失的總和 ∑k=ij dk。現在給定 N 個建物的損失陣列 di 以及正整數 K，請寫一個程式找出所有可能海嘯侵襲狀況中，嚴重程度由大到小排序的第 K 種狀況的嚴重程度。

  • 輸入格式：
    • 第一行輸入 2 個正整數 N (1 ≤ N ≤ 5 × 105) 與 K (1 ≤ K ≤ N(N+1)/2)。
    • 第二行包含 N 個非負整數 di (0 ≤ di ≤ 109)，代表每個建物的損失。
  • 輸出格式： 輸出一個整數值，代表所有可能連續區間和由大到小排序的第 K 大嚴重程度。

演算法使用解析：【二分搜尋法 (Binary Search) 與前綴和 (Prefix Sum) / 雙指標】

本題如果直接窮舉所有可能的連續區間和，總共有 \frac{N(N+1)}{2} 種組合。當 N = 5 × 105 時，區間總數高達約 1.25 × 1011 個，直接排序或窮舉會造成時間與記憶體極大超支。

  • 二分搜尋法（Binary Search）： 由於所有建物的損失 di ≥ 0，連續區間和的範圍介於 0 到所有建物總和（最大可能值為 5 × 1014）之間。我們可以對「嚴重程度 m」進行二分搜尋。
  • 條件判定與雙指標（Two Pointers）： 對於猜測的嚴重程度 m，我們需要快速計算「有多少個連續區間的和大於 m」。利用前綴和陣列（`prefixsum`），對於每個左端點 i，我們可以利用單調性透過雙指標（或 upperbound）迅速找到滿足 prefixsum[j] - prefixsum[i-1] > m 的最小右端點 j，從而得知以 i 為左端點且和小於等於 m 的區間數量，進而算出大於 m 的區間總數 count。
  • 若 count < K，代表大於 m 的狀況不夠 K 個，也就是第 K 大的嚴重程度小於等於 m，故收斂右界 r = m；否則代表大於 m 的狀況大於或等於 K 個，答案在右半部，收斂左界 l = m + 1。時間複雜度可降至 O(N log(Sum))，能完美通過測資。

【輸入範例 1 實際運作推導】

輸入：
3 2
1 2 4
  • 資料與前綴和：
    • 建物損失陣列 d = [1, 2, 4]
    • 前綴和陣列 prefixsum = [0, 1, 3, 7]
    • 總區間數 = \frac{3 × 4}{2} = 6 種。
  • 所有連續區間及其嚴重程度（總和）：
    1. 區間 [1, 3] (1 ~ 3)：1 + 2 + 4 = 7
    2. 區間 [2, 3] (2 ~ 3)：2 + 4 = 6
    3. 區間 [3, 3] (3 ~ 3)：4
    4. 區間 [1, 2] (1 ~ 2)：1 + 2 = 3
    5. 區間 [2, 2] (2 ~ 2)：2
    6. 區間 [1, 1] (1 ~ 1)：1
  • 由大到小排序： 7, 6, 4, 3, 2, 1。
  • 尋找第 K=2 大： 排序後第 2 個值為 6。

👉 輸出範例 1 結果： 6

輸入：

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <vector> // 引入 std::vector 動態陣列標頭檔
#include <stdio.h> // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf

int main() {
	
	long long N, K; // 宣告長整數變數 N (建物數量) 與 K (想查詢第 K 大的嚴重程度排名)
	scanf("%lld%lld", &N, &K); // 讀入 N 與 K
	
	std::vector<long long> d(N+1), prefixsum(N+1); // 宣告大小為 N+1 的向量 d 儲存每個建物損失，prefixsum 儲存前綴和
	for (int i = 1; i <= N; ++i) { // 使用迴圈依序讀入每個建物的損失值
		scanf("%lld", &d[i]); // 讀入第 i 個建物的損失
		prefixsum[i] = d[i] + prefixsum[i-1]; // 計算並儲存截至第 i 個建物的累積前綴和
	}
	
	long long l = 0, r = prefixsum[N]; // 設定二分搜的搜尋範圍：左界 l 從 0 開始，右界 r 為全部建物的總和（prefixsum[N]）
	while (l != r) { // 當左界不等於右界時持續進行二分搜尋
		long long m = (l + r) / 2, count = 0; // 計算中間值 m 作為嘗試的嚴重程度門檻，並初始化大於 m 的區間計數 count 為 0
		
		for (int i = 1, j = 1; i <= N; ++i) { // 使用雙指標法遍歷所有可能的區間左端點 i 與右端點 j
			while (j <= N && prefixsum[j]-prefixsum[i-1] <= m) { // 當右端點 j 在範圍內且以 i 為左端點、j 為右端點的區間和不大於 m 時
				++j; // 將右端點 j 向右移動以擴大區間和
			}
			if (prefixsum[j]-prefixsum[i-1] > m) { // 若當前區間和小於等於 m 的迴圈停止後，該區間和大於 m
				count += (N - j + 1); // 則以 i 為左端點、右端點從 j 到 N 的所有子區間和皆大於 m，將數量 (N - j + 1) 累加至 count
			}
		}
		
		if (count < K) { // 若大於 m 的區間總數小於 K，代表第 K 大的嚴重程度小於或等於 m
			r = m; // 將右界收縮至 m
		}
		else { // 若大於 m 的區間總數大於或等於 K，代表第 K 大的嚴重程度大於 m
			l = m + 1; // 將左界提升至 m + 1
		}
	}
	
	printf("%lld\n", l); // 當二分搜收斂時（l == r），輸出第 K 大的嚴重程度結果 l 與換行
	
}
