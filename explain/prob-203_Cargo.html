#203 202305Cargo (載運貨物)

題目摘要

問題敘述： 有 N 箱貨物由左至右排成一列，重量分別為 W1, W2, …, WN。運送規則如下：

  • 裝載規則： 只能由最左端開始依序取貨，即必須劃分成連續的區間裝車。
  • 重量限制： 每趟貨車的載運總重量必須介於下限 L 與上限 U 之間（即 L ≤ 每車載重 ≤ U）。

求有多少種合法的分裝載運方式，能夠將全部貨物運送完畢。答案請輸出除以 109 + 7 的餘數。

輸入格式：
第一列包含三個整數：N（貨物數量）、L（每車最小載重）、U（每車最大載重）。
第二列包含 N 個正整數 W1, W2, …, WN 代表各箱貨物的重量。

輸出格式： 輸出一非負整數，代表合法的分裝方案總數 ±od{109 + 7}。

演算法推導解析：【前綴和優化 DP + 雙指標滑動窗口】

若採用樸素動態規劃，令 dp[i] 為前 i 箱貨物完成載運的方法數，其轉移方程為：

$dp[i] = ∑j dp[j] 其中 L ≤ ∑k=j+1i Wk ≤ U$

若暴力窮舉分割點 j，單次轉移耗時 O(N)，總時間複雜度達 O(N2)，面對 N = 2 × 105 的規模會發生執行逾時 (TLE)。因此需進行兩階段結構優化：

  • 單調性與雙指標定位： 由於所有貨物重量 Wi > 0，前綴和具備嚴格單調遞增特性。對於當前結尾 i，合法的上一趟結尾索引 j 必為連續區間 [left, right)，使得區間和落在 [L, U] 內。藉由維護兩個單調不退回的指標 left 與 right，整體搜尋均攤為 O(N)。
  • 前綴和差分轉移： 在前綴和陣列上維護 DP 累積值，區間內所有 dp[j] 的和即可透過 O(1) 差分常數取得。

PDF 原題範例深度解析

輸入範例 1：標準分裝狀態 合法方案：2 種
輸入 (Input) 
5 4 8
3 5 4 3 4
輸出 (Output) 
2
邏輯拆解與推導：

載重限制為 4 ≤ 重量 ≤ 8。貨物重量序列為 [3, 5, 4, 3, 4]。

  1. 方案一：
    • 第一車：載運第 1, 2 箱 → 3 + 5 = 8 公斤（符合 [4, 8]）
    • 第二車：載運第 3 箱 → 4 公斤（符合 [4, 8]）
    • 第三車：載運第 4, 5 箱 → 3 + 4 = 7 公斤（符合 [4, 8]）
  2. 方案二：
    • 第一車：載運第 1, 2 箱 → 3 + 5 = 8 公斤（符合 [4, 8]）
    • 第二車：載運第 3, 4 箱 → 4 + 3 = 7 公斤（符合 [4, 8]）
    • 第三車：載運第 5 箱 → 4 公斤（符合 [4, 8]）

若第一車嘗試只載第 1 箱 (3kg)，重量不足 L=4；若嘗試載 1, 2, 3 箱 (3+5+4=12kg)，超過 U=8。因此第一車唯一合法裝法為載第 1、2 箱。後續衍生出 2 種合法組合，最終輸出 2。

輸入範例 2：邊界阻斷無解 無解方案：0 種
輸入 (Input) 
5 4 7
3 5 4 3 4
輸出 (Output) 
0
邏輯拆解與推導：

載重限制為 4 ≤ 重量 ≤ 7。貨物重量序列同為 [3, 5, 4, 3, 4]。

  • 檢視開頭貨物的分裝可能性：
    • 第一車只載貨物 1：重量為 3 公斤，小於下限 L = 4（不可行）。
    • 第一車載貨物 1 與 2：重量為 3 + 5 = 8 公斤，大於上限 U = 7（不可行）。
    • 第一車載更多貨物：重量只會持續遞增，全部超重。
  • 結論： 第一箱貨物根本無法找到任何符合法規的裝載組合起運，整趟運送流程在一開始即中斷，合法方法數為 0。
輸入範例 3：長序列連續組合分支 合法方案：8 種
輸入 (Input) 
11 3 7
2 1 4 3 1 2 2 3 4 2 5
輸出 (Output) 
8
邏輯拆解與推導：

N = 11，載重區間為 [3, 7]。貨物小且密集，存在多處重疊的分車界線：

  • 第一車可能劃分：
    • 載前 2 箱 [2, 1] → 3 公斤（符合 [3, 7]）
    • 載前 3 箱 [2, 1, 4] → 7 公斤（符合 [3, 7]）
  • DP 狀態遞迴累加： 當序列來到中間，例如重量序列 ... 1, 2, 2, 3 ... 時，既可將 [1, 2] 湊為 3kg，亦可將 [1, 2, 2] 湊為 5kg 或 [2, 2, 3] 湊為 7kg。雙指標在每一點動態框選出合法的前驅節點，狀態分支逐步擴展，經模運算後最終統計得 8 種合法配置。
輸入範例 4：大件單品箝制分割點 合法方案：2 種
輸入 (Input) 
8 2 7
3 1 6 5 4 2 7 4
輸出 (Output) 
2
邏輯拆解與推導：

N = 8，載重區間為 [2, 7]。序列中包含較大單件貨物（如 6, 7）：

  • 關鍵瓶頸分析：
    • 第 3 箱重 6 公斤：本身就逼近上限 7，若與第 2 箱(1kg)合併恰為 7kg；若單獨成車為 6kg。但若與前後任意其他貨物再湊合即刻超重。
    • 第 7 箱重 7 公斤：重量恰好等於最大上限 U = 7，這意味著第 7 箱必須且只能單獨成一車，無法與左側第 6 箱(2kg)或右側第 8 箱(4kg)合載。
  • 大件貨物直接將整個排列切割為局部的獨立區段，收斂了分裝分支，最終合法分裝數為 2。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <cstdio>     // 引入標準輸入輸出函式庫，使用高效能的 scanf 與 printf
#include <algorithm>  // 引入常用演算法庫

const int maxn = 200000 + 5;        // 定義資料規模上限 N <= 200000
const int MOD = 1000000000 + 7;     // 定義題目要求的取模常數 109 + 7
typedef long long ll;               // 定義 64 位元長整數型態避免溢位
using namespace std;

int solve(int n, int l, int u, const int *w)
{
    static int dp[maxn + 1];    // dp[i] 代表前 i 箱貨物分裝完成的方法數
    static int preW[maxn + 1];  // preW[i] 代表前 i 箱貨物的重量前綴和
    
    int left = 0, right = 0;    // 雙指標：維護符合載重 [L, U] 的合法前驅索引範圍 [left, right)
    
    preW[0] = 0;
    for (int i = 0; i < n; ++i)
    {
        preW[i + 1] = preW[i] + w[i]; // 建立前綴和陣列，使區間重量查詢降為 O(1)
    }
    
    dp[0] = 0; // 邊界初始條件
    dp[1] = 1; // 基礎狀態初始化
    
    for (int i = 0; i < n; ++i)
    {
        // 若當前區間重 preW[i + 1] - preW[left] 超過上限 U，移動 left 縮小區間
        while (preW[i + 1] - preW[left] > u)
        {
            ++left;
        }
        // 若當前區間重 preW[i + 1] - preW[right] 達到下限 L，推進 right 擴展合法界限
        while (preW[i + 1] - preW[right] >= l)
        {
            ++right;
        }
        
        // 將上一階段的 dp 和滾動累加到當前前綴
        dp[i + 1] = (dp[i + 1] + dp[i]) % MOD;
        // 透過差分區間 [left, right) 快速轉移狀態到 dp[i + 2]
        dp[i + 2] = (dp[right] - dp[left] + MOD) % MOD;
    }
    
    return dp[n + 1]; // 回傳完成前 n 箱貨物運送的所有合法方法數
}

int main()
{
    int n, l, u;
    static int w[maxn];
    
    // 讀取貨物總數 n、最小載重 l、最大載重 u
    if (scanf("%d%d%d", &n, &l, &u) != 3) return 0;
    
    // 依序讀入每箱貨物的重量
    for (int i = 0; i < n; ++i)
    {
        scanf("%d", &w[i]);
    }
    
    // 計算並輸出答案
    printf("%d\n", solve(n, l, u, w));
    
    return 0;
}
