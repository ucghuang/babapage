#48 201912_A2-Cut (空間切割)

PDF: 201912_A2-Cut.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 在一維空間中，對空間進行一次切割，稱為一刀，會使得空間變為二塊區域。而後我們每次再對空間進行切割，都只能再增加一塊區域，也就是一刀二塊，二刀三塊，三刀四塊等等，以此類推。但在更高維的空間中，每切割一次，不一定只增加一個區域，像在二維空間中，一刀最多會有二塊，二刀四塊，三刀七塊等等。請寫一個程式，計算 D 維空間中切割 N（原題為 C）次能分出來最多的區域個數。

輸入格式： 第一列為一個正整數 N (1 ≤ N ≤ 104)，代表要計算的資料筆數。接著 N 列，每一列有兩個正整數，以一個空白隔開，代表空間維度 D (1 ≤ D ≤ 50) 與切割的次數 C (1 ≤ C ≤ 50)。

輸出格式： 對每筆資料輸出 N 列，每一列為該情況下能切割出的最多區域數。

評分說明：

  • 第一組 (10 分) : 1 ≤ N ≤ 10、1 ≤ D ≤ 2、1 ≤ C ≤ 5。
  • 第二組 (30 分) : 1 ≤ N ≤ 10、1 ≤ D ≤ 3、1 ≤ C ≤ 5。
  • 第三組 (60 分) : 1 ≤ N ≤ 104、1 ≤ D ≤ 50、1 ≤ C ≤ 50。

演算法使用解析：【動態規劃 (Dynamic Programming) 與組合遞迴】

本題探討在 D 維空間中切割 C 次所能產生的最多區域個數 P(D, C)。透過組合數學與遞迴關係式：

  • 遞迴關係式： P(D, C) = P(D, C-1) + P(D-1, C-1)
  • 邊界條件：
    • 當切割次數 C = 0 時，任何維度 D 的區域數皆為 1 (P(D, 0) = 1)。
    • 當空間維度 D = 0 時，切割 C 次的區域數皆為 1 (P(0, C) = 1)。
  • 效能優化： 由於測資範圍 D ≤ 50、C ≤ 50，且查詢筆數高達 104，我們可利用動態規劃（二維陣列預處理）在 O(D × C) 時間內預先算出所有可能答案，後續每次查詢僅需 O(1) 時間輸出，完美應對大量測資。

二維 DP 狀態矩陣與幾何轉移視覺化

透過橫軸（切割次數 C）與縱軸（空間維度 D）建構表格，可以清楚看出每一格 DP[D][C] 的來源就是其正左方一格加上左上一格：

維度 D \ 切次 C C = 0 C = 1 C = 2 C = 3 C = 4 C = 5
D = 0 (零維:點) 1 1 1 1 1 1
D = 1 (一維:線) 1 2 3 4 5 6
D = 2 (二維:面) 1 2 4 7 11 16
D = 3 (三維:體) 1 2 4 8 15 26
D = 4 (四維超空間) 1 2 4 8 16 31
目標計算格（以 DP[2][3] = 7 為例）
來源相加格（DP[2][2]=4 與 DP[1][2]=3）
  • 結構拆解邏輯： DP[2][3] = DP[2][2] (前 2 刀原有區域 (4)) + DP[1][2] (第 3 刀被前 2 刀分割出的段數 (3)) = 7 塊。
  • 物理意涵： 在 D 維空間切下第 C 個超平面時，該平面自身被前 C-1 次切割截出最多 DP[D-1][C-1] 個 D-1 維子區域；而每一個子區域都會將原本的空間一分為二，恰好多創造出一個全新區域。
  • 組合學關聯： 此規律即為巴斯卡三角形每行累加前 D 項之和：P(D, C) = ∑k=0D C(C, k)。當 C ≤ D 時，切刀數不足以受限於維度，區域數恆為 2C（如 1, 2, 4, 8, 16…）。

課堂黑板板書推導

【遞迴狀態轉移推導範例】

依據公式 P(D, C) = P(D, C-1) + P(D-1, C-1)，我們以範例測資進行逐步推導：

  • 計算 P(1, 1)： P(1, 1) = P(1, 0) + P(0, 0) = 1 + 1 = 2
  • 計算 P(1, 2)： P(1, 2) = P(1, 1) + P(0, 1) = 2 + 1 = 3
  • 計算 P(2, 2)： P(2, 2) = P(2, 1) + P(1, 1) = 2 + 2 = 4（其中 P(2, 1) = P(2, 0) + P(1, 0) = 1 + 1 = 2）
  • 計算 P(2, 3)： P(2, 3) = P(2, 2) + P(1, 2) = 4 + 3 = 7
  • 計算 P(3, 3)： P(3, 3) = P(3, 2) + P(2, 2) = 4 + 4 = 8

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<bits/stdc++.h> // 引入標準函式庫標頭檔，包含輸入輸出與常用演算法
using namespace std; // 使用標準命名空間 std，避免重複寫 std::

long long int DP[105][105] ={0}; // 宣告一個 105x105 的二維長整數陣列 DP，並初始化為 0，用來儲存 D 維空間切割 C 次的最大區域數

int main(){ // 主程式開始
	for(int i=0;i<=50;i+=1){ // 當維度 i 從 0 到 50 遞增時
		DP[i][0] = 1; // 任何維度 i 切割 0 次的區域數皆為 1
		DP[0][i] = 1; // 0 維空間切割 i 次的區域數皆為 1
	}
	
	for(int i=1;i<=50;i+=1){ // 外層迴圈：維度 i 從 1 到 50
		for(int j=1;j<=50;j+=1){ // 內層迴圈：切割次數 j 從 1 到 50
			DP[i][j] = DP[i][j-1] + DP[i-1][j-1]; // 狀態轉移方程式：P(D, C) = P(D, C-1) + P(D-1, C-1)
		}
	}
	
	int N; // 宣告整數 N，用來儲存查詢的資料筆數
	cin >> N; // 讀入查詢筆數 N
	
	while(N--){ // 當 N 大於 0 時，每次迴圈將 N 減 1，處理每一筆測資
		int D,C; // 宣告整數 D（維度）與 C（切割次數）
		cin >> D >> C; // 讀入當前測資的維度 D 與切割次數 C
		cout <<DP[D][C] << endl; // 輸出查表得到的最多區域個數並換行
	}
} // 主程式結束
