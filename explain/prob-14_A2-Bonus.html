題目摘要與規格解析

情境敘述： 戀愛遊戲中，玩家從初始階段 S0 開始，透過經歷各種不同事件轉移至後續階段，最終抵達結局階段 SN-1。公司需要統計從起點到終點所有可能經歷的不同劇情路線總數 R，以此作為收費公式的核心變數。

  • 無環特性 (DAG)： 題目規定「玩家最多僅能經歷一次任意階段，沒有任何事件能回到曾走過的階段」，這說明圖中絕對不存在環（No Cycle），保證為有向無環圖（Directed Acyclic Graph, DAG）。
  • 單一單向流： 始終從 S0 出發，在 SN-1 結束，且保證路徑數 R ≥ 1，無重邊。
  • 測資規模：
    • 第一組 (10%)：2 ≤ N ≤ 100
    • 第二組 (30%)：2 ≤ N ≤ 50,000
    • 第三組 (60%)：2 ≤ N ≤ 1,000,000，邊數 N-1 ≤ E ≤ 2N。百萬級別的節點數要求演算法必須在 O(N + E) 線性時間內完成，嚴禁任何無記憶化的指數型回溯暴搜。

演算法本質：DAG 動態規劃與反向記憶化搜尋

在有向無環圖 (DAG) 中，計算從源點 S0 到各節點的總路徑數具備嚴格的無後效性與最優子結構：

動態規劃狀態轉移核心公式：
對於圖中任一節點 v，到達該節點的路線總數 R[v] 等於所有能一步走到它的前置節點（前驅點集 Pred(v)）之路線數總和：
R[v] = ∑u ∈ Pred(v) R[u]，且邊界條件為 R[0] = 1

反向建圖技巧（Reverse Edge Technique）：

  • 建圖方式： 當輸入一條從 t1 → t2 的邊時，原始解答使用 Edge[t2].push_back(t1) 建立反向邊。這表示 Edge[v] 儲存的是「可以走到 v 的所有前置節點」。
  • 搜尋邏輯： 從終點 DFS(N-1) 發動，程式會沿著反向邊逐步向前探索，直到碰到已知基底狀態 R[0] = 1，接著回溯累加，並把結果記錄在 R[cur]。
  • 剪枝與避免重複（記憶化）： 每個節點只需完整探索一次。若 R[u] > 0，代表該點已經計算出路線數，直接取值累加，不進入重複遞迴，保證時間複雜度被嚴格壓制在 O(N + E)。

【範例 3：邊界極端結構】單一直線鏈 vs 二分鑽石圖 (Diamonds)

為驗證程式在各種極端結構下的穩定度與空間時間開銷，我們考察以下兩種典型結構：

情況 A：單一路徑鏈條（Minimal Branches）

若輸入為 0 → 1 → 2 → ... → N-1，僅有 N-1 條邊。DFS 從終點一路遞迴深搜回起點，每一層累加 1，最終 R[N-1] = 1。遞迴深度達到 N，因此在百萬測資時，C++ 編譯環境需具備足夠的 Stack 空間。

情況 B：連續菱形結構（Exponential Growth）

若每兩個節點之間都形成雙分叉鑽石菱形結構（例如 S2k 同時連到 S2k+1 與 S2k+2，再匯入下一層），路線總數將呈指數級成長（2k）。 此時 long long 能夠防止在數值高達 263 - 1 前發生溢位。原解法採用的 long long R[] 能確保大量組合數時的計算正確性。

參考解答 C++ 完整原始碼與教學註解

💡 實作重點提示： 本程式使用 vector<int> Edge[] 建立反向鄰接表（將目標指向來源），並初始化 R[0] = 1。透過記憶化 DFS，確保每個節點只會被展開一次，整體執行時間為嚴格的線性時間 O(V + E)，完美通過百萬階測資。 

#include <bits/stdc++.h>  // 引入標準函式庫 (包含 vector, iostream 等)

// 宣告反向鄰接表：Edge[v] 儲存所有能夠「一步走向 v」的前置節點 (Predecessors)
// 題目的階段數量 N 最大可達 1,000,000，陣列空間設定 1000005 以防越界
std::vector<int> Edge[1000005];

// 宣告路線數記憶化陣列 R
// R[0] = 1 代表起始階段 S0 自成 1 條路線 (遞迴基準條件 Base Case)
// 其餘 R[i] 預設初始化為 0，表示「該階段路線數尚未被計算」
long long R[1000005] = {1};

/**
 * DFS 記憶化搜尋函式
 * @param cur 目前欲計算總路線數的目標階段編號
 */
void DFS(int cur)
{
    int n = Edge[cur].size();  // 取得該節點的所有前置節點數量

    // 遍歷所有能走向 cur 的前驅階段
    for (int i = 0; i < n; i += 1)
    {
        int prev_node = Edge[cur][i];

        // 如果前置節點的路線總數尚未計算過 (數值為 0)，先遞迴深搜計算該節點
        if (R[prev_node] == 0)
        {
            DFS(prev_node);
        }

        // 累加所有前置節點的路線數至目前節點
        R[cur] += R[prev_node];
    }
}

int main()
{
    // 加速標準 I/O 串流讀取速度
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(NULL);

    int S, E;
    if (!(std::cin >> S >> E)) return 0;  // 讀入階段數 S (即 N) 與事件邊數 E

    for (int i = 0; i < E; i += 1)
    {
        int t1, t2;
        std::cin >> t1 >> t2;  // 讀入一條單向事件邊：從階段 t1 進入階段 t2
        Edge[t2].push_back(t1);  // 建立反向邊：將 t1 加入到 t2 的前驅列表中
    }

    // 從最後一個結局階段 (編號 S - 1) 開始進行反向記憶化搜尋
    DFS(S - 1);

    // 輸出結局階段所匯集出的總通關路線數 R
    std::cout << R[S - 1] << std::endl;

    return 0;
}
