題目摘要

問題敘述： 戀愛遊戲中玩家要從初始階段 S0 經過多個事件選擇到達結局階段 SN-1。每條路線不能重複造訪同一個階段。給定 N 個階段與 E 條事件導向邊，請計算總共有多少條不同的通關路線數 R。

輸入格式： 第一列有兩個正整數 N 及 E (2 ≤ N ≤ 106)；接著 E 列每列有兩個整數 i、j，表示存在事件可從階段 Si 進入階段 Sj。

輸出格式： 輸出一個正整數 R，代表從初始階段到結局階段的總路線數。

演算法使用解析：【圖論演算法與記憶化搜尋 / DFS】

本題採用圖論深度優先搜尋 (DFS) 與記憶化 (Memoization) 策略：

  • 由於遊戲是有向無環圖 (DAG)，我們可以從終點階段 SN-1 出發，透過反向建立邊（從終點往回推導至起點）來計算到達各點的路線數。
  • 利用記憶化陣列 R[cur] 記錄已經計算過的節點路線數，若該節點已經算過則直接回傳，避免重複遞迴導致時間超時 (TLE)。

  • 圖形結構分析： 總共有 9 個階段（編號 0 到 8），起點為 S0，終點為 S8。
  • 反向邊與遞迴追溯過程：
    • 我們從終點 S8 出發，找出能通往 S8 的前置階段有：S2、S5、S6。
    • 因此 S8 的總路線數等於這三個前置階段路線數的加總：R[8] = R[2] + R[5] + R[6]。
    • 我們依序遞迴往前計算：
      • S6 的前置有 S4 和 S7（皆可通往 S6）。
      • S4 的前置有 S1 和 S3。
      • S1, S3, S7, S2, S5 的前置皆可追溯回初始起點 S0（起始點路線數 R[0] = 1）。
    • 透過記憶化 DFS 逐層加總回傳，最終在 S8 匯集得到總路線數為 5。

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<bits/stdc++.h>  // 引入常用 C++ 標頭檔

std::vector<int> Edge[1000005];  // 宣告鄰接表，用來儲存圖形中每個階段的前置或後續事件邊
long long R[1000005]={1};  // 宣告記憶化陣列 R，記錄到達各階段的路線總數，初始將起點設為 1

// DFS 函式：遞迴尋找並計算從當前節點出發的總路線數
void DFS(int cur)
{
    int n=Edge[cur].size();  // 取得與當前節點相連的邊數量
    for(int i=0;i<n;i+=1)
    {
        // 若目標鄰居節點的路線數尚未被計算過（等於 0）
        if (R[Edge[cur][i]]==0)
            DFS(Edge[cur][i]);  // 遞迴先計算該鄰居節點的路線數（記憶化搜尋）
            
        R[cur]+=R[Edge[cur][i]];  // 將鄰居節點的路線數累加到當前節點中
    }
}

int main()
{
    int S,E;
    std::cin>>S>>E;  // 讀入階段總數 S 與事件邊總數 E
    for(int i=0;i<E;i+=1)
    {
        int t1,t2;
        std::cin>>t1>>t2;  // 讀入每一條事件邊連接的兩個階段 t1 與 t2
        Edge[t2].pushback(t1);  // 建立反向邊，方便從終點往回推導路線
    }
    
    DFS(S-1);  // 從最終結局階段（編號 S-1）開始進行 DFS 搜尋
    
    std::cout<<R[S-1]<<std::endl;  // 輸出從起點到終點的總路線數 R
}
