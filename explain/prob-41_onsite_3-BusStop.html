題目摘要

問題敘述： 公車路線共有 B 個站牌（編號 1 … B），來回行駛。給定 P 位乘客的上下車起訖站 X 與 Y，每位乘客會經過介於 X 與 Y 之間的所有站牌。請統計經過各站牌的人流數量，並找出最少人流與最多人流的公車站牌編號。

  • 輸入格式： 第一行輸入兩個正整數 B（站牌數）與 P（乘客數）。接下來 P 行，每行有兩個正整數 X 與 Y[cite: 1]，代表乘客的上車與下車站牌。
  • 輸出格式： 輸出兩個正整數，以一個空白隔開：分別為最少人流之公車站牌編號（若有多個取編號最小者）以及最多人流之公車站牌編號（若有多個取編號最大者）[cite: 1]。

演算法使用解析：【前綴和與區間頻率統計思路】

本題在教學上屬於經典的「前綴和」與「區間標記」的基礎應用（難度評級：2 星 ★★☆☆☆）。其核心思路與設計邏輯如下：

  • 區間累加的概念： 每當有一位乘客從站牌 X 搭到 Y 時[cite: 1]，公車會行經介於 X 與 Y 之間的所有站牌。這意味著我們需要對一段連續的區間 [ min(X, Y), max(X, Y) ] 內的每一個站牌人流計數器全部加 1。
  • 前綴和/差分思想的雛形： 在處理多次區間更新與點查詢的場景中，最直觀的作法是利用迴圈將區間內每個位置加上權重。當資料量較小時，直接透過迴圈對陣列區間做累加（即本題解答採用的直接區間標記法，也是前綴和與差分陣列的核心應用場景）即可完美對應。
  • 極值尋找策略： 在統計完所有站牌的人流後，透過一次線性掃描（Linear Scan），由左至右找出最小值與最大值對應的索引，並嚴格遵守題目「最小編號取最小、最大編號取最大」的 tie-breaking 條件[cite: 1]。

課堂黑板板書推導（涵蓋全數三個輸入範例）

【輸入範例 1 實際運作推導】[cite: 1]

輸入：
8 3
2 7
5 3
5 8
  • 初始狀態： 共有 B = 8 個站牌，乘客數 P = 3[cite: 1]。人流統計陣列 Stop 初始化為全 0。
  • 處理第 1 筆乘客 (2 7)： 行經區間 [2, 7]，將站牌 2, 3, 4, 5, 6, 7 的人流各 +1。當前陣列：[0, 1, 1, 1, 1, 1, 1, 0]
  • 處理第 2 筆乘客 (5 3)： 起訖點順序調整為 [3, 5]，將站牌 3, 4, 5 的人流各 +1。當前陣列：[0, 1, 2, 2, 2, 1, 1, 0]
  • 處理第 3 筆乘客 (5 8)： 行經區間 [5, 8]，將站牌 5, 6, 7, 8 的人流各 +1。最終陣列：[0, 1, 2, 2, 3, 2, 2, 1]（對應索引 1 到 8）
  • 尋找極值： 最少人流為 0（1 號站牌），最多人流為 3（5 號站牌）[cite: 1]。

    • (1 5) → 1~5 各 +1
    • (10 5) → 5~10 各 +1
    • (4 2) → 2~4 各 +1

    • (7 10) → 7~10 各 +1
    • (2 4) → 2~4 各 +1
    • (10 8) → 8~10 各 +1
    • (8 9) → 8~9 各 +1
  • 統計與極值： 經過全體 9 筆區間累加後，全體站牌人流的最小值出現在 1 號站牌（人流最少），最大值出現在 9 號站牌（人流最多）[cite: 1]。

【輸入範例 3 實際運作推導】[cite: 1]

輸入：
1000 2
1 1000
1 1000
  • 初始狀態： 共有 B = 1000 個站牌，乘客數 P = 2[cite: 1]。
  • 處理第 1 筆乘客 (1 1000)： 從 1 號站一路搭到 1000 號站，使全體 1 … 1000 號站牌人流各 +1。
  • 處理第 2 筆乘客 (1 1000)： 重複一次，使全體 1 … 1000 號站牌人流再各 +1。
  • 尋找極值：此時所有站牌的人流皆為 2。依據題意：
    • 最少人流發生在多個站牌（值皆為 2），取編號最小者 → 1 號。
    • 最多人流發生在多個站牌（值皆為 2），取編號最大者（題目要求若有多個最多人流則輸出編號最大者） → 1000 號[cite: 1]。

1 1000[cite: 1]

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <stdio.h> // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf

int main()
{
    int B, P; // 宣告整數 B 代表總站牌數，P 代表乘客總人數
    scanf("%d %d", &B, &P); // 讀入站牌數 B 與乘客數 P
    
    int Stop[1001] = {0}; // 宣告大小為 1001 的陣列 Stop 用來記錄每個站牌經過的人流數，並全部初始化為 0
    
    for(int i = 1; i <= P; i += 1) // 透過迴圈處理每一位乘客的搭車需求，共執行 P 次
    {
        int X, Y; // 宣告變數 X 與 Y 分別代表上車站牌與下車站牌
        scanf("%d %d", &X, &Y); // 讀入當前乘客的起訖站
        
        if(X > Y) // 檢查若上車站大於下車站（代表反向行駛或編號大小顛倒）
        {
            int tmp = X; // 利用暫存變數 tmp 進行數值交換
            X = Y;
            Y = tmp; // 確保 X 永遠是起點（較小編號）、Y 永遠是終點（較大編號）
        }
        
        for(int j = X; j <= Y; j += 1) // 遍歷從起點 X 到終點 Y 的所有區間站牌
        {
            Stop[j] += 1; // 該站牌的人流計數器加 1（實踐區間標記與前綴和累加邏輯）
        }
    }

    int MinS = 1000, MaxS = 1; // 初始化最小人流閥值為大數，最大人流閥值為 1
    int MinSIndex = 1000, MaxSIndex = 1; // 初始化記錄最少與最多人流的站牌編號
    
    for(int i = 1; i <= B; i += 1) // 從 1 號站牌到 B 號站牌依序檢查人流統計結果
    {
        if(Stop[i] < MinS) // 若當前站牌人流小於目前記錄的最小值
        {
            MinS = Stop[i]; // 更新最小人流數
            MinSIndex = i; // 更新最少人流的站牌編號
        }

        if(Stop[i] >= MaxS) // 若當前站牌人流大於或等於目前記錄的最大值（使用 >= 確保有多個最大時取編號最大者）
        {
            MaxS = Stop[i]; // 更新最大人流數
            MaxSIndex = i; // 更新最多人流的站牌編號
        }
    }

    printf("%d %d", MinSIndex, MaxSIndex); // 輸出最少人流站牌編號與最多人流站牌編號，中間以空白隔開[cite: 1]
    return 0; // 程式正常結束
}
