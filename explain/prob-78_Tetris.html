#78 202008Tetris (俄羅斯方塊)

題目摘要

問題敘述： 模擬俄羅斯方塊遊戲中 T 型方塊的移動與旋轉。給定畫面大小 x × y，起始時方塊錨點位於 (\lceil x/2 \rceil, y)。遊戲中有 5 種指令（代號 0 到 4）：

  • 0： 無指令（維持方向）
  • 1： 右移
  • 2： 左移
  • 3： 置底
  • 4： 右旋

每送出一個指令，方塊會先向下移動一格，再執行指令效果。若指令執行後超出邊界（不合法），則該指令必須視為 0 號指令（即只往下移一格而不做額外平移或旋轉）。請輸出方塊執行完所有指令後的最終畫面矩陣（1 代表有方塊，0 代表無方塊）。

輸入格式： 第一行有兩個整數 x, y (3 ≤ x, y ≤ 100)。第二行有一個整數 n (1 ≤ n < y) 代表指令數。第三行有 n 個整數代表各個指令。

輸出格式： 輸出遊戲執行完所有指令後的 y × x 畫面。

演算法使用解析：【幾何模擬與狀態追蹤】

本題為座標幾何與狀態模擬題，核心實作重點如下：

  • 方塊建模： 以錨點 (cx, cy) 與旋轉方向 cori（0~3）來完整描述 T 型方塊的狀態。透過相對座標偏移量陣列 tbias 計算 4 個組成方格的絕對座標。
  • 防呆與邊界檢查： 每次移動或旋轉前，使用 checkt 檢查 4 個方格是否完全落在遊戲區範圍內（1 ≤ x' ≤ x 且 1 ≤ y' ≤ y）。
  • 防呆降級機制： 若帶有平移或旋轉的指令導致超出邊界，程式會自動將其降級為 0 號指令（即僅向下移動一格）。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
6 6
3
0 1 3
  • 畫面大小 6 × 6，初始錨點為 ( (6+1)/2, 6 ) = (3, 6)。
  • 依序執行指令 `0`、`1`、`3`，每次移動前先下移一格，並進行邊界檢驗與防呆降級。
  • 最終計算出方塊落下的 4 個格子位置，並由上到下輸出 6 × 6 矩陣畫面。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <iostream> // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout
#include <assert.h> // 引入斷言標頭檔，用於防呆與除錯

using namespace std; // 使用標準命名空間 std

/*
    T 型方塊在 4 種不同旋轉方向 (0~3) 下，相對於錨點 (center) 的 4 個方格相對座標偏移量
*/
int tbias[4][4][2]={
    {{ 0, 0},{ 0,-1},{-1, 0},{ 1, 0}},
    {{ 0, 0},{-1, 0},{ 0, 1},{ 0,-1}},
    {{ 0, 0},{ 0, 1},{-1, 0},{ 1, 0}},
    {{ 0, 0},{ 1, 0},{ 0, 1},{ 0,-1}}
};

// 檢查某個座標 (cx, cy) 是否落在遊戲格子範圍 (1~x, 1~y) 內
bool checkgrid(int cx,int cy,int x,int y)
{
    return 0<cx && cx<=x && 0<cy && cy<=y;
}

// 檢查在給定錨點與旋轉方向下，T 型方塊的 4 個格子是否全部合法（未超出邊界）
int checkt(int cx,int cy,int cori,int x,int y)
{
    for(int i=0;i!=4;i++)
        if(!checkgrid(cx + tbias[cori][i][0],cy + tbias[cori][i][1],x,y))
            return false;
    return true;
}

// 執行安全移動：方塊先嘗試下移並套用指令動作；若超出邊界則退回僅向下移動一格
void safemove(int &cx,int &cy,int &cori,int x,int y,int move)
{
    // 5 種指令對應的 (x 軸偏移, y 軸偏移, 旋轉角度改變)
    int bias[5][3] = {
        { 0,-1, 0}, // 0: 無指令（僅下移）
        { 1,-1, 0}, // 1: 右移一格並下移
        {-1,-1, 0}, // 2: 左移一格並下移
        { 0,(cori==2)? -cy+1:-cy+2, 0}, // 3: 置底
        { 0,-1, 1}  // 4: 右旋 90 度並下移
    };
    // 嘗試執行指令後的完整移動
    if(checkt(cx + bias[move][0],cy+ bias[move][1],(cori+ bias[move][2])%4,x,y))
    {
        cx += bias[move][0];
        cy += bias[move][1];
        cori=(cori+ bias[move][2])%4;
    }
    else if(checkt(cx,cy-1,cori,x,y)) // 若指令不合法（超出邊界），則視為 0 號指令（僅向下移動一格）
    {
        cy --;
    }
    else
    {
        assert(false); // 若連單純下移都不合法，觸發斷言
    }
}

int main()
{
    int x,y,csize; // 宣告 x（橫軸寬度）、y（縱軸高度）、csize（指令總數）
    cin >> x >> y; // 讀入畫面大小 x 與 y
    cin >> csize; // 讀入指令數目 csize
    int cs[csize]; // 宣告儲存指令的陣列 cs
    for(int i=0;i!=csize;i++)
        cin>>cs[i]; // 依序讀取所有指令
    
    int sx = (x+1)/2 , sy = y ,sori=0; // 初始化方塊錨點與方向：起始 x 向上取整 (x+1)/2，起始 y 頂端 y，初始方向 0
    for(int i=0;i!=csize;i++)
        safemove(sx ,sy,sori,x,y,cs[i]); // 依序執行每一個指令

    int maps[y][x]; // 宣告 y×x 的二維陣列 maps 代表最終遊戲畫面
    for(int i=0;i!=y;i++)
        for(int j=0;j!=x;j++)
            maps[i][j] = 0; // 初始化所有格子為 0（無方塊）

    for(int i=0;i!=4;i++) // 根據最終錨點與旋轉方向，將 T 型方塊的 4 個格子標記為 1
    {
        int tarx = sx+tbias[sori][i][0];
        int tary = sy+tbias[sori][i][1];
        maps[tary-1][tarx-1] = 1;
    }

    // 由上到下（y-1 到 0）輸出最終遊戲畫面矩陣
    for(int i=y-1;i>=0;i--)
    {
        for(int j=0;j!=x;j++)
            cout<< maps[i][j];
        cout << '\n';
    }

    return 0; // 程式正常結束
}
