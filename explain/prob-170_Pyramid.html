#170 202210Pyramid (金字塔)

題目摘要

問題敘述： 給定 N 塊矩形木板，每塊木板有長度 L 與寬度 W。小新想用這些木板堆疊成一座金字塔。金字塔每一層由一片木板構成，且上層木板必須「完全小於」下層木板（即木板 A 的長度小於木板 B 且寬度小於木板 B）。木板不可旋轉。請計算金字塔最多可以有幾層。

輸入格式： 第一列有一個整數 N (1 ≤ N ≤ 105) 代表木板總數。接下來 N 列，每列有兩個整數 L 和 W (1 ≤ L ≤ 109, 1 ≤ W ≤ 109)，代表木板的長度與寬度。

輸出格式： 輸出一個數字代表金字塔的最大層數。

演算法使用解析：【排序與最長遞增子序列 (LIS) 配合二分搜尋】

本題為經典的二維偏序 / 最長遞增子序列 (LIS) 變體問題：

  • 排序策略： 先將所有木板依長度 L 由小到大排序；若長度相同，則依寬度 W 由大到小排序。這樣可以確保相同長度的木板不會互相視為合法遞增（避免重複長度被選取）。
  • LIS 狀態維護： 排序後，對木板的寬度 W 維護一個 pyramid 陣列。利用 lowerbound 進行二分搜尋，尋找最長嚴格遞增子序列。
  • 效能優化： 時間複雜度為 O(N log N)，空間複雜度為 O(N)，能完美應對 N = 105 的大規模測資。

    1. (3, 6)

    3. (8, 7)
    4. (9, 10)
    5. (9, 7)
  • 提取寬度序列進行 LIS 模擬：[6, 2, 7, 10, 7]
    • 加入 6 → `[6]`
    • 處理 2 → 替換 6 → `[2]`
    • 處理 7 → 附加 → `[2, 7]`
    • 處理 10 → 附加 → `[2, 7, 10]`
    • 處理 7 → 替換 7 → `[2, 7, 10]`
  • 最終 LIS 長度（金字塔最大層數）為 3。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<iostream> // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout
#include<vector> // 引入動態陣列 vector 標頭檔
#include<algorithm> // 引入演算法標頭檔，包含 sort 與 lowerbound
#include<utility> // 引入 pair 容器標頭檔
using namespace std; // 使用標準命名空間 std

int main()
{
    int N; // 宣告整數 N，用來儲存木板總數
    cin >> N; // 讀入木板總數 N
    vector<pair<int,int>> wood; // 宣告 vector 儲存 pair<int, int>，分別代表木板的長 (first) 與寬 (second)
    for(int i=0;i<N;++i) // 迴圈讀入每塊木板的尺寸
    {
        int a,b; // 宣告暫存變數 a（長）與 b（寬）
        cin >> a >> b; // 讀入長度 a 與寬度 b
        wood.pushback(makepair(a,b)); // 將木板尺寸放入 wood 容器中
    }

    // 將木板進行排序：若長度不同則依長度由小到大排序；若長度相同則依寬度由大到小排序
    sort(begin(wood),end(wood),
         [](pair<int,int> &a, pair<int,int> &b)->bool{return a.first==b.first? a.second>b.second:a.first<b.first;});

    vector<int> pyramid; // 宣告 pyramid 陣列，用來維護最長遞增子序列 (LIS) 的寬度
    pyramid.pushback(wood[0].second); // 將第一塊木板的寬度放入 pyramid 作為起點
    for(int i=1;i<wood.size();++i) // 從第二塊木板開始走訪所有木板
    {
        if(pyramid.back()<wood[i].second) // 若當前木板寬度大於 pyramid 最後一個元素（可接在金字塔上方）
            pyramid.pushback(wood[i].second); // 直接將其加入 pyramid 尾端
        else // 否則（寬度小於或等於 pyramid 尾端）
            *lowerbound(begin(pyramid),end(pyramid),wood[i].second) = wood[i].second; // 利用二分搜尋找到第一個大於等於當前寬度的位置並進行替換（優化 LIS）

    }
    cout << pyramid.size() << endl; // 輸出 pyramid 的大小，即為金字塔的最大層數
    return 0; // 程式正常結束
}
