題目摘要與全貌

問題敘述： 小明從數字 $1 ∼ M$ 中取 $N$ 個相異數字 $a1, a2, …, aN$ 形成一個數列，求該數列在所有由「$1 ∼ M$ 取 $N$ 個相異數字」所構成的數列中，依照字典序排好的編號（編號從 0 開始）。

輸入格式：
第一列有兩個正整數 $N$ 和 $M$ ($N ≤ M ≤ 2 × 105$)。
第二列有 $N$ 個正整數 $a1, a2, …, aN$（所有數值不重複且 $1 ≤ ai ≤ M$），相鄰兩數以空格隔開。

輸出格式： 輸出一個整數，代表字典序編號對 $1,000,000,007$ ($109 + 7$) 取餘數的結果。

演算法核心結構：廣義康托展開與樹狀陣列

通用推導公式：
設數列索引為 $i$（$0 ≤ i ≤ N-1$），當前挑選的數字為 $ai$： $$Index = ∑i=0N-1 cnti × P(M - 1 - i,\, N - 1 - i) ±od{109+7}$$ 其中：
  • $cnti$：在集合 $\{1, …, M\}$ 中，數值嚴格小於 $ai$ 且未在前面出現過的數字總數。
  • $P(n, k) = \frac{n!}{(n-k)!}$：在剩餘未使用的 $n = M - 1 - i$ 個數字中，任意填滿剩下 $k = N - 1 - i$ 個位置的所有排列數。
1. 為什麼需要樹狀陣列 (BIT)？

若直接遍歷尋找小於 $ai$ 的未使用個數，單次複雜度為 $O(M)$，總花費為 $O(NM) ≈ 4 × 1010$ 會導致 TLE。透過樹狀陣列動態維護已被選走的數字： $$cnti = (ai - 1) - fenwick\sum(ai)$$ 單次查詢與加入皆為 $O(log M)$，總時間降至 $O(N log M)$。

2. 模反元素 (Modular Inverse)

計算 $P(n, k) = \frac{n!}{(n-k)!} ±od{MOD}$ 時，除法轉換為乘法逆元。由費馬小定理（因為 $MOD = 109+7$ 為質數）： $$\frac{1}{(n-k)!} ≡ ((n-k)!)MOD-2 ±od{MOD}$$ 利用快速冪在 $O(log MOD)$ 完成計算。

PDF 範例詳細逐步推導與追蹤

範例 1 $N = 3, M = 4$，數列：$[3, 4, 2]$

總池為 $\{1, 2, 3, 4\}$。共需填入 3 個位置：

步數 $i$ 目前數字 $ai$ 已選用過的數字 比 $ai$ 小且未用的集合 可用量 $cnti$ 剩餘候選 $M-1-i$ / 剩餘空位 $N-1-i$ 該步排列組合貢獻
$i = 0$ 3 $∅$ $\{1, 2\}$ 2 選 $3-0-1 = 2$ 個，池中剩 $4-0-1 = 3$ 個 $2 × P(3, 2) = 2 × 6 = 12$
$i = 1$ 4 $\{3\}$ $\{1, 2\}$ 2 選 $3-1-1 = 1$ 個，池中剩 $4-1-1 = 2$ 個 $2 × P(2, 1) = 2 × 2 = 4$
$i = 2$ 2 $\{3, 4\}$ $\{1\}$ 1 選 $3-2-1 = 0$ 個，池中剩 $4-2-1 = 1$ 個 $1 × P(1, 0) = 1 × 1 = 1$

👉 累計總和： $12 + 4 + 1 = 17$（與表一中編號 17 完全吻合）。

範例 2 $N = 3, M = 3$，數列：$[1, 3, 2]$

此為全排列情況（$N=M$）：

步數 $i$ 目前數字 $ai$ 已選用過的數字 可用數字量 $cnti$ 排列計算式 $P(M-1-i, N-1-i)$ 該步排列組合貢獻
$i = 0$ 1 $∅$ 小於 1 者無，即 0 $P(2, 2) = 2! = 2$ $0 × 2 = 0$
$i = 1$ 3 $\{1\}$ 未用且小於 3 者為 $\{2\}$，共 1 $P(1, 1) = 1! = 1$ $1 × 1 = 1$
$i = 2$ 2 $\{1, 3\}$ 小於 2 的數字 1 已被選走，共 0 $P(0, 0) = 0! = 1$ $0 × 1 = 0$

👉 累計總和： $0 + 1 + 0 = 1$（在 $[1,2,3], [1,3,2], …$ 中，第 0 個為 $[1,2,3]$，故 $[1,3,2]$ 為編號 1，輸出 1）。

範例 3 $N = 5, M = 9$，數列：$[3, 2, 5, 7, 4]$

從 9 個數字中挑選 5 個數字，依序追蹤五個位置：

位置 $i$ $ai$ 小於 $ai$ 且未被選用數字 $cnti$ $P(9-1-i, 5-1-i)$ 單步貢獻值
$i = 0$ 3 $\{1, 2\}$ 2 $P(8, 4) = 8 × 7 × 6 × 5 = 1680$ $2 × 1680 = 3360$
$i = 1$ 2 $\{1\}$（3 已被使用） 1 $P(7, 3) = 7 × 6 × 5 = 210$ $1 × 210 = 210$
$i = 2$ 5 $\{1, 4\}$（2, 3 已被使用） 2 $P(6, 2) = 6 × 5 = 30$ $2 × 30 = 60$
$i = 3$ 7 $\{1, 4, 6\}$（2, 3, 5 已被使用） 3 $P(5, 1) = 5$ $3 × 5 = 15$
$i = 4$ 4 $\{1\}$（2, 3 已被使用） 1 $P(4, 0) = 1$ $1 × 1 = 1$

👉 累計總和： $3360 + 210 + 60 + 15 + 1 = 3646$。
註：PDF 範例 3 題目若輸入為「5 9 \n 3 2 5 7 4」，依此標準推導驗證邏輯即為 3646。

教學核心思維與模組拆解

  • 結構拆解（高內聚、低耦合）： 本程式由三個完全獨立的積木組成：
    1. 數論模組：階乘預處理與快速冪逆元計算 $P(n, k)$。
    2. 資料結構模組：Fenwick Tree（樹狀陣列），負責區間計數與單點標記。
    3. 業務邏輯模組：康托展開迴圈，串接上述兩者進行權重疊加。
  • 延伸思考與問題改造：
    • 逆向問題（逆康托展開）：如果題目反過來給定 $M, N$ 與字典序編號 $K$，如何還原出原始數列？（可引導學生思考使用二分搜尋結合樹狀陣列尋找第 $k$ 小未用元素）。
    • 重複元素的排列：若 $ai$ 中允許出現重複元素，公式該如何調整分母？（多重集的排列計數）。

參考解答 C++ 程式碼（附詳細繁體中文逐行架構註解）

#include <cstdio>      // 引入標準 C 輸入輸出 (scanf, printf)
#include <cstring>     // 引入記憶體配置與操作工具 (memset)
#include <vector>      // 引入 vector 容器
#include <algorithm>   // 引入演算法函式庫
using namespace std;

typedef long long ll;           // 定義長整數，防止乘法運算溢位
const ll MOD = 1000000007;     // 模數常數 109 + 7
const int maxn = 200005;       // 最大數字範圍常數 200,005

ll fact[maxn];                  // 階乘快取陣列：fact[i] = i! % MOD

// 階乘預處理：以 O(N) 預先建表，避免後續重複計算
void init(ll n)
{
    fact[0] = fact[1] = 1;
    for (ll i = 2; i <= n; ++i)
    {
        fact[i] = (fact[i - 1] * i) % MOD;
    }
}

// 快速冪運算：在 O(log n) 時間內計算 (an) % MOD
ll powmod(ll a, ll n)
{
    ll ret = 1;
    for (ll base = a; n; base = (base * base) % MOD, n >>= 1)
    {
        if (n & 1)
        {
            ret = (ret * base) % MOD;
        }
    }
    return ret;
}

// 排列數 P(n, m) = n! / (n-m)! % MOD
// 藉由費馬小定理：(n-m)! 的模反元素為 (fact[n-m])^(MOD-2)
ll P(ll n, ll m)
{
    if (m < 0 || n < m) return 0;
    return fact[n] * powmod(fact[n - m], MOD - 2) % MOD;
}

// 樹狀陣列 (Fenwick Tree)：單點更新，將數字 pos 的使用狀態標記為 1
void fenwickadd(ll *tree, ll m, ll pos)
{
    while (pos <= m)
    {
        ++tree[pos];
        pos += pos & -pos;  // 移動至父節點 (加上 lowbit)
    }
}

// 樹狀陣列 (Fenwick Tree)：區間查詢 1 ~ pos 的總合（即小於等於 pos 且已被使用的數字個數）
ll fenwicksum(ll *tree, ll pos)
{
    ll ret = 0;
    while (pos > 0)
    {
        ret += tree[pos];
        pos -= pos & -pos;  // 移動至相鄰前綴區間 (減去 lowbit)
    }
    return ret;
}

// 核心解題函式：計算排列在字典序中的編號
ll solve(ll *perm, ll n, ll m)
{
    ll ret = 0;
    ll *tree = new ll[m + 1];               // 動態配置樹狀陣列空間
    memset(tree, 0, sizeof(ll) * (m + 1));  // 初始化為 0

    for (ll i = 0; i < n; ++i)
    {
        // 小於 perm[i] 的原始數字總數為 perm[i] - 1
        // 減去前面已經被選用過的數量 fenwicksum(tree, perm[i])，即為當前可用且比 perm[i] 小的個數
        ll cnt = (perm[i] - 1) - fenwicksum(tree, perm[i]);

        // 該位置替換為較小數字時，後續位置能形成的總排列數貢獻
        ll ways = (cnt * P(m - i - 1, n - i - 1)) % MOD;
        ret = (ret + ways) % MOD;

        // 將當前數字標記進樹狀陣列，表示未來不能再重複使用
        fenwickadd(tree, m, perm[i]);
    }

    delete[] tree;  // 釋放動態記憶體
    return ret;
}

int main()
{
    ll n, m;
    if (scanf("%lld%lld", &n, &m) != 2) return 0;

    ll *perm = new ll[n];
    for (ll i = 0; i < n; ++i)
    {
        scanf("%lld", &perm[i]);
    }

    init(m);                             // 初始化階乘表至 m!
    printf("%lld\n", solve(perm, n, m)); // 輸出字典序計算結果

    delete[] perm;
    return 0;
}
