#4 201903_B1-BMR (基礎代謝率)

PDF: 201903_B1-BMR(Q).pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 依據美國運動醫學協會提供的公式，根據性別（男/女）、年齡、身高與體重計算個人的基礎代謝率（BMR），並將結果四捨五入至小數點後兩位。

  • 男性 BMR = (13.7 × 體重(kg)) + (5.0 × 身高(cm)) − (6.8 × 年齡) + 66
  • 女性 BMR = (9.6 × 體重(kg)) + (1.8 × 身高(cm)) − (4.7 × 年齡) + 655

輸入格式： 第一行有一個正整數 N (1 ≤ N ≤ 20) 代表人數；接下來 N 行，每行包含四個正整數 G、A、H、W（分別代表性別、年齡、身高、體重）。

輸出格式： 對每個人輸出其基礎代謝率，四捨五入至小數點後兩位，每人輸出後換行。

演算法使用解析：【數學公式直接代入與條件判斷】

本題為基礎的條件分支與數學運算題。透過讀入人數 N，並在迴圈內讀入個人的性別、年齡、身高與體重。

  • 依據性別變數 G（1 代表男性，0 代表女性）選擇對應的 BMR 計算公式。
  • 使用雙精度浮點數（double）進行計算，並利用 printf("%.2f\n", BMR) 自動處理四捨五入至小數點後兩位，確保輸出格式符合規範。

  • 第一筆測資： G = 1 (男), A = 10 (年齡), H = 100 (身高 cm), W = 20 (體重 kg)
    • 代入男性公式：BMR = (13.7 × 20) + (5.0 × 10) − (6.8 × 10) + 66
    • = 274.0 + 50.0 − 68.0 + 66 = 772.00
  • 第二筆測資： G = 0 (女), A = 20 (年齡), H = 120 (身高 cm), W = 30 (體重 kg)
    • 代入女性公式：BMR = (9.6 × 30) + (1.8 × 120) − (4.7 × 20) + 655
    • = 288.0 + 216.0 − 94.0 + 655 = 1065.00

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<stdio.h> // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf

int main()
{
    int N = 0; // 宣告變數 N 用來儲存要計算 BMR 的總人數
    scanf("%d",&N); // 讀入人數 N

    for(int i=0; i<N; ++i) // 使用迴圈依序處理每位受測者的資料，共執行 N 次
    {
       	int Gender = 0, height = 0, weight = 0, age = 0; // 宣告性別、身高、體重與年齡變數
       	scanf("%d %d %d %d",&Gender, &age, &height, &weight); // 讀入當前受測者的性別、年齡、身高、體重

        double BMR = 0; // 宣告雙精度浮點數變數 BMR，用來儲存計算後的基礎代謝率結果
       	if(Gender == 0) // 檢查若性別代號為 0 (代表女性)
       	{
        	BMR = (double)(9.6*weight + 1.8*height - 4.7*age + 655); // 依據女性 BMR 公式進行計算並轉型為 double
       	}
      	else if(Gender == 1) // 檢查若性別代號為 1 (代表男性)
      	{
      		BMR = (double)(13.7*weight + 5*height - 6.8*age + 66); // 依據男性 BMR 公式進行計算並轉型為 double
       	}

        printf("%.2f\n",BMR); // 格式化輸出 BMR 數值，四捨五入至小數點後兩位並換行
    }
    
    return 0; // 程式正常結束
}
