題目摘要

問題敘述： 遙遠的資工星上有一所大學，資工系預期開放 N 個課程，每堂課各有其開始時間 S 與結束時間 E。已知每堂課都需要一間教室，但若課程時間不重疊（即課程 A 的結束時間 EA 小於或等於課程 B 的開始時間 SB），則可以共用同一間教室。已知資工系已經有一間教室，請問滿足所有課程需求後，最少需要幾間教室？

  • 輸入格式： 第一列為正整數 N（0 ≤ N ≤ 107），代表課程數量；接著有 N 列，每列包含兩個整數 S 與 E（0 ≤ S < E ≤ 107−1），表示每堂課的上課與下課時間。
  • 輸出格式： 輸出一列，包含一個整數 K，表示最少需要的教室數量。

演算法使用解析：【差分陣列與掃描線演算法 (Difference Array & Sweep-line Algorithm)】

本題的核心在於計算在任意時間點同時進行的最大課程數量，因為同一時間重疊多少門課，就需要多少間教室。

  • 差分陣列 (Difference Array)： 由於時間範圍最大可達 107，我們可以使用全域陣列 arr[SIZE]（大小設定為 10000005）。每當有一門課從時間 T1 開始到 T2 結束，我們就在開始時刻 T1 加上 1（arr[T1] += 1，代表多了一堂課開始），並在結束時刻 T2 減去 1（arr[T2] -= 1，代表該堂課結束釋放一間教室）。
  • 掃描線統計 (Sweep-line)： 接著由時間 0 開始向右掃描，透過累加差分值 now += arr[i] 維護當前正在進行的課程數，並用 ans = std::max(ans, now) 記錄整個時間軸上同時進行的最大課程數（即最少需要的教室數）。此方法時間複雜度為 O(N + MAX\TIME)，能高效處理 N ≤ 107 的大規模測資。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
3
0 1
1 2
2 3
  • 步驟 1：讀入 3 筆課程並更新差分陣列
    • 課程 1 (0 1)：arr[0] += 1, arr[1] -= 1
    • 課程 2 (1 2)：arr[1] += 1, arr[2] -= 1
    • 課程 3 (2 3)：arr[2] += 1, arr[3] -= 1
  • 步驟 2：掃描時間軸計算最大並行數（初始 ans = 1, now = 0）
    • 時間 i = 0：now += arr[0] (+1) ⇒ now = 1，ans = max(1, 1) = 1
    • 時間 i = 1：now += arr[1] (-1 + 1 = 0) ⇒ now = 1，ans = max(1, 1) = 1
    • 時間 i = 2：now += arr[2] (-1 + 1 = 0) ⇒ now = 1，ans = max(1, 1) = 1
    • 時間 i = 3：now += arr[3] (-1) ⇒ now = 0，ans = max(1, 0) = 1

👉 輸出範例 1 結果： 1

【輸入範例 2 實際運作推導】

輸入：
6
1 3
4 7
2 5
2 4
3 7
2 6
  • 步驟 1：差分陣列標記
    • (1, 3): arr[1]+=1, arr[3]-=1
    • (4, 7): arr[4]+=1, arr[7]-=1
    • (2, 5): arr[2]+=1, arr[5]-=1
    • (2, 4): arr[2]+=1, arr[4]-=1
    • (3, 7): arr[3]+=1, arr[7]-=1
    • (2, 6): arr[2]+=1, arr[6]-=1
  • 步驟 2：時間軸掃描累積
    • i = 1：now = 1, ans = 1
    • i = 2：now = 1 + 3 = 4, ans = max(1, 4) = 4
    • i = 3：now = 4 - 1 + 1 = 4, ans = max(4, 4) = 4
    • i = 4：now = 4 - 1 - 1 + 1 = 3, ans = 4
    • ... 隨著時間推進，最大並行課程數維持在 4。

👉 輸出範例 2 結果： 4

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<bits/stdc++.h> // 引入 C++ 標準函式庫（包含輸入輸出、容器、演算法等）
#define SIZE 10000005 // 定義全域常數 SIZE 為 10000005，對應最大可能的時間點範圍
int arr[SIZE]= {}; // 宣告全域差分陣列 arr，並全部初始化為 0，用來記錄各時間點的課程增減量

int main()
{
    int N; // 宣告整數變數 N 用來儲存課程總數量
    scanf("%d", &N); // 讀入課程數量 N
    
    for(int i=0; i<N; i+=1) // 使用迴圈讀入每一門課的時間區間，共執行 N 次
    {
        int T1, T2; // 宣告整數變數 T1 與 T2 分別代表課程的開始時間與結束時間
        scanf("%d%d",&T1, &T2); // 讀入當前課程的開始與結束時間
        arr[T1]+=1; // 在課程開始時間 T1 標記 +1，代表此時多了一堂課開始進行
        arr[T2]-=1; // 在課程結束時間 T2 標記 -1，代表此時有一堂課結束並釋放教室
    }
    
    int ans=1, now=0; // 宣告 ans 代表最少需要的教室數（題目已知至少有一間），now 代表當前同時進行的課程數
    
    for(int i=0; i<SIZE; i+=1) // 從時間 0 開始向右掃描整個時間軸至最大範圍 SIZE
    {
        now+=arr[i]; // 將當前時間點 i 的差分值累加到當前課程數 now 中
        ans=std::max(ans, now); // 更新歷史最大並行課程數，確保 ans 記錄最大需求量
    }
    
    printf("%d\n",ans); // 輸出最終計算出的最少教室數量 K 並換行
}
