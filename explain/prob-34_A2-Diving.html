#34 201911_A2-Diving (潛水)

題目摘要

問題敘述： 小軒想從島嶼 A 經由潛水方式移動到島嶼 B。每條潛水路徑都有對應需要的氧氣量 W（代表該路徑的難度/消耗量）。到達每個島嶼都可以將氧氣筒重新裝滿。小軒希望能背負容量最小的氧氣筒，順利從 A 島移動到 B 島（即最小化路徑中單段最大的氧氣消耗量）。若無法到達則輸出 `-1`。

輸入格式： 第一列有兩個整數 N 與 M (2 ≤ N ≤ 500)，代表小島數與潛水路徑數；接著 M 列每列三個整數，代表兩島編號與所需氧氣量 W (2 ≤ W ≤ 50000)；最後一列有兩個整數 A 與 B。

輸出格式： 輸出小軒最少要背多少容量的氧氣筒；若無法到達輸出 `-1`。

演算法使用解析：【圖論演算法 / Kruskal 最小生成樹 (MST) 變形】

本題採用Kruskal 演算法與併查集 (Disjoint Set Union, DSU)：

  • 題目要求找出從 A 到 B 的一條路徑，使得該路徑上的最大邊權（氧氣消耗量）達到最小，這正是經典的最大權最小邊 / 最小生成樹 (MST) 應用。
  • 我們將所有潛水路徑依據氧氣量 W 由小到大進行排序。
  • 使用 DSU 將邊逐一加入，當島嶼 A 與島嶼 B 連通時，當前加入的邊權就是能讓 A 到 B 暢通且容量最小的氧氣筒需求。

【輸入範例 1 實際運作推導】

輸入：
4 4
0 2 3
0 1 1
1 3 6
2 3 5
0 3
  • 所有邊依權重排序：
    • (0, 1) 權重 1
    • (0, 2) 權重 3
    • (2, 3) 權重 5
    • (1, 3) 權重 6
  • 逐步加入 Kruskal MST：
    • 加入 (0, 1) 權重 1：島 0 與島 1 連通。
    • 加入 (0, 2) 權重 3：島 0, 1, 2 連通。
    • 加入 (2, 3) 權重 5：島 0, 1, 2, 3 全部連通。此時檢查目標 A = 0 與 B = 3 已經連通！
  • 最後加入的邊權重為 5，即為最小氧氣筒容量。

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱,含每行詳細中文教學註解）

#include <iostream>
#include <algorithm>
#include <vector>
#define endl '\n'
#define IOS cin.tie(0), cout.tie(0), ios::syncwithstdio(false)
#define N 1500
using namespace std;

// 定義結構體儲存邊的資訊（起點 st、終點 en、權重/氧氣量 w）
struct edge
{
    int st;
    int en;
    int w;
    edge(int a, int b, int c):
        st(a), en(b), w(c){};
};

int dis[N] = {};  // DSU 併查集陣列，用來記錄每個節點的根節點

// 自定義比較函式：將邊依據權重 w 由小到大排序（Kruskal 核心步驟）
bool cmp(edge l, edge r)
{
    return l.w < r.w;
}

// 初始化 DSU，一開始每個節點的根都是自己
void init(int n)
{
    for(int i = 0; i < n; i++)
    {
        dis[i] = i;
    }
}

// 尋找根節點（帶有路徑壓縮優化）
int find_(int x)
{
    if(x == dis[x])
    {
        return x;
    }
    return dis[x] = find_(dis[x]);
}

// 合併兩個集合
void union_(int x, int y)
{
    x = find_(x);
    y = find_(y);
    if(x != y)
    {
        dis[x] = y;
    }
}

int main()
{
    IOS;  // 加速輸入輸出
    int n, m;
    vector<edge> v;  // 宣告儲存所有邊的動態陣列
    cin >> n >> m;  // 讀入島嶼數 n 與路徑數 m
    for(int i = 0; i < m; i++)
    {
        int x, y, z;
        cin >> x >> y >> z;  // 讀入兩島編號 x, y 與所需氧氣量 z
        v.emplaceback(edge(x, y, z));  // 將邊加入陣列中
    }
    int a, b;
    cin >> a >> b;  // 讀入想從島 a 移動到島 b
    
    sort(v.begin(), v.end(), cmp);  // 將所有潛水路徑依氧氣量由小到大排序
    init(n);  // 初始化併查集
    int ans = 0;  // 記錄最終所需的最小氧氣筒容量
    
    // 依序走訪排序好的每一條邊
    for(int i = 0; i < m; i++)
    {
        int x = v[i].st, y = v[i].en;
        if(find_(x) != find_(y))  // 若兩島尚未連通
        {
            union_(x, y);  // 將兩島合併在同一集合中
        }
        if(find_(a) == find_(b))  // 若此時起點 a 與終點 b 已經連通
        {
            ans = v[i].w;  // 當前加入的邊權重即為滿足條件的最大邊（也就是最小氧氣筒容量）
            break;  // 達成目標，結束迴圈
        }
    }
    
    // 輸出結果：若 ans 不為 0 代表成功找到路徑，否則輸出 -1
    if(ans != 0)
        cout << ans << endl;
    else
        cout << "-1" << endl;
}
