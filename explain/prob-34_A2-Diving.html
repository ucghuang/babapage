題目摘要與測資規模

問題敘述： 小軒趁放暑假去澎湖潛水。今天想從小島 A 經由潛水方式移動到小島 B。小島間的距離需要花費不同的氧氣量 W（代表雙向潛水移動的難度），且每抵達一座島就可以把氧氣筒重新裝滿。小軒希望背負容量最小的氧氣筒完成行程（即最小化路徑中單段的最大氧氣消耗量）。若無法到達則輸出 -1。

輸入格式： 第一列有兩個整數 N 與 M (2 ≤ N ≤ 500, 0 ≤ M ≤ N(N-1)/2)，代表小島數與潛水路徑數，島嶼編號為 0 ~ N-1。接著 M 列每列三個整數，代表兩島編號與所需氧氣量 W (2 ≤ W ≤ 50000)。最後一列有兩個整數 A 與 B，代表起點與終點。

輸出格式： 輸出小軒最少要背多少容量的氧氣筒；若無法到達則輸出 -1。

評分級距： 第一組 (30分)：2 ≤ N ≤ 10, 0 ≤ M ≤ 50；第二組 (70分)：無額外限制。

演算法模型解析：【最小瓶頸路徑 / Kruskal 最小生成樹 (MST)】

這道題的核心是「最小化所有可行路徑中，單段最大耗氧邊的權重」（Minimum Bottleneck Path）：

  • 容量瓶頸性質： 既然抵達任一島嶼氧氣均會回滿，那麼整趟旅程能不能順利通行，完全取決於整條路徑上消耗最大（權重最大）的那一段。如果背包容量 C ≥ max(W_e)，就能全程走通。
  • Kruskal 演算法的貪婪保證： 將所有雙向潛水邊依據耗氧量 W 由小到大排序，透過併查集 (DSU) 由小到大將邊依序加入圖中。
  • 提前終止條件： 在加入某條邊 (u, v, W) 之後，立刻檢查起點 A 與終點 B 是否已經在同一連通元件（find(A) == find(B)）。因為邊是從小到大加入的，第一個使 A 與 B 連通的邊權重，即為最佳解答容量。

【範例 1 演算法逐步追蹤】

起點 A = 0，終點 B = 3。總島嶼數 N = 4，邊數 M = 4。

範例 1 原拓撲與關鍵瓶頸邊示意

綠線：成功選取的連通邊 | 紅虛線：促成 A、B 連通的關鍵瓶頸邊

步驟 考慮邊 (u, v) 權重 w 合併前根節點 find(u), find(v) 動作與 DSU 集合狀態 檢查 find(0) == find(3)
初始化 - - - {0}, {1}, {2}, {3} 否 (0 != 3)
1 (0, 1) 1 find(0)=0, find(1)=1 合併: {0, 1}, {2}, {3} 否 (0 != 3)
2 (0, 2) 3 find(0)=1, find(2)=2 合併: {0, 1, 2}, {3} 否 (2 != 3)
3 (2, 3) 5 find(2)=2, find(3)=3 合併: {0, 1, 2, 3} 成立！連通達成
4 (1, 3) 6 - 不需處理 (迴圈已提早 break) -

👉 範例 1 輸出結果： 5（瓶頸路徑為 0 - 2 - 3，最大單段消耗為 5）

【範例 2 演算法逐步追蹤】

起點 A = 0，終點 B = 4。總島嶼數 N = 5，邊數 M = 6。

範例 2 原拓撲與關鍵瓶頸邊示意

邊 (4, 2) 權重 6 成功將島 4 連入包含島 0 的集合

步驟 排序後邊 (u, v) 權重 w 集合關係與決策 目前連通分量狀態 檢查 find(0) == find(4)
初始化 - - - {0}, {1}, {2}, {3}, {4} 否
1 (0, 1) 1 find(0)!=find(1) → 合併 {0, 1}, {2}, {3}, {4} 否
2 (0, 2) 2 find(0)!=find(2) → 合併 {0, 1, 2}, {3}, {4} 否
3 (1, 3) 4 find(1)!=find(3) → 合併 {0, 1, 2, 3}, {4} 否 (島 4 仍孤立)
4 (3, 2) 5 find(3)==find(2) → 已在同集合 不變 ({0, 1, 2, 3}, {4}) 否
5 (4, 2) 6 find(4)!=find(2) → 合併 {0, 1, 2, 3, 4} 成立！0 與 4 成功連通
6 (3, 4) 7 - 不需處理 (已 break) -

👉 範例 2 輸出結果： 6（最佳路徑為 0 - 2 - 4，最大單段消耗為 6）

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含詳細教學註解）

#include <iostream>
#include <algorithm>
#include <vector>
#define endl '\n'
#define IOS cin.tie(0), cout.tie(0), ios::sync_with_stdio(false)
#define N 1500
using namespace std;

// 定義結構體儲存邊的資訊（起點 st、終點 en、權重/氧氣量 w）
struct edge
{
    int st;
    int en;
    int w;
    edge(int a, int b, int c):
        st(a), en(b), w(c){};
};

int dis[N] = {};  // DSU 併查集陣列，用來記錄每個節點的根節點

// 自定義比較函式：將邊依據權重 w 由小到大排序（Kruskal 核心步驟）
bool cmp(edge l, edge r)
{
    return l.w < r.w;
}

// 初始化 DSU，一開始每個節點的根都是自己
void init(int n)
{
    for(int i = 0; i < n; i++)
    {
        dis[i] = i;
    }
}

// 尋找根節點（帶有路徑壓縮優化）
int find_(int x)
{
    if(x == dis[x])
    {
        return x;
    }
    return dis[x] = find_(dis[x]);
}

// 合併兩個集合
void union_(int x, int y)
{
    x = find_(x);
    y = find_(y);
    if(x != y)
    {
        dis[x] = y;
    }
}

int main()
{
    IOS;  // 加速輸入輸出
    int n, m;
    vector<edge> v;  // 宣告儲存所有邊的動態陣列
    cin >> n >> m;   // 讀入島嶼數 n 與路徑數 m
    for(int i = 0; i < m; i++)
    {
        int x, y, z;
        cin >> x >> y >> z;  // 讀入兩島編號 x, y 與所需氧氣量 z
        v.emplace_back(edge(x, y, z));  // 將邊加入陣列中
    }
    int a, b;
    cin >> a >> b;  // 讀入想從島 a 移動到島 b
    
    sort(v.begin(), v.end(), cmp);  // 將所有潛水路徑依氧氣量由小到大排序
    init(n);  // 初始化併查集
    int ans = 0;  // 記錄最終所需的最小氧氣筒容量
    
    // 依序走訪排序好的每一條邊
    for(int i = 0; i < m; i++)
    {
        int x = v[i].st, y = v[i].en;
        if(find_(x) != find_(y))  // 若兩島尚未連通
        {
            union_(x, y);  // 將兩島合併在同一集合中
        }
        if(find_(a) == find_(b))  // 若此時起點 a 與終點 b 已經連通
        {
            ans = v[i].w;  // 當前加入的邊權重即為滿足條件的最大邊（也就是最小氧氣筒容量）
            break;  // 達成目標，結束迴圈
        }
    }
    
    // 輸出結果：若 ans 不為 0 代表成功找到路徑，否則輸出 -1
    if(ans != 0)
        cout << ans << endl;
    else
        cout << "-1" << endl;
    
    return 0;
}
