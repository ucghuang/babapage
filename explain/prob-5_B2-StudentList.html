題目摘要

問題敘述： 阿旺老師規定每堂課固定有三位同學請假。老師習慣從最後一個座號開始點名，因此名條必須將「有出席」同學的座號由後往前印出來（格式為 No. 座號）[cite: 1]。

輸入格式： 總共有兩行。第一行輸入一個整數 N (3 < N ≤ 20) 代表全班總人數（座號從 1 到 N）；第二行固定輸入三個以空白隔開的數字，代表三位請假同學的座號[cite: 1]。

輸出格式： 輸出 N - 3 列，每列為一個出席同學的座號（格式如 No. 5），無多餘換行[cite: 1]。

演算法使用解析：【逆向迴圈過濾與條件判斷】

本題透過由大到小的反向迴圈（從 N 遞減到 1）來滿足「由後往前印出」的要求[cite: 1]。

  • 在迴圈中逐一檢查當前座號 i 是否等於三位請假同學中任一人的座號（a, b, c）[cite: 1]。
  • 若 i 不是請假座號，則印出 No. i，並利用條件控制格式與換行，確保符合題目無多餘換行的輸出規範[cite: 1]。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
5
3 4 5
  • 全班人數 N = 5，請假座號為 3, 4, 5。
  • 由後往前檢查座號：
    • i = 5：是請假生，略過。
    • i = 4：是請假生，略過。
    • i = 3：是請假生，略過。
    • i = 2：出席，輸出 No. 2。
    • i = 1：出席，輸出 No. 1。

👉 輸出範例 1 結果：
No. 2
No. 1

【輸入範例 2 實際運作推導】

輸入：
8
1 2 3
  • 全班人數 N = 8，請假座號為 1, 2, 3。
  • 從 8 倒數到 1，排除 1, 2, 3 後，依序印出 8 到 4。

👉 輸出範例 2 結果：
No. 8
No. 7
No. 6
No. 5
No. 4

  • 從 10 倒數到 1，排除 3, 6, 9 後，依序印出：10, 8, 7, 5, 4, 2, 1。

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include <iostream> // 引入標準輸入輸出標頭檔，以便使用 cin 與 cout
using namespace std; // 使用標準命名空間，避免每次都要寫 std::

int main()
{
    int n; // 宣告變數 n 儲存全班總人數
    int a,b,c; // 宣告三個變數 a, b, c 分別儲存三位請假同學的座號
    cin>>n; // 讀入全班總人數 n
    cin>>a>>b>>c; // 讀入三位請假同學的座號
    int j=1; // 宣告計數器 j，用來控制換行與輸出的格式
    
    // 使用由大到小的迴圈，從最後一個座號 n 開始往前檢查到 1 號
    for(int i=n; i>0; i-=1)
    {
        // 檢查當前座號 i 是否不等於任何一位請假同學的座號 (a, b, c)
        if(i!=a && i!=b && i!=c)
        {
            cout<<"No. "<<i; // 若為出席同學，則印出 "No. " 加上該座號
            
            // 控制換行：若還沒印完所有應出席的同學，則換行並將計數器 j 加 1
            if(j<n-3)
            {
                cout<<endl; // 換行
                j+=1; // 計數器累加
            }
        }
    }
}
