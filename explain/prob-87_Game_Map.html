題目摘要與核心規範

問題情境： 玩家在 x imes y 的矩形網格地圖中移動，初始血量為 3 點。目標是從起點走到終點，每次只能往上下左右相鄰一格移動，求成功抵達終點的最少步數。

元素與規則說明：

  • 障礙物（Block）：完全無法通行。
  • 陷阱（Trap）：可以踩上去，但踩到會扣 1 點血量。若血量扣成 0 則判定死亡失敗。
  • 座標系統：左下角為 (0, 0)，橫向往右為 x，縱向往上為 y。
  • 輸出定義：輸出走到終點的最少步數；若無法生還抵達則輸出 -1。

教學核心：輸入文字如何一步步轉化成圖形地圖？

很多同學看到題目給的一串純文字數字會覺得抽象，其實繪製地圖只需要三個固定步驟：

步驟流程 題目輸入的讀取指令 畫在方格紙上的轉化動作
第 1 步：決定地圖框線 cin >> x >> y;
例如：3 5		 在紙上畫出寬度為 3 格、高度為 5 格的網格，將左下角標記為 (0,0)，右上角為 (2,4)。
第 2 步：插上起點與終點旗標 cin >> sx >> sy;
cin >> ex >> ey;		 在座標 (Sx, Sy) 塗上綠色標記為 S (起點)；在 (Ex, Ey) 塗上黃色標記為 E (終點)。
第 3 步：擺放障礙與陷阱 cin >> B >> T;
隨後讀取 B 行與 T 行座標		 依據每對座標 (xp, yp)：
• 障礙物座標填上深灰色 B（不可通行）
• 陷阱座標填上粉紅色 T（踩過扣 1 滴血）
💡 教學常見陷阱（座標軸 vs 陣列）：
題目給的座標是 (x, y) = ( ext{橫向欄}, ext{縱向列})，但 C++ 的二維陣列通常是 陣列[列][欄]，也就是 maps[y][x]！在寫程式標記時必須注意填入的是 maps[yp][xp]，否則整張地圖會發生水平/垂直翻轉。

本體程式核心演算法機制深度解析

1. 三維狀態佇列（State-Space BFS）：

傳統的 BFS 只要用 visited[y][x] 記錄是否造訪過即可。但本題有「陷阱會扣血」的機制：如果先走到某格但只剩 1 滴血，後續可能會因血量歸零而無法過關；反之，若稍晚走到同一格卻有 2 滴血，這條分支反而有機會生還。因此每個佇列節點都封裝了三個數值：struct state { health, x, y };。

2. 三維動態剪枝陣列 maprecords[1000][1000][3]：

為了防止重複搜尋造成超時（TLE），使用三維陣列記錄在特定剩餘血量下抵達某座標的最少步數：

  • maprecords[y][x][hp - 1]：存放抵達 (x, y) 且剩餘 hp 血量時的最小步數。
  • 若新分支抵達 (x, y) 時的步數大於或等於已記錄的歷史最優步數，即直接 continue 剪枝捨棄。

3. 迷因初始值的作用：

程式碼中出現的字串轉整數如 *(uint32t*)"starburst steam!!!"，在二進位中代表一個龐大的正整數（相當於 0xXXXXXXXX），其作用單純是將紀錄陣列初始化為「無限大」，代表該狀態尚未被探索過。

參考解答 C++ 程式碼（保留完整代碼，逐行繁體中文教學註解）

#include <bits/stdc++.h>  // 引入標準函式庫 (包含 I/O、queue 等)
using namespace std;  // 使用標準命名空間 std

uint8t maps[1000][1000] = {0};  // 全域地圖陣列：0 表示空地，1 表示障礙物，2 表示陷阱
uint32t maprecords[1000][1000][3] = {0};  // 三維陣列：記錄每個座標在不同剩餘血量（1~3）下到達時的最小步數，用於狀態剪枝

struct state  // 定義 BFS 佇列中儲存的狀態結構體
{
    uint8t health;  // 當前剩餘血量 (1 至 3)
    int x;           // 當前橫向座標 x
    int y;           // 當前縱向座標 y
};

inline bool checkbound(int x,int y,int xp,int yp)  // 內聯函數：檢查座標 (xp, yp) 是否在橫向 x、縱向 y 的地圖範圍內
{
    return xp >= 0 && xp < x && yp >= 0 && yp < y;  // 回傳是否合法的布林值
}

inline void addoffset(int &x,int &y,int types)  // 內聯函數：根據移動方向代號（0~3）更新座標 (x, y)
{
    int offset[4][2]={  // 定義 4 個移動方向的偏移量：上、下、左、右
        {0,1},   // 往上方移動 (y+1)
        {0,-1},  // 往下方移動 (y-1)
        {1,0},   // 往右方移動 (x+1)
        {-1,0}   // 往左方移動 (x-1)
    };
    x+=offset[types][0];  // 累加 x 軸偏移量
    y+=offset[types][1];  // 累加 y 軸偏移量
}

int bfs(int sx,int sy,int x, int y, int ex, int ey)  // 廣度優先搜尋函數：尋找從起點到終點的最短步數
{
    for(int i=0;i!=y;++i)  // 走訪縱向每一列
        for(int j=0;j!=x;++j)  // 走訪橫向每一行
        {
            // 初始化 maprecords，填入極大值（此處利用迷因字串轉換為 uint32t 作為初始無窮大）
            maprecords[i][j][0] = *(uint32t*)"24歳、学生です";
            maprecords[i][j][1] = *(uint32t*)"starburst steam!!!";
            maprecords[i][j][2] = *(uint32t*)"ｱ゛↑ｱ゛↑ｱ゛↑ｱ゛↑ｱ゛↑";
        }
    queue<state> que;  // 宣告 state 類型的 BFS 佇列
    que.push({3,sx,sy});  // 將初始血量 3 與起點座標 (sx, sy) 放入佇列
    int steps = 0;  // 初始化步數計數器為 0
    while(!que.empty())  // 當佇列不為空時持續迴圈
    {
        auto sz = que.size();  // 取得當前層級的節點數量
        for(int i=0;i < sz;++i)  // 走訪當前層級的所有狀態
        {
            auto cur = que.front();  // 取得佇列前端的當前狀態
            if(cur.x == ex && cur.y == ey)  // 若當前座標已到達終點 (ex, ey)
                return steps;  // 回傳當前的最短步數

            for(int u=0;u!=4;++u)  // 走訪 4 個相鄰移動方向
            {
                int xp = cur.x, yp = cur.y;  // 複製當前座標
                addoffset(xp,yp,u);  // 計算下一步的新座標 (xp, yp)
                if(!checkbound(x,y,xp,yp))  // 若新座標超出地圖範圍
                    continue;  // 跳過此方向
                if(maps[yp][xp] == 1)  // 若新座標是障礙物 (1)
                    continue;  // 無法通行，跳過
                if(maps[yp][xp] == 2 && cur.health-1 <= 0)  // 若新座標是陷阱 (2) 且扣血後血量 <= 0
                    continue;  // 血量耗盡遊戲失敗，跳過
                
                int rhp = cur.health-(maps[yp][xp] == 2);  // 計算移動到新位置後的剩餘血量（若踩到陷阱則血量 -1）
                if(maprecords[yp][xp][rhp-1] <= steps)  // 剪枝檢查：若該位置在相同或更高血量下已經被更少或相等的步數造訪過
                    continue;  // 略過此分支，避免重複搜尋
                
                maprecords[yp][xp][rhp-1] = steps;  // 更新該位置在對應血量下的最少步數紀錄
                que.push({(uint8t)rhp,xp,yp});  // 將新狀態（更新後的血量與座標）推入佇列
            }
            que.pop();  // 將當前狀態從佇列前端移除
        }
        steps++;  // 當前層級走訪完畢，步數 +1
    }
    return -1;  // 若佇列耗盡仍無法到達終點，回傳 -1
}

int main()  // 主程式起點
{
    int x,y;  // 宣告地圖寬度 x 與高度 y
    int sx,sy;  // 宣告起點座標 (sx, sy)
    int ex,ey;  // 宣告終點座標 (ex, ey)
    int bc,tc;  // 宣告障礙物個數 bc 與陷阱個數 tc

    cin >> x >> y;  // 輸入地圖尺寸
    cin >> sx >> sy;  // 輸入起點座標
    cin >> ex >> ey;  // 輸入終點座標
    cin >> bc >> tc;  // 輸入障礙物與陷阱數量
    for(int i = 0 ; i != bc ; i++)  // 迴圈讀入每個障礙物座標
    {
        int xp, yp;
        cin >> xp >> yp;
        maps[yp][xp] = 1;  // 在地圖中將該座標標記為障礙物 (1)
    }
    for(int i = 0 ; i != tc ; i++)  // 迴圈讀入每個陷阱座標
    {
        int xp, yp;
        cin >> xp >> yp;
        maps[yp][xp] = 2;  // 在地圖中將該座標標記為陷阱 (2)
    }
    cout << bfs(sx,sy,x,y,ex,ey) << '
';  // 呼叫 bfs 計算並輸出最短步數或 -1
}
