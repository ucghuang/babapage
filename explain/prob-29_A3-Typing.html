#29 201910_A3-Typing (猴子打字遊戲)

PDF: 201910_A3-Typing.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 三隻猴子在打字機上各自輸入了一段字串。給定一段目標字串，以及三隻猴子輸入的字串，請計算並找出哪隻猴子的字串與目標字若要透過「編輯距離 (Edit Distance)」轉換成目標字串時成本最小。編輯距離規則如下：新增一個字元成本為 2、刪除一個字元成本為 2、取代一個字元成本為 3（若字元相同則成本為 0）。

輸入格式： 共四列，每列包含一個不含空格的字串。第一列為目標字串，後三列分別為第一、二、三隻猴子所輸入的字串。

輸出格式： 輸出兩個數字 $N$ 與 $K$，中間以空白隔開。$N$ 為三隻猴子當中編輯距離最小的猴子編號（1、2 或 3，若編輯距離相同則輸出編號最大者），$K$ 為其最小編輯距離。

演算法使用解析：【動態規劃 (DP) / 編輯距離 (Levenshtein Distance) 變形】

本題採用經典的動態規劃編輯距離演算法：

  • 這是著名的字串相似度與最小編輯距離問題（類似 Levenshtein Distance）。我們針對每一隻猴子的字串與目標字串建立二維 DP 表格， $DP[i][j]$ 代表將猴子字串的前 $i$ 個字元變成目標字串前 $j$ 個字元的最小編輯成本。
  • 狀態轉移方程式：
    • 若字元相同 ($s[0][i-1] == s[t][j-1]$)：$DP[i][j] = \min(\text{斜上方}, \text{上方}+2, \text{左方}+2)$。
    • 若字元不同：$DP[i][j] = \min(\text{斜上方}+3, \text{上方}+2, \text{左方}+2)$（其中 3 代表取代成本，2 代表新增或刪除成本）。
  • 對三隻猴子分別計算出最佳編輯距離，並利用貪心比較選出距離最小的優勝者。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
abc
bcd
cde
efg
  • 目標字串： abc ($L_1 = 3$)
  • 猴子 1 字串： bcd ($L_2 = 3$)
    • 計算將 bcd 變成 abc 的最小編輯距離：
    • 可以將 b 取代為 a (成本 3)，保留 c (成本 0)，並刪除 d 或藉由其他對應操作，總編輯距離計算結果為 4。
  • 猴子 2 與猴子 3： 分別計算出對應的編輯距離。
  • 三者比較後，猴子 1 的編輯距離最小（為 4）。

👉 輸出範例 1 結果： 1 4

【輸入範例 2 實際運作推導】

輸入：
abcd
abcde
abc
bcd
  • 目標字串： abcd
  • 分別計算三隻猴子字串與目標字串的編輯距離，猴子 3 的編輯距離為最小的 2。

👉 輸出範例 2 結果： 3 2

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<bits/stdc++.h>  // 引入常用 C++ 標頭檔
#define infinity 999999  // 定義一個無限大常數，用來初始化最小值比較

int DP[10005][10005];  // 宣告二維全域 DP 陣列，DP[i][j] 代表字串轉換的最小編輯距離

int main()
{
    char s[4][10001];  // 宣告字元陣列儲存 4 個字串（s[0] 為目標字串，s[1]~s[3] 為三隻猴子輸入的字串）
    for(int i=0; i<4; i++)
        scanf("%s", s[i]);  // 依序讀入目標字串與三隻猴子的字串
        
    int L1 = strlen(s[0]);  // 取得目標字串的長度
    int win = 1;  // 記錄最佳猴子的編號，預設為第 1 隻
    int min_d = infinity;  // 記錄最小的編輯距離，初始設為無限大
    
    // 依序對三隻猴子（索引 1 到 3）進行編輯距離 DP 計算
    for(int t=1; t<=3; t++)
    {
        int L2 = strlen(s[t]);  // 取得當前第 t 隻猴子字串的長度
        
        // 初始化 DP 表格的邊界條件（新增或刪除字元的成本每字元為 2）
        for(int i=0; i<=L1||i<=L2; i++)
            DP[i][0] = DP[0][i] = i * 2;
            
        // 填滿二維 DP 表格
        for(int i=1; i<=L1; i++)
        {
            for(int j=1; j<=L2; j++)
            {
                // 若當前字元相同，不需取代，成本取斜上方(皆匹配)、或上方/左方 (+2) 的最小值
                if(s[0][i-1] == s[t][j-1])
                    DP[i][j] = std::min(DP[i-1][j-1], std::min(DP[i][j-1]+2, DP[i-1][j]+2));
                else
                    // 若字元不同，取代成本為 3 (斜上方+3)，或者新增/刪除成本為 2 (上方/左方+2)
                    DP[i][j] = std::min(DP[i-1][j-1]+3, std::min(DP[i][j-1]+2, DP[i-1][j]+2));
            }
        }
        
        // 比較並找出編輯距離最小的猴子（題目要求若距離相同則輸出編號最大者，故使用 <=）
        if (DP[L1][L2] <= min_d)
        {
            min_d = DP[L1][L2];  // 更新最小編輯距離
            win = t;  // 更新贏家猴子編號
        }
    }
    
    printf("%d %d\n", win, min_d);  // 輸出表現最佳的猴子編號與其最小編輯距離
}
