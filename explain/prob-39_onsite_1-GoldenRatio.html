題目摘要

問題敘述： 費氏數列（Fibonacci sequence）可以用來組成黃金比例螺線。若將以費氏數列前 $n$ 項為邊長的正方形組合成一個長方形，其長寬比會對應到費氏數列的相鄰項。給定一個正整數 $n$ ($1 \le n \le 45$)，代表作品是以費氏數列第 1 至 $n$ 項為邊長的正方形來組成，請根據費氏數列求出該作品的「長：寬」比例。

輸入格式： 輸入僅有一個正整數 $n$ ($1 \le n \le 45$)。

輸出格式： 輸出長寬比格式為 h:w（數字與冒號之間沒有空白）。

演算法使用解析：【數論與數學 / 費氏數列與迴圈遞推】

本題採用費氏數列遞推性質：

  • 費氏數列的定義為前兩項相加等於第三項（$F_1=1, F_2=1, F_3=2, F_4=3 \dots$）。
  • 當組合到第 $n$ 項時，所形成的長方形長寬剛好對應到費氏數列的特定項。例如當 $n=1$ 時長寬比為 $1:1$；當 $n \ge 2$ 時，長與寬分別對應到 $F_n$ 與 $F_n + F_{n-1}$（或相鄰的費氏數列數值）。
  • 透過迴圈預先算出對應的費氏數列數值，即可直接印出格式化的比例。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
6
  • 計算費氏數列直到第 6 項：
    • $F_1 = 1, F_2 = 1, F_3 = 2, F_4 = 3, F_5 = 5, F_6 = 8$。
  • 對應長寬比： 當 $n = 6$ 時，對應的邊長組合數值為 $8$ 與 $(8 + 5 = 13)$。
  • 輸出格式化： 8:13。

👉 輸出範例 1 結果： 8:13

【輸入範例 2 實際運作推導】

輸入：
8
  • 計算費氏數列直到第 8 項：
    • $F_7 = 13, F_8 = 21$。
  • 對應長寬比： 當 $n = 8$ 時，對應數值為 $21$ 與 $(21 + 13 = 34)$。

👉 輸出範例 2 結果： 21:34

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<stdio.h>  // 引入標準輸入輸出標頭檔

int main()
{	
	int N = 0;  // 宣告變數 N 代表輸入的費氏數列項數
	int h = 0, w = 0;  // 宣告變數 h(高/短邊) 與 w(寬/長邊)
	scanf("%d", &N);  // 讀入項數 N

	int num1 = 0, num2 = 1;  // 初始化費氏數列的前兩項基礎值
	int num3 = 0;  // 宣告變數儲存當前計算出的費氏數列新項
	
	// 使用迴圈計算費氏數列直到第 N 項
	for(int i=2; i<=N; i+=1)
	{
		num3 = num1 + num2;  // 第三項等於前兩項相加
		if( i == N )
			break;  // 若達到指定的第 N 項則跳出迴圈
		num1 = num2;  // 更新前一項數值
		num2 = num3;  // 更新當前項數值
	}

	// 根據 N 的大小決定長寬比輸出
	if( N == 1 ){
		h = 1;
		w = 1;  // 若 N 為 1，長寬皆為 1
	}
	else{
		h = num3;  // 高度為費氏數列第 N 項
		w = num3 + num2;  // 寬度為第 N 項加上前一項
	} 
		
	printf("%d:%d\n", h, w);  // 格式化輸出長寬比 (h:w)
	return 0;  // 程式正常結束
}
