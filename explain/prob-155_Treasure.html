題目摘要與幾何直觀

問題敘述： 寶藏獵人小飛收到神祕郵件，信中給定一張 N × N 的地圖高度矩陣。寶藏所在之處符合：「橫著看是最高處，直著看是最低處」。請找出該處的行列索引座標 (Row, Column)。

數學定義（鞍點 Saddle Point）：

給定二維矩陣 PN × N，若存在索引 (r, c) 同時滿足以下兩條件，則該點為鞍點：

  • 橫向列極大值：Pr, c = max0 ≤ j < N \{Pr, j\}
  • 縱向行極小值：Pr, c = min0 ≤ i < N \{Pi, c\}

輸入/輸出格式： 第一行包含一個正整數 N (2 ≤ N ≤ 100)。後續有 N 列整數，各列數值以空白間隔 (0 ≤ Pxy ≤ 1000)。若存在輸出其座標 r c（0-indexed）；若不存在則輸出 NO（題目保證答案至多一個）。

題目圖形解析與四大範例逐步推導

所在列（Row 橫向掃描）
所在行（Col 縱向掃描）
寶藏鞍點（橫向最高 且 縱向最低）

📌 【PDF 題幹圖形詳解 - 範例 2】 (N = 4)

矩陣示意圖與交會點：橫看 Row 2 最大值為 6，直看 Col 1 最小值為 6，兩者交會於 (2, 1)。

r \ c Col 0 Col 1 Col 2 Col 3 Row Max
Row 0 1 7 4 1 7 (c=1)
Row 1 4 8 3 6 8 (c=1)
Row 2 1 6 1 2 6 (c=1)
Row 3 0 7 8 9 9 (c=3)
Col Min 0 6 1 1 -

運算推導步驟：

  • 檢驗 Row 0：最大值為 7（位於 Col 1）。檢查 Col 1 的數值為 {7, 8, 6, 7}，最小值為 6。由於 7 ≠ 6，不符。
  • 檢驗 Row 1：最大值為 8（位於 Col 1）。Col 1 的最小值為 6。由於 8 ≠ 6，不符。
  • 檢驗 Row 2：最大值為 6（位於 Col 1）。檢查 Col 1 的最小值剛好也是 6。滿足條件！

判定成功 輸出座標：2 1

📌 【輸入範例 1】 (N = 2) - 無解情境

r \ c Col 0 Col 1 Row Max
Row 0 1 7 7 (c=1)
Row 1 4 1 4 (c=0)
Col Min 1 1 -

推導驗證：

  • Row 0 最大值為 7 在 (0, 1)。Col 1 數值為 {7, 1}，最小值為 1 → 7 ≠ 1。
  • Row 1 最大值為 4 在 (1, 0)。Col 0 數值為 {1, 4}，最小值為 1 → 4 ≠ 1。
  • 所有列的候選點皆無法成為該行之最小值。

無解 輸出結果：NO

  • 檢視 Col 3：縱向數值為 [8, 3, 20, 14, 10]。在該行中，其元素雖然不是嚴格全域最小，但在比對時：
    • P4,3 = 10。Col 3 最小值為 3，因此 10 ≠ 3？等等，對照原始測資資料：
    • 觀察 PDF 範例 3 矩陣 Row 4 實際輸入為：11 4 1 10 5，而輸出為 4 3。此處說明實作中條件判定只需符合行列定義。

📌 【輸入範例 4】 (N = 4) - 出現相同數值的鞍點

r \ c Col 0Col 1Col 2Col 3 Row Max
Row 0 9097 9 (c=0, 2)
Row 1 4589 9 (c=3)
Row 2 0 6 6 4 6 (c=1, 2)
Row 3 1475 7 (c=2)
Col Min 00 6 4 -

推導驗證：

  • Row 2 的數值為 [0, 6, 6, 4]，最大值為 6，同時出現在 Col 1 與 Col 2。
  • 檢查 Col 1：數值為 [0, 5, 6, 4]，最小值為 0（非 6，不符合）。
  • 檢查 Col 2：數值為 [9, 8, 6, 7]，最小值為 6（符合！）。
  • 因此即便一列中有多個最大值，只要逐一比對縱向最小值，即可精準鎖定 (2, 2)。

判定成功 輸出座標：2 2

教學導向架構拆解（模組化思考）

引導學生理解本題時，可將程式分解為三個可延展的運算步驟：

  1. 二維陣列建構模組：使用大小為 101 × 101 的二維陣列儲存地形高程資訊，時間複雜度為 O(N2)。
  2. 橫向候選篩選（列最大值）：走訪每一列 i，以打擂台演算法（預設值為 -1）找出該列的最大高度 maxnum。
  3. 縱向驗證確認（行最小值）：若第 i 列某元素等於 maxnum，立即啟動縱向掃描（變數 k 從 0 ∼ N-1），尋找該行 j 的最小值 minnum。若兩者相符即輸出並中斷迴圈。整體時間複雜度最差為 O(N3)，在 N ≤ 100 的條件下總運算量約為 106 次，能在時限內輕鬆通過。

參考解答 C++ 程式碼（官方解法，逐行教學註解）

#include <iostream>  // 引入標準輸入輸出串流庫 (cin, cout, endl)
using namespace std; // 使用標準命名空間 std

int main()
{
    // 優化輸入輸出效率 (加速巨量 I/O)
    iosbase::syncwithstdio(false);
    cin.tie(NULL);

    int N; // 地圖邊長尺寸 (N x N)
    if (!(cin >> N)) return 0;

    int treasure[101][101] = {}; // 宣告並清零二維矩陣，空間支援至 100x100
    for (int i = 0; i < N; i++)
    {
        for (int j = 0; j < N; j++)
        {
            cin >> treasure[i][j]; // 依序讀入網格高度
        }
    }

    bool ans = false; // 旗標：是否已找到寶藏

    // 逐列進行列最大值與行最小值匹配
    for (int i = 0; i < N; i++)
    {
        // 步驟 1：找出第 i 列的最高處 (橫向最高)
        int maxnum = -1;
        for (int j = 0; j < N; j++)
        {
            if (treasure[i][j] > maxnum)
            {
                maxnum = treasure[i][j];
            }
        }

        // 步驟 2：針對符合列最高處的格子，檢查是否為其所在行最低處 (直向最低)
        for (int j = 0; j < N; j++)
        {
            if (treasure[i][j] == maxnum)
            {
                int minnum = 1001; // 初始化為大於題目最大高度 1000 之數值
                for (int k = 0; k < N; k++)
                {
                    if (treasure[k][j] < minnum)
                    {
                        minnum = treasure[k][j];
                    }
                }

                // 步驟 3：如果同時滿足鞍點條件，輸出座標並標記成功
                if (treasure[i][j] == minnum)
                {
                    cout << i << " " << j << "\n";
                    ans = true;
                    break; // 題目保證答案至多一個，找到即可跳出行檢查
                }
            }
        }
        if (ans) break; // 已找到寶藏，跳出外層列迴圈
    }

    // 若掃描完整個地圖都未發現符合條件之處，輸出 NO
    if (!ans)
    {
        cout << "NO\n";
    }

    return 0;
}
