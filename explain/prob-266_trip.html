#266 202410trip (校外教學分組)

題目摘要

問題敘述： 校外教學要將 N 位學生分成 3 組行動。老師認為如果組內有學生彼此是朋友的話可能會因為聊天導致秩序不好，因此同一組內不能存在有兩位學生彼此是朋友關係。

同時，為了使每一組的導遊負擔儘量一樣，老師也希望「最多人的組」和「最少人的組」人數的差值越小越好。

給定 M 筆學生間的朋友關係，請幫老師計算出分組後「最多人的組」和「最少人的組」人數的最小差值；如果無法分組，請輸出 -1。

輸入格式： 第一列有兩個正整數 N 與 M (3 ≤ N ≤ 16, M ≤ N × (N-1)/2)，表示有 N 位學生和 M 筆學生們的朋友關係。接下來 M 列，每列有兩個相異正整數 X 與 Y (1 ≤ X, Y ≤ N)，代表學生 X 和學生 Y 互相是朋友。

輸出格式： 輸出一個整數，表示分組後「最多人的組」和「最少人的組」人數的最小差值，如果無法分組，輸出 -1。

演算法使用解析：【深度優先搜尋 (DFS) / 狀態窮舉與回溯法】

本題資料規模限制為 N ≤ 16：

  • 狀態枚舉： 由於 N 很小（最多 16 個人），每一位學生可以獨立選擇分配到第 0、1 或 2 組，總共的可能分配組合為 316 ≈ 4.3 × 107 種。透過深度優先搜尋 (DFS) 遞迴枚舉所有學生的分組狀態。
  • 合法性檢查： 當所有學生的分組決定後（到達遞迴終止條件 cur == n），檢查每一條朋友關係 (X, Y)，若兩者被分在同一組（即 group[X] == group[Y]），則此分組方案非法，予以捨棄。
  • 最佳化求解： 對於所有合法的分組方案，統計三組的人數，計算「最多人數組 - 最少人數組」的差值，並更新全域的最小值。若找不到任何合法方案則輸出 -1。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
5 5
1 2
2 3
3 4
4 5
1 5
  • N = 5 位學生，M = 5 筆朋友關係：(1,2), (2,3), (3,4), (4,5), (1,5) 形成一個五邊形環。
  • 透過 DFS 尋找合法分組方案。例如將學生 1、4 分成一組（2人），學生 2、5 分成一組（2人），學生 3 獨立成一組（1人）。
  • 檢查各組朋友關係：1 和 4 不同組，2 和 5 不同組，均合法。
  • 此時三組人數分別為 2、2、1。最多人組 = 2，最少人組 = 1，差值 = 2 - 1 = 1。

👉 輸出範例 1 結果： 1

【輸入範例 2 實際運作推導】

輸入：
4 6
1 2
1 3
1 4
2 3
2 4
3 4
  • N = 4，M = 6。這代表 4 個人兩兩互為朋友（完全圖 K4）。
  • 因為任兩個人都是朋友，所以無論怎麼分成 3 組，總會有一組裡面包含兩個人且這兩個人互相是朋友，違反「同一組內不能有朋友」的規則。

👉 輸出範例 2 結果： -1（無法分組）

【輸入範例 3 實際運作推導】

輸入：
6 1
1 2
  • N = 6，M = 1，只有學生 1 和 2 是朋友。
  • 可以將學生 1 和其他非朋友分開，例如將 1 分到組 0，2 分到組 1，其餘 3、4、5、6 分別合理分配，使得三組人數盡可能均勻（例如 2 人、2 人、2 人）。
  • 此時最多人組 = 2，最少人組 = 2，差值 = 2 - 2 = 0。

👉 輸出範例 3 結果： 0

參考解答 C++ 程式碼（含每行詳細中文教學註解）

#include<cstdio>    // 引入標準輸入輸出標頭檔，以便使用 scanf 與 printf
#include<algorithm> // 引入演算法標頭檔，以便使用 min 與 max 函數
using namespace std;

const int maxn = 16 + 1; // 定義學生人數最大常數
const int maxm = maxn * (maxn - 1) / 2; // 定義朋友關係邊的最大數量
const int inf = 2147483647; // 定義無窮大初始值

// 深度優先搜尋 (DFS) 枚舉每個學生的分組狀態
void dfs(int cur, int n, int m, int *group, const int f[maxm][2], int& ans)
{
	if (cur == n) // 若所有學生的分組已決定完成（遞迴終止條件）
	{
		bool flag = true; // 旗標用來記錄當前分組是否合法
		for (int i = 0; i < m; ++i) // 檢查所有朋友關係
		{
			// 若互為朋友的兩位學生被分配到同一組
			if (group[f[i][0]] == group[f[i][1]])
			{
				flag = false; // 違反規定，標記為不合法
				break;
			}
		}
		if (flag == true) // 若分組方案合法
		{
			int cnt[3] = {0}; // 統計三組各自的人數
			for (int i = 0; i < n; ++i)
			{
				++cnt[group[i]];
			}
			// 計算最多人數組與最少人數組的差值，並更新全域最小差值 ans
			ans = min(ans, max({cnt[0], cnt[1], cnt[2]}) - min({cnt[0], cnt[1], cnt[2]}));
		}
		return;
	}
	// 對當前學生 cur 嘗試分配到 0, 1, 2 三組中的其中一組
	for (int i = 0; i < 3; ++i)
	{
		group[cur] = i; // 將學生 cur 放入第 i 組
		dfs(cur + 1, n, m, group, f, ans); // 遞迴決定下一位學生
	}
	return;
}

int solve(int n, int m, int f[maxm][2])
{
	int group[maxn]; // 儲存每位學生的分組編號 (0, 1, 2)
	int ans = inf;   // 初始化最小差值為無窮大
	dfs(0, n, m, group, f, ans); // 從第 0 位學生開始進行 DFS 搜尋
	if (ans == inf)  // 若無窮大未被更新，代表找不到任何合法分組方案
	{
		return -1;   // 回傳 -1
	}
	return ans;      // 回傳最小差值
}

int main()
{
	int n, m;
	int f[maxm][2];
	scanf("%d%d", &n, &m); // 讀入學生人數 n 與朋友關係數 m
	for (int i = 0; i < m; ++i)
	{
		scanf("%d%d", &f[i][0], &f[i][1]); // 讀入互為朋友的兩位學生編號
		--f[i][0]; // 將學生編號轉換為 0 起始索引
		--f[i][1];
	}
	printf("%d\n", solve(n, m, f)); // 執行求解並輸出結果
	return 0; // 程式正常結束
}
