#32 201910_B3-Master (虛擬寵物大師)

PDF: 201910_B3-Master.pdf 開啟題目與原始解法 ↗

題目摘要

問題敘述： 虛擬寵物的強度取決於原始 CP 值與 IV 值（素質）。利用手上的星塵沙子，每消耗 1000 星塵可提升一級，依據 IV 區間不同，每升一等增加的 CP 值也有所差異（IV 0~29 增加 10，IV 30~39 增加 50，IV 40~45 增加 100）。給定候選寵物數量 n、手上的星塵總量 S，以及每隻寵物的 CP 值與 IV 值，請找出消耗完現有星塵成長後，能達到最高 CP 值的寵物編號與其最終 CP 值。

輸入格式： 第一行有兩個正整數 n (1 ≤ n ≤ 50) 與 S (1 ≤ S ≤ 105)；接下來 n 行，每行有兩個整數 CP 與 IV。

輸出格式： 輸出一行，包含欲捕捉的「虛擬寵物編號」與該寵物「成長後最高 CP 值」，中間以空格隔開。

演算法使用解析：【貪心法 (Greedy) 與直接計算】

本題採用貪心與直接模擬策略：

  • 每隻寵物升等所消耗的星塵總量是固定的（即手上的總星塵 S 全數投資在同一隻寵物身上）。
  • 因此，我們可以獨立計算每一隻寵物在消耗完所有星塵後能提升幾等（\lfloor S / 1000 \rfloor），並依據其 IV 值對應的每級 CP 成長量，直接算出成長後的最終 CP 值。
  • 在所有候選寵物中，透過貪心比較法挑選出最終 CP 值最高者即可。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
3 1000
1520 43
1300 33
1600 22
  • 總星塵 S = 1000： 可升級次數為 1000 / 1000 = 1 等。
  • 逐一評估每隻寵物：
    • 寵物 1： CP = 1520, IV = 43（屬於 40 ∼ 45 區間，每等增加 100）。
      成長後 CP = 1520 + 1 × 100 = 1620。
    • 寵物 2： CP = 1300, IV = 33（屬於 30 ∼ 39 區間，每等增加 50）。
      成長後 CP = 1300 + 1 × 50 = 1350。
    • 寵物 3： CP = 1600, IV = 22（屬於 0 ∼ 29 區間，每等增加 10）。
      成長後 CP = 1600 + 1 × 10 = 1610。
  • 比較結果： 最高 CP 值為 1620，對應編號為 1。

👉 輸出範例 1 結果： 1 1620

【輸入範例 2 實際運作推導】

輸入：
4 55555
200 42
400 40
500 30
3000 27
  • 總星塵 S = 55555： 可升級次數為 55555 / 1000 = 55 等。
  • 逐一評估：
    • 寵物 1 (IV = 42, 增 100)：200 + 55 × 100 = 5700。
    • 寵物 2 (IV = 40, 增 100)：400 + 55 × 100 = 5900（最高）。
    • 寵物 3 (IV = 30, 增 50)：500 + 55 × 50 = 3250。
    • 寵物 4 (IV = 27, 增 10)：3000 + 55 × 10 = 3550。

👉 輸出範例 2 結果： 2 5900

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include<stdio.h>  // 引入標準輸入輸出標頭檔

int main()
{
	int n = 0, S = 0;  // 宣告 n 代表候選寵物數量，S 代表小手上的星塵沙子總量
	scanf("%d %d", &n, &S);  // 讀入寵物數量 n 與星塵總量 S

	int BestCp = 0, BestCpNo = 0;  // 宣告紀錄最高成長後 CP 值與對應寵物編號的變數
	for(int i=1; i<=n; i+=1)
	{
		int resultCP = 0;  // 宣告變數儲存當前寵物成長後的 CP 值
		int cp = 0, iv = 0;  // 宣告變數儲存當前寵物的原始 CP 值與 IV 值
		scanf("%d %d", &cp, &iv);  // 讀入當前寵物的 CP 與 IV

		int tmpS = S;  // 將總星塵數量暫存到 tmpS 中
		// 根據題目給定的 IV 區間與對應的 CP 增加值進行貪心計算
		if( iv >= 40 )
			resultCP = cp + (tmpS/1000)*100;  // 若 IV 在 40~45 之間，每 1000 星塵增加 100 CP
		else if( iv >= 30 )
			resultCP = cp + (tmpS/1000)*50;   // 若 IV 在 30~39 之間，每 1000 星塵增加 50 CP
		else if( iv >= 0 )
			resultCP = cp + (tmpS/1000)*10;   // 若 IV 在 0~29 之間，每 1000 星塵增加 10 CP
		
		// 比較並更新所有候選寵物中的最高 CP 值與編號
		if( resultCP > BestCp ){
			BestCp = resultCP;  // 更新最高 CP 值
			BestCpNo = i;      // 更新對應的寵物編號
		}
	}

	printf("%d %d\n", BestCpNo, BestCp);  // 輸出成長後最高 CP 值的寵物編號與其最高 CP 值
	return 0;  // 程式正常結束
}
