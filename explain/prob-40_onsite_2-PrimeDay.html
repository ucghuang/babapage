#40 201912-onsite_2-PrimeDay (質數日)

題目摘要

問題敘述： 某些日期（如 20190823）除了本身是質數之外，把最左邊的數字依序去掉後剩下的數字（如 190823、90823、823、23、3）也全都是質數，這樣的日子被稱為「質數日」。給定多個 21~30 世紀中的日期，請撰寫程式判斷這些日期是否為質數日。

輸入格式： 第一行輸入一個正整數 D (1 ≤ D ≤ 10) 代表有幾個日期；接下來 D 行，每行一個正整數 N (20000101 ≤ N ≤ 29991231) 表示日期。

輸出格式： 對於每個日期輸出一行文字：若是質數日輸出 N is a Prime Day!，否則輸出 N isn't a Prime Day!。

演算法使用解析：【數論與數學 / 質數判定與位數剝離】

本題採用質數試除法與模運算 (Modulo Operation)：

  • 質數定義：在大於 1 的自然數中，除了 1 和該數自身外，無法被其他自然數整除的數（最小的質數是 2，且 1 既不是質數也不是合數）。
  • 質數判定：對於任意數 M，我們利用迴圈從 2 測試到 \sqrt{M}，若能被整除則代表不是質數。
  • 位數剝離：透過連續對 107, 106, … 取餘數（% Digit），每次去掉最左邊的一個數字，並依序檢查每一個截斷後的數是否皆為質數。若在剝離過程中剩下了 1，因 1 不是質數（最小的質數是 2），故不符合質數日定義。

課堂黑板板書推導

【輸入範例 1 實際運作推導】

輸入：
1
20190823
  • 檢查完整數字： 20190823 經試除法判定是質數。
  • 剝離最左邊數字：
    • 去掉 '2' → 190823（經試除法判定是質數）
    • 去掉 '1' → 90823（經試除法判定是質數）
    • 去掉 '9' → 823（經試除法判定是質數）
    • 去掉 '0' → 23（經試除法判定是質數）
    • 去掉 '2' → 3（經試除法判定是質數）
  • 每一層截斷數字皆大於 1 且通過質數檢驗。

👉 輸出範例 1 結果： 20190823 is a Prime Day!

【輸入範例 2 實際運作推導】

輸入：
4
29331013
20400823
20191102
20000101
  • 第一筆測資： 29331013
    • 依序檢查完整數以及剝離後的 9331013、331013、31013、1013、13、3。每一層截斷後的數經過試除法全部都是大於 1 的質數。

    👉 結果：29331013 is a Prime Day!

  • 第二筆測資： 20400823
    • 依序檢查完整數以及剝離後的 400823、823、23、3 等。所有過程中的截斷數皆通過質數檢驗。

    👉 結果：20400823 is a Prime Day!

  • 第三筆測資： 20191102
    • 完整數 20191102 末尾是 2 且大於 2（偶數），明顯可被 2 整除，因此它不是質數（合數）。

    👉 結果：20191102 isn't a Prime Day!

  • 第四筆測資： 20000101
    • 當數字在剝離過程中最後剩下 1 時，因為 1 不是質數（根據定義，最小的質數是 2），所以不符合質數日的條件，故判定為否。

    👉 結果：20000101 isn't a Prime Day!

參考解答 C++ 程式碼（百分之百保留原始解答邏輯與變數名稱，含每行詳細中文教學註解）

#include <stdio.h>  // 引入標準輸入輸出標頭檔
#include <math.h>   // 引入數學函式庫，以便使用 sqrt 根號計算

int main()
{
    int D = 0;  // 宣告變數 D 代表測資中的日期總數
    int N = 0, M = 0;  // N 儲存原始日期，M 儲存剝離過程中的數字
    scanf("%d", &D);  // 讀入測試日期個數 D
    
    for(int i = 0; i < D; i += 1)
    {
        scanf("%d", &N);  // 讀入當前要檢查的日期 N
        M = N;  // 將日期複製給 M 進行後續的剝離與檢查
        int Digit = 10000000;  // 初始化位數遮罩，用來協助去掉最左邊的數字
        bool Check = true;  // 旗標變數，記錄目前為止是否全都是質數（預設為 true）
        
        while(M > 0)
        {
            // 質數試除法：檢查當前數字 M 是否為質數
            for(int j = 2; j <= sqrt(M); j += 1)
            {
                if(M % j == 0)  // 若 M 可被 j 整除
                {
                    Check = false;  // 代表不是質數，標記 Check 為 false
                    break;  // 跳出內層迴圈
                }
            }
            if(Check == false) break;  // 若已經確定不是質數，直接終止檢查
            
            M %= Digit;  // 對 Digit 取餘數，藉此去掉最左邊的第一個數字
            Digit /= 10;  // 將位數遮罩除以 10，準備檢查下一個更短的數字
        }
        
        // 根據檢查結果輸出是否為質數日
        if(Check == true) printf("%d is a Prime Day!\n", N);
        else printf("%d isn't a Prime Day!\n", N);
    }
}
